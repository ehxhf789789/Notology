Notology Primitives — 5.0.2a

Primitive 컴포넌트 미리보기

Tier 2 semantic token 만 사용하는 14개 primitive. 상단에서 테마 + 폰트를 토글해 light / dark / 폰트 변경 모두 검증하세요. Component 15–23 (Tooltip / Popover / Dialog / DropdownMenu / Tabs / Toast / Select 등) 은 Floating-UI 와 함께 5.0.2b 에서 제공됩니다.

이 페이지는 production 의 reset.css 를 그대로 import 하므로, settings 에서 폰트를 바꿀 때와 동일한 메커니즘 ([data-font] selector → --app-font cascade) 으로 동작합니다. 모든 primitive 는 font-family: inherit 으로 사용자 폰트를 자동으로 따라갑니다.
