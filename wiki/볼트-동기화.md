# <img src="images/icons/hard-drive.png" width="24" height="24"> 볼트 & 동기화

볼트(Vault)는 노트가 저장되는 폴더입니다. 여러 볼트를 만들어 용도별로 나누고, NAS나 클라우드 드라이브와 동기화하여 여러 기기에서 사용할 수 있습니다.

---

## 볼트 개념

**볼트**는 Notology가 관리하는 노트 폴더입니다.

| 특징 | 설명 |
|------|------|
| **일반 폴더** | 볼트는 Windows의 일반 폴더입니다. 탐색기에서 직접 접근할 수 있습니다 |
| **마크다운 파일** | 모든 노트는 `.md` (마크다운) 파일로 저장됩니다 |
| **폴더 구조** | 볼트 안에 폴더를 자유롭게 만들어 정리할 수 있습니다 |
| **여러 볼트** | 용도별로 여러 볼트를 만들 수 있습니다 |
| **호환성** | 마크다운 파일이므로 다른 편집기에서도 열 수 있습니다 |

---

## 볼트 관리

### 새 볼트 열기

1. 사이드바 상단의 **볼트 이름**을 클릭합니다
2. **새 볼트 열기**를 선택합니다
3. 원하는 폴더를 선택합니다

> 📸 **여기에 GIF** — `images/vault-open-new.gif`
>
> **촬영**: 사이드바 상단의 볼트 이름을 클릭하여 새 볼트를 여는 과정
> **순서**: ① 사이드바 상단의 볼트 이름 클릭 → ② 드롭다운 메뉴에서 "새 볼트 열기" 선택 → ③ 폴더 선택 대화상자 표시 → ④ 원하는 폴더 선택 → ⑤ 새 볼트가 로드됨
> **화면 영역**: 전체 화면 (사이드바 상단 클릭 → 드롭다운 → 폴더 선택 대화상자)
> **강조**: 사이드바 상단의 볼트 이름 클릭 영역, "새 볼트 열기" 메뉴 항목
> **길이**: 5~8초

### 최근 볼트 전환

1. 사이드바 상단의 **볼트 이름**을 클릭합니다
2. **최근 사용한 볼트 목록**에서 원하는 볼트를 선택합니다

> 📸 **여기에 GIF** — `images/vault-switch.gif`
>
> **촬영**: 사이드바 상단에서 최근 볼트 목록을 통해 다른 볼트로 전환하는 과정
> **순서**: ① 사이드바 상단의 볼트 이름 클릭 → ② 드롭다운에 표시된 최근 볼트 목록 확인 → ③ 다른 볼트 이름 클릭 → ④ 볼트가 전환되며 사이드바 파일 트리가 변경됨
> **화면 영역**: 전체 화면 (사이드바 상단 드롭다운 + 볼트 전환 후 파일 트리 변화)
> **강조**: 최근 볼트 목록의 항목들, 전환 후 사이드바의 파일 트리가 바뀌는 순간
> **길이**: 5~8초

### 볼트 활용 예시

| 볼트 | 용도 | 내용 |
|------|------|------|
| **업무** | 회사 업무 관련 | 회의록, 프로젝트, 보고서, 동료 정보 |
| **개인** | 개인 생활 | 일기, 취미, 독서 노트, 아이디어 |
| **연구** | 학습/연구 | 논문 정리, 실험 기록, 강의 노트 |

> **💡 팁**: 업무와 개인 노트를 분리하고 싶다면 볼트를 나누는 것이 좋습니다. 하나의 볼트 안에서 폴더로 구분해도 됩니다.

## 볼트 잠금

Notology는 한 번에 하나의 기기에서만 볼트를 사용하도록 **잠금 시스템**을 제공합니다.

| 상황 | 동작 |
|------|------|
| **볼트 열기** | 자동으로 잠금이 설정됩니다 |
| **앱 종료** | 자동으로 잠금이 해제됩니다 |
| **다른 기기에서 열기 시도** | 경고 메시지가 표시됩니다 |
| **강제 열기** | 경고를 확인한 뒤 강제로 열 수 있습니다 |

> 📸 **여기에 GIF** — `images/vault-lock-warning.gif`
>
> **촬영**: 다른 기기에서 이미 열린 볼트를 열려고 할 때 나타나는 잠금 경고 메시지
> **순서**: ① 이미 잠긴 볼트를 열기 시도 → ② 잠금 경고 대화상자가 나타남 → ③ 경고 메시지 내용 확인 (어떤 기기에서 사용 중인지 표시) → ④ "강제 열기" 또는 "취소" 버튼
> **화면 영역**: 전체 화면 (경고 대화상자가 중앙에 표시)
> **강조**: 경고 메시지 텍스트, "강제 열기" 버튼
> **길이**: 3~5초

> **주의**: 같은 볼트를 두 기기에서 동시에 편집하면 파일 충돌이 발생할 수 있습니다. 반드시 한 기기에서 작업을 마친 뒤 다른 기기에서 열어주세요.

## NAS / 클라우드 동기화

NAS 동기화 클라이언트나 클라우드 드라이브(OneDrive, Google Drive 등)를 사용하면 여러 PC에서 노트를 동기화할 수 있습니다.

### 설정 방법

| 단계 | 설명 |
|------|------|
| 1 | NAS 동기화 클라이언트 또는 클라우드 드라이브 앱을 PC에 설치합니다 |
| 2 | 동기화 앱에서 **동기화 폴더**를 설정합니다 |
| 3 | Notology에서 해당 동기화 폴더를 **볼트로 열기**합니다 |

이렇게 하면 PC에서 노트를 수정하면 NAS나 클라우드에 자동으로 업로드되고, 다른 PC에서도 최신 내용을 받아볼 수 있습니다.

### 호환되는 동기화 도구

| 종류 | 예시 |
|------|------|
| **NAS** | NAS 제조사에서 제공하는 동기화 클라이언트 |
| **클라우드** | OneDrive, Google Drive, Dropbox, iCloud 등 |
| **외장하드** | USB, 외장 SSD 등 (수동 복사) |

> 📸 **여기에 GIF** — `images/vault-sync-setup.gif`
>
> **촬영**: 동기화 폴더를 Notology 볼트로 설정하는 과정
> **순서**: ① 동기화 앱의 동기화 폴더 위치 확인 → ② Notology에서 "새 볼트 열기" 선택 → ③ 동기화 폴더를 볼트로 지정 → ④ 볼트가 로드되고 동기화 상태 확인
> **화면 영역**: 전체 화면 (Notology 앱에서 볼트 폴더를 선택하는 과정)
> **강조**: 동기화 폴더를 선택하는 순간
> **길이**: 5~8초

### 동기화 동작

| 기능 | 설명 |
|------|------|
| **자동 동기화** | 노트 저장 시 자동으로 NAS에 업로드됩니다 (디바운스 적용) |
| **충돌 감지** | 같은 파일이 두 곳에서 수정되면 충돌을 감지합니다 |
| **이름 변경 재시도** | NAS 동기화 중 파일 잠금이 발생하면 최대 3회까지 자동 재시도합니다 |

> 📸 **여기에 GIF** — `images/vault-conflict-resolve.gif`
>
> **촬영**: 동기화 충돌이 발생했을 때 충돌 파일을 해결하는 과정
> **순서**: ① 충돌 알림 또는 충돌 파일 감지 → ② 충돌 파일 표시 (파일명에 충돌 표시) → ③ 사용자가 충돌을 확인하고 해결
> **화면 영역**: 사이드바 파일 트리 + 에디터 영역
> **강조**: 충돌이 발생한 파일의 표시 방식, 해결 과정
> **길이**: 5~8초

## 데이터 저장 위치

Notology의 데이터는 다음 위치에 저장됩니다.

| 데이터 | 위치 | 설명 |
|--------|------|------|
| **노트 파일** | 볼트 폴더 | 사용자가 지정한 폴더 (`.md` 파일) |
| **앱 설정** | `%APPDATA%\com.notology.app\` | 테마, 글꼴, 최근 볼트 목록 등 |
| **검색 인덱스** | `%LOCALAPPDATA%\Notology\indices\` | 전문 검색을 위한 인덱스 파일 |
| **미리보기 캐시** | `%LOCALAPPDATA%\Notology\preview_cache\` | 문서 미리보기 변환 캐시 |

> **💡 팁**: `%APPDATA%`는 Windows 탐색기 주소창에 직접 입력하면 이동할 수 있습니다.

## 백업 팁

노트를 안전하게 보관하기 위한 백업 방법입니다.

| 방법 | 설명 |
|------|------|
| **폴더 복사** | 볼트 폴더를 통째로 USB나 외장하드에 복사합니다 |
| **클라우드 동기화** | 볼트 폴더를 OneDrive, Google Drive 등에 위치시킵니다 |
| **NAS 동기화** | NAS 동기화 클라이언트로 자동 백업합니다 |
| **Git 관리** | 볼트 폴더를 Git으로 버전 관리합니다 (개발자 추천) |

노트는 모두 **일반 마크다운 파일**이므로, Notology가 아닌 다른 마크다운 편집기에서도 언제든 열어볼 수 있습니다. 특정 앱에 종속되지 않습니다.
