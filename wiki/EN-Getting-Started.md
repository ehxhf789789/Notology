## Installing Notology

Notology is a Windows-only desktop application. Follow the steps below to get started.

| Step | What to do |
|------|------------|
| 1 | Download the latest `.msi` file from the [GitHub Releases](https://github.com/your-repo/releases) page |
| 2 | Double-click the downloaded `.msi` file to run the installer |
| 3 | When the setup wizard appears, click **Next** until the installation is complete |
| 4 | Launch **Notology** from the desktop shortcut or the Start menu |

## Creating a Vault

A **Vault** is a folder where your notes are stored. Think of it as a box that holds your entire note collection.

- Every note inside a Vault is saved as a `.md` (Markdown) file
- You can freely create folders inside a Vault to organize your notes
- You can create multiple Vaults for different purposes (e.g., one for work, one for personal use)

### How to create a Vault

1. When you launch Notology for the first time, a "Select a Vault" screen appears
2. Click the **Create New Vault** button
3. Choose a folder location for your notes (e.g., your Documents folder)
4. Enter a Vault name and click **OK** — done!

> **Screen area**: Full Notology app window
> **Highlight**: Clicking the "Create New Vault" button and the folder selection step
> **Duration**: 8~12s

> **💡 Tip**: If you set your Vault to a NAS or cloud drive folder (OneDrive, Google Drive, etc.), you can access the same notes from multiple computers.

## Creating Your First Note

Now that your Vault is ready, let's write a note!

1. Press `Ctrl + N` (or click the **+ button** at the bottom of the sidebar)
2. Enter a note name (e.g., "My First Note")
3. Pick a template (for now, just choose the default "Note")
4. When the editor opens, start writing!

## What Are Containers?

In Notology, a **Container** is a top-level bucket that holds your notes. There are two types.

| Container Type | What is it? | When to use it |
|----------------|-------------|----------------|
| **Standard** | Lets you freely create folders and organize notes. Just like Windows File Explorer, you can nest folders inside folders. | Project management, general notes, flexible structure |
| **Storage** | Stores notes using a single template in a uniform format. Notes are listed flat, with no folders. | Contact lists, meeting logs, data cards |

> 📸 **GIF placeholder** — `images/create-container.gif`
>
> **Shot**: Creating a Standard container and a Storage container one after the other
> **Steps**: ① Click the add container button in the sidebar → ② Select "Standard" → ③ Enter a name → ④ Creation complete → ⑤ Click add again → ⑥ Select "Storage" → ⑦ Enter name + choose template → ⑧ Creation complete
> **Screen area**: Sidebar area centered (including dialogs)
> **Highlight**: The difference between the Standard and Storage selection screens
> **Duration**: 8~12s
