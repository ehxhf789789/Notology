# <img src="images/icons/tag.png" width="24" height="24"> 태그 시스템

태그는 노트를 분류하는 라벨입니다. 폴더와 달리 하나의 노트에 여러 태그를 붙일 수 있어서, 유연하게 노트를 정리하고 찾을 수 있어요.

---

## 개념

태그는 노트 상단의 **YAML 프론트매터** `tags` 항목에 저장됩니다.

```yaml
---
tags:
  - 프로젝트
  - 진행중
  - domain:개발
---
```

- 하나의 노트에 여러 태그를 붙일 수 있습니다
- 태그로 관련 노트를 빠르게 묶어서 검색할 수 있습니다
- 그래프 뷰에서 같은 태그를 가진 노트의 관계를 시각화할 수 있습니다

> 📸 **여기에 스크린샷** — `images/tags-concept.png`
>
> **촬영**: YAML 프론트매터에 태그가 입력된 노트 화면
> **내용**: 노트 상단에 `tags:` 항목이 보이고, 그 아래 여러 태그(예: 프로젝트, 진행중, domain:개발)가 목록 형태로 표시된 상태
> **화면 영역**: 에디터 상단 영역 (YAML 프론트매터 부분)

---

## 태그 추가하기

### YAML에서 직접 추가

노트 상단의 프론트매터 영역에서 `tags` 항목에 태그를 입력합니다.

```yaml
---
tags:
  - 새로운태그
---
```

### 검색에서 일괄 추가

검색 결과에서 여러 노트를 선택한 뒤, 일괄 작업으로 태그를 한꺼번에 추가할 수 있습니다.

> 📸 **여기에 GIF** — `images/tags-add.gif`
>
> **촬영**: YAML 프론트매터에서 태그를 직접 추가하거나, 검색 결과에서 여러 노트에 태그를 일괄 추가하는 과정
> **순서**: ① 노트 상단의 YAML 프론트매터에서 새 태그 입력 → ② 태그가 추가됨 (또는) ① 검색(Ctrl+Shift+F) 열기 → ② 여러 노트 선택 → ③ 일괄 태그 추가 실행
> **화면 영역**: 에디터 상단 (YAML 영역) 또는 검색 패널 전체
> **강조**: 태그가 추가되는 순간, 일괄 선택 시 체크박스
> **길이**: 5~8초

## 태그 색상

태그마다 고유한 색상을 지정할 수 있습니다. 색상이 지정된 태그는 노트와 검색 결과에서 눈에 띄게 구분됩니다.

| 기능 | 설명 |
|------|------|
| **색상 지정** | 태그를 클릭하여 원하는 색상을 선택합니다 |
| **시각 구분** | 중요한 태그에 눈에 띄는 색상을 지정하면 빠르게 식별할 수 있습니다 |
| **일관성** | 한번 지정한 색상은 모든 노트에서 동일하게 표시됩니다 |

> 📸 **여기에 GIF** — `images/tags-colors.gif`
>
> **촬영**: 태그를 클릭하여 색상 선택 팔레트에서 색상을 지정하는 과정
> **순서**: ① 노트 상단의 태그 클릭 → ② 색상 선택 팔레트 표시 → ③ 원하는 색상 클릭 → ④ 태그 색상이 변경됨
> **화면 영역**: 에디터 상단 (태그 영역 + 색상 팔레트 팝업)
> **강조**: 색상 팔레트 팝업, 색상 변경 전후 태그의 시각적 차이
> **길이**: 3~5초

## 네임스페이스 태그

태그에 **접두사(prefix)**를 붙여 체계적으로 분류할 수 있습니다. `접두사:값` 형식으로 작성합니다.

| 접두사 | 용도 | 예시 |
|--------|------|------|
| `domain:` | 분야/영역 | `domain:개발`, `domain:마케팅`, `domain:디자인` |
| `who:` | 사람/담당자 | `who:김철수`, `who:이영희` |
| `org:` | 조직/팀 | `org:기획팀`, `org:개발팀`, `org:거래처A` |
| `ctx:` | 맥락/상황 | `ctx:긴급`, `ctx:보류`, `ctx:완료` |

### 예시

```yaml
---
tags:
  - domain:개발
  - who:김철수
  - org:프론트엔드팀
  - ctx:진행중
---
```

이렇게 네임스페이스를 사용하면 검색할 때 `domain:` 으로 시작하는 태그만 필터링하는 등 체계적인 관리가 가능합니다.

> 📸 **여기에 GIF** — `images/tags-namespace.gif`
>
> **촬영**: 네임스페이스 태그(domain:, who: 등)가 적용된 노트를 보여주고, 검색에서 접두사로 필터링하는 과정
> **순서**: ① 노트의 YAML에서 네임스페이스 태그(domain:개발, who:김철수) 확인 → ② 검색 열기 → ③ 태그 필터에서 "domain:" 접두사로 검색 → ④ 해당 태그를 가진 노트만 필터링됨
> **화면 영역**: 에디터 상단 (YAML 영역) → 검색 패널 전환
> **강조**: 접두사:값 형식의 태그 표시, 검색 필터링 결과
> **길이**: 5~8초

## 태그로 검색하기

검색(`Ctrl + Shift + F`)에서 태그를 기준으로 노트를 찾을 수 있습니다.

| 방법 | 설명 |
|------|------|
| **태그 필터** | 검색 패널의 태그 필터에서 원하는 태그를 선택합니다 |
| **직접 검색** | 검색 필드를 "태그"로 변경한 뒤 태그 이름을 입력합니다 |
| **복합 검색** | 키워드 + 태그 필터를 함께 사용하여 더 정확하게 찾습니다 |

> 📸 **여기에 GIF** — `images/tags-search.gif`
>
> **촬영**: 검색 패널에서 태그 필터를 선택하거나 태그 이름으로 검색하여 노트를 찾는 과정
> **순서**: ① Ctrl+Shift+F로 검색 열기 → ② 태그 필터 드롭다운 클릭 → ③ 원하는 태그 선택 → ④ 해당 태그가 있는 노트 목록 표시
> **화면 영역**: 검색 패널 전체 (검색 바 + 필터 + 결과 목록)
> **강조**: 태그 필터 드롭다운, 필터 적용 후 결과 변화
> **길이**: 5~8초

## 그래프 뷰에서 태그

[그래프 뷰](그래프-뷰)에서 태그는 **마름모(◆)** 모양의 노드로 표시됩니다.

- 같은 태그를 가진 노트들이 태그 노드를 중심으로 연결됩니다
- 태그 표시를 켜고 끌 수 있습니다 (그래프 설정 패널)
- 어떤 노트들이 같은 분류에 속하는지 시각적으로 파악할 수 있습니다

> 📸 **여기에 GIF** — `images/tags-graph.gif`
>
> **촬영**: 그래프 뷰에서 태그 노드(마름모)를 중심으로 같은 태그를 가진 노트들이 연결된 모습을 보여주는 과정
> **순서**: ① 그래프 뷰 열기 → ② 태그 노드(마름모)에 마우스 호버 → ③ 해당 태그를 가진 노트들이 하이라이트됨 → ④ 설정 패널에서 태그 표시 토글 ON/OFF
> **화면 영역**: 그래프 뷰 전체 (그래프 메인 영역 + 우측 설정 패널)
> **강조**: 마름모 모양의 태그 노드, 호버 시 연결된 노트 하이라이트
> **길이**: 5~8초

## 미사용 태그 정리

더 이상 사용하지 않는 태그를 정리할 수 있습니다.

- 어떤 노트에도 사용되지 않는 태그는 자동으로 감지됩니다
- 미사용 태그를 일괄 삭제하여 태그 목록을 깔끔하게 유지할 수 있습니다

> 📸 **여기에 GIF** — `images/tags-cleanup.gif`
>
> **촬영**: 미사용 태그를 감지하고 일괄 삭제하는 과정
> **순서**: ① 미사용 태그 목록 확인 → ② 삭제할 태그 선택 → ③ 일괄 삭제 실행 → ④ 태그 목록이 정리됨
> **화면 영역**: 태그 관리 패널 또는 설정 화면
> **강조**: 미사용 태그가 표시되는 방식, 삭제 전후 목록 변화
> **길이**: 5~8초

## 활용 예시

| 목적 | 추천 태그 | 설명 |
|------|----------|------|
| **프로젝트 관리** | `domain:프로젝트명`, `ctx:진행중`, `ctx:완료` | 프로젝트별로 노트를 모으고 진행 상태를 추적합니다 |
| **사람 관리** | `who:이름`, `org:소속` | 특정 사람과 관련된 노트를 빠르게 찾습니다 |
| **학습 정리** | `domain:과목명`, `ctx:복습필요` | 과목별로 노트를 분류하고 복습이 필요한 항목을 표시합니다 |
| **일상 업무** | `ctx:긴급`, `ctx:보류`, `domain:일정` | 업무 우선순위를 태그로 관리합니다 |

> **💡 팁**: 태그는 3~5개 정도가 적당합니다. 너무 많은 태그를 붙이면 오히려 관리가 어려워질 수 있습니다.
