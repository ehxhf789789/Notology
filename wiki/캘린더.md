# <img src="images/icons/calendar.png" width="24" height="24"> 캘린더 & 메모

날짜별로 메모와 할 일을 관리합니다. 노트에 작성한 코멘트가 캘린더에 자동으로 연결되어, 일정과 노트를 한곳에서 볼 수 있습니다.

---

## 캘린더 열기

| 방법 | 설명 |
|------|------|
| **단축키** | `Ctrl + Shift + C` |
| **패널 열기** | `Ctrl + →` 로 오른쪽 패널을 열면 캘린더가 포함되어 있습니다 |
| **접힌 바** | 패널이 접혀 있을 때 캘린더 아이콘 버튼을 클릭합니다 |

> 📸 **여기에 GIF** — `images/calendar-open.gif`
>
> **촬영**: Ctrl+Shift+C 단축키로 캘린더를 여는 과정
> **순서**: ① 키보드에서 Ctrl+Shift+C 입력 → ② 오른쪽 패널이 슬라이드되며 열림 → ③ 캘린더가 표시됨
> **화면 영역**: 전체 화면 (에디터 + 오른쪽 패널이 열리는 과정 포함)
> **강조**: 단축키 입력 후 패널이 열리는 애니메이션
> **길이**: 3~5초

---

## 월간 캘린더

캘린더는 한 달씩 보여주며, 상단에서 월을 이동할 수 있습니다.

| 기능 | 설명 |
|------|------|
| **◀ / ▶ 버튼** | 이전 달 / 다음 달로 이동합니다 |
| **오늘 강조** | 오늘 날짜가 강조 표시됩니다 |
| **메모 점(dot)** | 메모가 있는 날짜에 작은 점이 표시됩니다 |

> 📸 **여기에 GIF** — `images/calendar-navigate.gif`
>
> **촬영**: 월별 이동 버튼 클릭, 오늘 강조 표시, 메모 있는 날짜의 점 확인
> **순서**: ① ◀ 버튼 클릭하여 이전 달로 이동 → ② ▶ 버튼 클릭하여 다음 달로 이동 → ③ 오늘 날짜가 강조된 모습 확인 → ④ 메모 점(dot)이 있는 날짜에 마우스 올리기
> **화면 영역**: 오른쪽 패널의 캘린더 영역만
> **강조**: 오늘 날짜의 강조 스타일, 메모가 있는 날짜의 작은 점(dot)
> **길이**: 5~8초

## 날짜 선택

캘린더에서 날짜를 클릭하면 해당 날짜의 메모와 할 일 목록이 아래에 나타납니다.

> 📸 **여기에 GIF** — `images/calendar-select-date.gif`
>
> **촬영**: 캘린더에서 날짜를 클릭하여 메모 목록이 표시되는 과정
> **순서**: ① 메모 점이 있는 날짜 클릭 → ② 해당 날짜가 선택 표시됨 → ③ 아래에 메모/할 일 목록이 나타남
> **화면 영역**: 오른쪽 패널 전체 (캘린더 + 아래 메모 목록 영역)
> **강조**: 날짜 클릭 후 아래 영역에 메모 목록이 펼쳐지는 순간
> **길이**: 3~5초

---

## 메모 / 할 일 탭

선택한 날짜의 항목은 두 가지 탭으로 나뉩니다.

| 탭 | 내용 | 표시 형태 |
|----|------|----------|
| **📝 메모** | 해당 날짜에 작성된 코멘트 | 텍스트 메시지 목록 |
| **✅ 할 일** | 해당 날짜의 체크리스트 항목 | 체크박스 목록 |

각 탭 옆에는 오늘 날짜의 **항목 수 배지**가 표시되어, 오늘 할 일이 몇 개인지 바로 확인할 수 있습니다.

> 📸 **여기에 GIF** — `images/calendar-tabs.gif`
>
> **촬영**: 메모 탭과 할 일 탭을 전환하며 배지 숫자를 확인하는 과정
> **순서**: ① 📝 메모 탭 클릭 → 메모 목록 표시 → ② ✅ 할 일 탭 클릭 → 체크박스 목록 표시 → ③ 각 탭 옆의 배지 숫자 확인
> **화면 영역**: 오른쪽 패널 하단 (탭 바 + 목록 영역)
> **강조**: 탭 전환 시 내용이 바뀌는 순간, 탭 옆의 배지 숫자
> **길이**: 5~8초

## 메모 동작

캘린더의 메모 항목으로 다양한 작업을 할 수 있습니다.

| 동작 | 설명 |
|------|------|
| **메모 클릭** | 해당 메모가 포함된 노트가 호버 윈도우로 열립니다 |
| **체크 표시** | 메모나 할 일의 완료 상태를 체크/해제할 수 있습니다 |

> 📸 **여기에 GIF** — `images/calendar-open-note.gif`
>
> **촬영**: 캘린더 메모 항목을 클릭하여 해당 노트가 호버 윈도우로 열리는 과정
> **순서**: ① 메모 목록에서 특정 메모 항목 클릭 → ② 호버 윈도우가 나타남 → ③ 해당 메모가 포함된 노트 내용이 표시됨
> **화면 영역**: 전체 화면 (오른쪽 패널의 메모 클릭 + 중앙에 나타나는 호버 윈도우)
> **강조**: 메모 클릭 후 호버 윈도우가 팝업되는 순간
> **길이**: 3~5초

> 📸 **여기에 GIF** — `images/calendar-check-memo.gif`
>
> **촬영**: 할 일 탭에서 체크박스를 클릭하여 완료/미완료 상태를 전환하는 과정
> **순서**: ① 할 일 탭의 체크박스 클릭하여 완료 표시 → ② 취소선이 생기거나 스타일 변경 → ③ 다시 클릭하여 미완료로 되돌리기
> **화면 영역**: 오른쪽 패널 하단 (할 일 목록 영역)
> **강조**: 체크박스 클릭 시 완료 스타일 변경 (취소선, 색상 변화 등)
> **길이**: 3~5초

## 접힌 바의 캘린더 배지

오른쪽 패널이 접혀 있을 때, 캘린더 버튼에 **오늘의 메모/할 일 수**가 배지로 표시됩니다. 패널을 열지 않아도 오늘 일정을 빠르게 확인할 수 있습니다.

> 📸 **여기에 GIF** — `images/calendar-badge.gif`
>
> **촬영**: 오른쪽 패널이 접힌 상태에서 캘린더 버튼의 배지 숫자를 보여주는 장면
> **순서**: ① 오른쪽 패널이 접힌 상태를 보여줌 → ② 캘린더 아이콘 옆의 배지 숫자에 주목 → ③ 배지를 클릭하여 패널 열기
> **화면 영역**: 화면 오른쪽 가장자리 (접힌 바 영역만)
> **강조**: 캘린더 아이콘 옆에 표시되는 배지 숫자
> **길이**: 3~5초

## 활용 예시

캘린더를 이렇게 활용해보세요.

| 활용 방법 | 설명 |
|-----------|------|
| **일일 기록** | 매일의 작업 내용이나 생각을 코멘트로 남기면 캘린더에서 날짜별로 되돌아볼 수 있습니다 |
| **프로젝트 마감일** | 프로젝트 노트에 마감일 코멘트를 추가하면 캘린더에서 일정을 확인할 수 있습니다 |
| **회의 일정** | 회의록 노트에 날짜 코멘트를 남기면 캘린더에서 회의 스케줄을 한눈에 볼 수 있습니다 |
| **일일 회고** | 하루가 끝날 때 캘린더에서 오늘 작성한 메모를 돌아보며 정리합니다 |
| **할 일 관리** | 체크리스트를 활용해 오늘 해야 할 작업을 관리합니다 |

> **💡 팁**: 노트에 코멘트를 추가할 때 날짜를 지정하면 캘린더에 자동으로 연결됩니다. 자세한 내용은 [에디터 고급](에디터-고급) 페이지를 참고하세요.
