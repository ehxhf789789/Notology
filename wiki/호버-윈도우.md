# <img src="images/icons/app-window.png" width="24" height="24"> 호버 윈도우

메인 에디터 위에 떠다니는 작은 창입니다. 글을 쓰면서 다른 노트를 동시에 참고할 수 있습니다.

---

## 핵심 개념

**호버 윈도우**는 메인 에디터 위에 떠다니는 별도의 창입니다. 쉽게 말해 "참고용 메모지를 책 위에 올려놓는 것"과 같습니다.

- 메인 에디터에서 글을 쓰면서 다른 노트를 참고할 수 있습니다
- 여러 개의 호버 윈도우를 동시에 열 수 있습니다
- 마크다운 노트뿐만 아니라 PDF, 이미지, Office 문서도 볼 수 있습니다

> 📸 **여기에 GIF** — `images/hover-window-concept.gif`
>
> **촬영**: 메인 에디터 위에 호버 윈도우가 떠 있는 기본 모습 보여주기
> **순서**: ① 메인 에디터에 노트가 열려 있음 → ② 호버 윈도우가 위에 떠 있음 → ③ 메인 에디터 클릭해서 글 쓰기 → ④ 호버 윈도우 클릭해서 내용 확인
> **화면 영역**: 앱 전체 화면
> **강조**: 메인 에디터와 호버 윈도우가 동시에 보이는 모습
> **길이**: 5~8초

---

## 호버 윈도우 열기

호버 윈도우를 여는 방법은 여러 가지입니다.

| 이렇게 하면 | 호버 윈도우가 열립니다 |
|------------|---------------------|
| `[[위키링크]]` 클릭 | 노트 안의 위키링크를 클릭합니다 |
| 사이드바 더블클릭 | 파일 탐색기에서 노트를 더블클릭합니다 |
| 검색 결과 클릭 | 검색 결과에서 항목을 클릭합니다 |
| 캘린더 메모 클릭 | 오른쪽 패널의 캘린더에서 메모를 클릭합니다 |
| 우클릭 → "호버로 열기" | 사이드바에서 노트를 우클릭해서 선택합니다 |

> 📸 **여기에 GIF** — `images/hover-open-wikilink.gif`
>
> **촬영**: 에디터 안의 위키링크를 클릭해서 호버 윈도우를 여는 과정
> **순서**: ① 에디터에서 [[노트이름]] 위키링크가 보임 → ② 위키링크 클릭 → ③ 호버 윈도우가 열리면서 해당 노트 내용 표시
> **화면 영역**: 에디터 영역 + 호버 윈도우
> **강조**: 위키링크 클릭 순간과 호버 윈도우가 나타나는 순간
> **길이**: 3~5초

> 📸 **여기에 GIF** — `images/hover-open-methods.gif`
>
> **촬영**: 사이드바 더블클릭, 우클릭 메뉴 등 다른 방법으로 호버 윈도우 여는 모습
> **순서**: ① 사이드바에서 노트 더블클릭 → ② 호버 윈도우 열림 → ③ 닫기 → ④ 노트 우클릭 → ⑤ "호버로 열기" 선택 → ⑥ 호버 윈도우 열림
> **화면 영역**: 사이드바 + 에디터 영역
> **강조**: 더블클릭과 우클릭 메뉴의 "호버로 열기" 항목
> **길이**: 5~8초

## 창 조작하기

### 이동하기

호버 윈도우의 위쪽 타이틀 바를 마우스로 잡고 끌면(드래그) 원하는 위치로 옮길 수 있습니다.

> 📸 **여기에 GIF** — `images/hover-move.gif`
>
> **촬영**: 호버 윈도우의 타이틀 바를 드래그해서 이동하는 모습
> **순서**: ① 호버 윈도우가 화면 중앙에 있음 → ② 타이틀 바 드래그 시작 → ③ 왼쪽으로 이동 → ④ 오른쪽 아래로 이동 → ⑤ 마우스 놓기
> **화면 영역**: 앱 전체 화면
> **강조**: 마우스 커서가 타이틀 바를 잡는 순간
> **길이**: 3~5초

### 크기 조절하기

창의 모서리나 가장자리를 마우스로 잡고 끌면 크기를 바꿀 수 있습니다.

### 크기 프리셋

미리 정해진 크기로 빠르게 바꿀 수 있습니다.

| 프리셋 | 크기 (너비 x 높이) | 이럴 때 쓰면 좋아요 |
|--------|-------------------|-------------------|
| **Small** | 600 x 500 | 짧은 메모 확인할 때 |
| **Medium** | 800 x 600 | 일반적인 노트 볼 때 |
| **Large** | 1000 x 800 | 긴 문서 편집할 때 |
| **Wide** | 1200 x 700 | 표나 코드가 많은 노트 볼 때 |

> 📸 **여기에 GIF** — `images/hover-resize.gif`
>
> **촬영**: 호버 윈도우의 모서리를 드래그해서 크기를 바꾸고, 프리셋 버튼으로 크기를 변경하는 모습
> **순서**: ① 호버 윈도우 모서리 드래그로 크기 조절 → ② 프리셋 버튼 클릭 → ③ "Small" 선택 → ④ 프리셋 버튼 클릭 → ⑤ "Large" 선택
> **화면 영역**: 호버 윈도우 중심 (앱 전체 화면)
> **강조**: 크기가 바뀌는 애니메이션
> **길이**: 5~8초

## 여러 창 관리

### 동시에 여러 노트 열기

호버 윈도우는 여러 개를 동시에 열 수 있습니다. 각 창은 따로따로 움직이고 크기를 바꿀 수 있습니다.

> 📸 **여기에 GIF** — `images/hover-multiple.gif`
>
> **촬영**: 호버 윈도우 2~3개를 동시에 열어서 화면에 배치하는 모습
> **순서**: ① 첫 번째 호버 윈도우 열기 → ② 두 번째 호버 윈도우 열기 → ③ 각각 다른 위치로 이동 → ④ 세 번째 호버 윈도우 열기
> **화면 영역**: 앱 전체 화면
> **강조**: 여러 창이 동시에 떠 있는 모습
> **길이**: 5~8초

### 최소화

호버 윈도우를 최소화하면 화면 오른쪽에 작은 버튼으로 줄어듭니다. 그 버튼을 다시 클릭하면 펼쳐집니다.

- 여러 창을 열어놓고 필요할 때만 꺼내 쓸 수 있습니다
- 최소화된 버튼에는 노트 이름이 표시됩니다

> 📸 **여기에 GIF** — `images/hover-minimize.gif`
>
> **촬영**: 호버 윈도우를 최소화하고 다시 복원하는 과정
> **순서**: ① 호버 윈도우 열려 있음 → ② 최소화 버튼 클릭 → ③ 오른쪽에 작은 버튼으로 줄어듦 → ④ 작은 버튼 클릭 → ⑤ 호버 윈도우 다시 펼쳐짐
> **화면 영역**: 앱 전체 화면 (오른쪽 최소화 바 포함)
> **강조**: 최소화 버튼과 오른쪽의 작은 복원 버튼
> **길이**: 3~5초

> 📸 **여기에 GIF** — `images/hover-collapsed-bar.gif`
>
> **촬영**: 여러 호버 윈도우가 최소화된 상태에서 하나씩 복원하는 모습
> **순서**: ① 3개 이상의 호버 윈도우가 모두 최소화됨 → ② 오른쪽에 여러 버튼 나열 → ③ 하나 클릭해서 복원 → ④ 다른 하나 클릭해서 복원
> **화면 영역**: 앱 전체 화면 (오른쪽 최소화 바에 포커스)
> **강조**: 최소화된 버튼들에 노트 이름이 표시되는 모습
> **길이**: 5~8초

## 파일 유형별 뷰어

호버 윈도우는 파일 종류에 따라 자동으로 적절한 뷰어를 선택합니다.

| 파일 종류 | 확장자 | 어떻게 보여주나요? |
|----------|--------|-----------------|
| **마크다운 노트** | `.md` | 편집 가능한 에디터로 열림 |
| **PDF** | `.pdf` | PDF 뷰어로 열림 |
| **이미지** | `.png`, `.jpg`, `.gif` 등 | 이미지 뷰어로 열림 |
| **Office 문서** | `.docx`, `.xlsx`, `.pptx`, `.hwpx` | 문서 미리보기로 열림 (LibreOffice 필요) |
| **코드 파일** | `.js`, `.py`, `.rs` 등 | 구문 강조 뷰어로 열림 |

> 📸 **여기에 GIF** — `images/hover-file-types.gif`
>
> **촬영**: 여러 종류의 파일을 호버 윈도우로 하나씩 열어보는 모습
> **순서**: ① .md 노트 열기 (편집 가능) → ② .pdf 파일 열기 (PDF 뷰어) → ③ .png 이미지 열기 (이미지 뷰어) → ④ .docx 파일 열기 (문서 미리보기)
> **화면 영역**: 앱 전체 화면 (호버 윈도우에 포커스)
> **강조**: 각 파일 유형에 따라 다른 뷰어가 나타나는 모습
> **길이**: 8~12초

> **💡 참고**: Office 문서(.docx 등) 미리보기를 쓰려면 컴퓨터에 LibreOffice가 설치되어 있어야 합니다. 설치가 안 되어 있으면 "앱에서 열기" 버튼으로 기본 프로그램(예: Word, 한글)에서 열 수 있습니다.

- 같은 노트를 다시 열면 바로 나타납니다 (기다릴 필요 없음)
- 앱을 종료하면 캐시가 사라집니다

## 활용 팁

### 참고하면서 글쓰기

메인 에디터에서 글을 쓰면서 호버 윈도우로 참고 자료를 띄워두세요.

1. 메인 에디터에서 작성할 노트를 엽니다
2. 사이드바에서 참고할 노트를 **더블클릭**해서 호버 윈도우로 엽니다
3. 호버 윈도우를 화면 한쪽에 놓습니다
4. 호버 윈도우 내용을 보면서 메인 에디터에서 글을 씁니다

### 노트 비교

두 개의 호버 윈도우를 나란히 놓고 노트를 비교할 수 있습니다.

> 📸 **여기에 GIF** — `images/hover-workflow-tips.gif`
>
> **촬영**: 메인 에디터에서 글을 쓰면서 호버 윈도우로 참고 자료를 보는 실제 워크플로우
> **순서**: ① 메인 에디터에 작성 중인 노트 → ② 사이드바에서 참고 노트 더블클릭 → ③ 호버 윈도우 열림 → ④ 호버 윈도우를 오른쪽으로 이동 → ⑤ 호버 윈도우 내용을 보면서 메인 에디터에 타이핑
> **화면 영역**: 앱 전체 화면
> **강조**: 메인 에디터와 호버 윈도우를 번갈아 사용하는 흐름
> **길이**: 8~12초
