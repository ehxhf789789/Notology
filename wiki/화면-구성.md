# <img src="images/icons/layout.png" width="24" height="24"> 화면 구성

Notology 앱을 열면 보이는 화면의 각 부분이 무엇인지 알아봅니다.

---

## 전체 레이아웃

Notology는 크게 **3개 영역**으로 나뉘어 있습니다.

```
┌──────────────────────────────────────────────────┐
│                    타이틀 바                       │
├──────────┬─────────────────────┬─────────────────┤
│          │                     │                 │
│ 사이드바  │      에디터 영역      │   오른쪽 패널   │
│          │                     │                 │
│ · 파일   │  · 도구 모음(툴바)    │  · 캘린더      │
│   탐색기  │  · 노트 편집 공간     │  · 메모 목록   │
│ · 컨테이너│  · 자동 저장         │  · 백링크      │
│ · 검색   │                     │                 │
│ · 설정   │                     │                 │
│          │                     │                 │
├──────────┴─────────────────────┴─────────────────┤
│                    상태 바                        │
└──────────────────────────────────────────────────┘
```

- **사이드바 (왼쪽)**: 내 파일과 폴더를 보고 관리하는 곳
- **에디터 영역 (가운데)**: 노트를 쓰고 편집하는 메인 공간
- **오른쪽 패널**: 캘린더, 메모, 백링크 등 부가 정보를 보여주는 곳

> 📸 **여기에 스크린샷** — `images/interface-overview.png`
>
> **촬영**: Notology 앱 전체 화면 — 3개 영역이 모두 보이는 상태
> **내용**: 사이드바에 폴더/노트가 보이고, 에디터에 노트 내용이 있고, 오른쪽에 캘린더가 표시된 상태
> **화면 영역**: 앱 전체 화면 캡처

## 사이드바 (왼쪽)

사이드바는 내 파일을 찾아다니고 관리하는 곳입니다. Windows 탐색기와 비슷합니다.

| 구성 요소 | 하는 일 |
|----------|---------|
| Vault 선택기 | 지금 쓰고 있는 Vault를 확인하고, 다른 Vault로 바꿀 수 있습니다 |
| 파일 탐색기 | 폴더와 노트를 트리 구조로 보여줍니다 |
| 하단 버튼 | 새 노트 만들기(+), 검색, 설정 버튼이 있습니다 |

> 📸 **여기에 GIF** — `images/sidebar-toggle.gif`
>
> **촬영**: Ctrl+← 단축키로 사이드바를 열고 닫는 모습
> **순서**: ① 사이드바가 열린 상태 → ② Ctrl+← 누르기 → ③ 사이드바가 접힘 (에디터가 넓어짐) → ④ 다시 Ctrl+← 누르기 → ⑤ 사이드바가 다시 열림
> **화면 영역**: 앱 전체 화면 (사이드바 영역 변화가 보이도록)
> **강조**: 사이드바가 열리고 닫힐 때 에디터 영역이 넓어지는 모습
> **길이**: 3~5초

> 📸 **여기에 GIF** — `images/sidebar-folder-tree.gif`
>
> **촬영**: 사이드바에서 폴더를 열고 닫으며 노트를 탐색하는 모습
> **순서**: ① 폴더 클릭해서 펼치기 → ② 하위 노트 확인 → ③ 다른 폴더 펼치기 → ④ 노트 클릭해서 에디터에 열기
> **화면 영역**: 사이드바 영역 중심 (에디터 일부 포함)
> **강조**: 폴더 화살표 클릭과 노트가 에디터에 열리는 순간
> **길이**: 5~8초

자세한 내용은 [사이드바](사이드바) 페이지에서 확인하세요.

## 에디터 영역 (가운데)

노트를 쓰고 편집하는 메인 공간입니다.

### 도구 모음 (툴바)

에디터 위쪽에 있는 버튼 줄입니다. 클릭 한 번으로 글꼴이나 서식을 바꿀 수 있습니다.

- 텍스트 꾸미기 (굵게, 기울임, 밑줄 등)
- 제목 크기 고르기 (H1 ~ H6)
- 목록 만들기 (글머리 기호, 번호, 체크리스트)
- 표, 이미지, 코드 블록 넣기
- 텍스트 정렬, 콜아웃(색상 상자) 넣기

> 📸 **여기에 GIF** — `images/toolbar-toggle.gif`
>
> **촬영**: 도구 모음에서 여러 서식 버튼을 클릭해보는 모습
> **순서**: ① 텍스트 선택 → ② 굵게(B) 버튼 클릭 → ③ 기울임(I) 버튼 클릭 → ④ 제목(H) 드롭다운 열기 → ⑤ H2 선택
> **화면 영역**: 에디터 상단 도구 모음 + 에디터 본문 상단 부분
> **강조**: 각 버튼 클릭 시 텍스트에 서식이 적용되는 모습
> **길이**: 5~8초

### 편집 공간

마크다운 기반 실시간 편집기입니다. 마크다운 문법을 입력하면 바로 서식이 적용되어 보입니다. 예를 들어 `# 제목`을 입력하면 큰 제목 글씨가 됩니다.

## 오른쪽 패널

캘린더와 부가 정보를 보여주는 곳입니다.

| 구성 요소 | 하는 일 |
|----------|---------|
| 캘린더 | 달력이 표시됩니다. 날짜를 클릭하면 그 날 쓴 메모를 볼 수 있습니다 |
| 메모 목록 | 선택한 날짜에 추가한 인라인 메모(코멘트)가 표시됩니다 |
| 백링크 | 지금 보고 있는 노트를 참조하는 다른 노트 목록이 표시됩니다 |

> 📸 **여기에 GIF** — `images/right-panel.gif`
>
> **촬영**: 오른쪽 패널에서 캘린더 날짜를 클릭하고 메모를 확인하는 과정
> **순서**: ① 오른쪽 패널의 캘린더 보기 → ② 메모가 있는 날짜 클릭 → ③ 메모 목록 확인 → ④ 메모 클릭해서 해당 노트로 이동
> **화면 영역**: 오른쪽 패널 영역만
> **강조**: 날짜 클릭 시 메모 목록이 나타나는 순간
> **길이**: 5~8초

---

## 호버 윈도우 (떠다니는 창)

메인 에디터 위에 떠다니는 작은 창입니다. 글을 쓰면서 다른 노트를 동시에 열어볼 수 있어서 매우 편리합니다.

> 📸 **여기에 GIF** — `images/hover-window-intro.gif`
>
> **촬영**: 메인 에디터 위에 호버 윈도우가 뜨는 기본 동작
> **순서**: ① 메인 에디터에서 위키링크([[...]]) 클릭 → ② 호버 윈도우가 뜸 → ③ 호버 윈도우에서 내용 확인 → ④ 호버 윈도우 닫기
> **화면 영역**: 앱 전체 화면
> **강조**: 호버 윈도우가 메인 에디터 위에 떠 있는 모습
> **길이**: 5~8초

자세한 내용은 [호버 윈도우](호버-윈도우) 페이지에서 확인하세요.

## 타이틀 바

앱 맨 위쪽 바입니다.

- 지금 열려 있는 노트의 이름이 표시됩니다
- 창 최소화, 최대화, 닫기 버튼이 있습니다
- 타이틀 바를 드래그하면 앱 창을 이동할 수 있습니다

## 자주 쓰는 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl + N` | 새 노트 만들기 |
| `Ctrl + Shift + F` | 검색 열기 |
| `Ctrl + ←` | 사이드바 열기/닫기 |
| `Ctrl + 마우스 휠` | 에디터 확대/축소 |
| `Ctrl + B` | 글씨 굵게 |
| `Ctrl + I` | 글씨 기울임 |
| `Ctrl + Z` | 실행 취소 (되돌리기) |
| `Ctrl + Shift + Z` | 다시 실행 |

더 많은 단축키는 [에디터 기본](에디터-기본) 페이지에서 확인하세요.
