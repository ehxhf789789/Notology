# <img src="images/icons/share-2.png" width="24" height="24"> 그래프 뷰

노트끼리 어떻게 연결되어 있는지를 **네트워크 그래프**로 보여줍니다. 어떤 노트가 서로 이어져 있는지 한눈에 확인할 수 있어요.

---

## 그래프 뷰 열기

사이드바 하단의 **그래프 뷰** 버튼을 클릭하면 전체 화면 그래프가 열립니다.

> 📸 **여기에 GIF** — `images/graph-open.gif`
>
> **촬영**: 사이드바에서 그래프 뷰 버튼을 클릭해 그래프 화면을 여는 과정
> **순서**: ① 사이드바 하단의 그래프 뷰 버튼에 커서 이동 → ② 클릭 → ③ 전체 화면 그래프가 나타남
> **화면 영역**: 전체 화면 (사이드바 + 메인 영역 전환 과정 포함)
> **강조**: 사이드바 하단의 그래프 뷰 버튼 위치
> **길이**: 3~5초

---

## 개념

그래프 뷰는 **힘-기반 배치(force-directed)** 방식으로 노트 관계를 그림으로 보여줍니다. 연결이 많은 노트는 중앙에, 적은 노트는 바깥쪽에 자연스럽게 놓입니다.

- 노트를 많이 연결할수록 그래프가 풍성해집니다
- 위키링크(`[[노트]]`)로 연결한 관계가 선으로 표시됩니다
- 태그, 첨부파일, 폴더 관계도 함께 볼 수 있습니다

---

## 노드 유형

그래프에서 각 항목은 **노드**로 표시되며, 유형에 따라 모양이 다릅니다.

| 모양 | 유형 | 설명 |
|------|------|------|
| ⬤ 원형 | **노트** | 연결이 많을수록 원이 커집니다 |
| ◆ 마름모 | **태그** | 해당 태그를 가진 모든 노트와 연결됩니다 |
| ▢ 둥근 사각형 | **첨부파일** | 노트에 첨부된 파일입니다 |
| 📁 폴더 | **폴더** | 노트를 담고 있는 폴더입니다 |

> 📸 **여기에 GIF** — `images/graph-node-types.gif`
>
> **촬영**: 그래프 위에서 서로 다른 유형의 노드(원, 마름모, 사각형, 폴더)에 마우스를 올려 차이를 보여주기
> **순서**: ① 노트 노드(원)에 호버 → ② 태그 노드(마름모)에 호버 → ③ 첨부파일 노드(사각형)에 호버 → ④ 폴더 노드에 호버
> **화면 영역**: 그래프 메인 영역 (노드들이 잘 보이도록 적당히 줌인)
> **강조**: 각 노드의 모양 차이와 호버 시 표시되는 라벨
> **길이**: 5~8초

---

## 엣지(연결선) 유형

노드 사이의 연결선도 관계에 따라 다르게 표시됩니다.

| 선 스타일 | 관계 | 설명 |
|-----------|------|------|
| **실선 화살표** ─→ | 위키링크 | `[[노트]]`로 직접 연결한 관계 |
| **점선** ┄┄ | 태그 | 같은 태그를 공유하는 관계 |
| **실선** ── | 첨부파일 | 노트에 첨부된 파일 관계 |
| **점선(얇은)** ····· | 포함 | 폴더가 노트를 포함하는 관계 |

## 마우스 조작

그래프는 마우스로 자유롭게 탐색할 수 있습니다.

| 동작 | 조작 방법 |
|------|----------|
| **화면 이동** | 빈 공간을 드래그합니다 |
| **확대/축소** | 마우스 휠을 위아래로 굴립니다 |
| **노드 강조** | 노드 위에 마우스를 올리면 연결된 노드가 하이라이트됩니다 |
| **노드 선택** | 노드를 한 번 클릭합니다 |
| **노트 열기** | 노드를 더블클릭하면 해당 노트가 열립니다 |
| **노드 고정/해제** | 노드를 우클릭하면 현재 위치에 고정(pin)하거나 해제합니다 |

> 📸 **여기에 GIF** — `images/graph-interaction.gif`
>
> **촬영**: 그래프에서 이동, 줌, 호버 강조, 더블클릭으로 노트 여는 일련의 조작 시연
> **순서**: ① 빈 공간 드래그로 화면 이동 → ② 마우스 휠로 줌 인/아웃 → ③ 노드에 호버해서 연결 하이라이트 → ④ 노드 더블클릭으로 노트 열기
> **화면 영역**: 그래프 메인 영역 전체
> **강조**: 호버 시 연결된 노드가 밝아지는 하이라이트 효과, 더블클릭 후 노트가 열리는 순간
> **길이**: 8~12초

> 📸 **여기에 GIF** — `images/graph-pin-node.gif`
>
> **촬영**: 노드를 우클릭하여 위치를 고정(pin)하고, 다시 우클릭하여 해제하는 과정
> **순서**: ① 노드 위에서 우클릭 → ② 노드가 고정됨 (핀 아이콘 또는 시각 표시) → ③ 다른 노드를 드래그해서 그래프가 움직여도 고정 노드는 제자리 유지 → ④ 고정 노드를 다시 우클릭하여 해제
> **화면 영역**: 그래프 메인 영역 (고정할 노드 주변 줌인)
> **강조**: 고정된 노드가 다른 노드와 달리 움직이지 않는 모습
> **길이**: 5~8초

## 그래프 검색

그래프 상단의 **검색 상자**에 노트 이름을 입력하면 해당 노드를 빠르게 찾을 수 있습니다.

1. 검색 상자에 키워드를 입력합니다
2. 일치하는 노드가 **빛나는 효과**로 강조됩니다
3. 화면이 해당 노드를 중심으로 **자동 이동**합니다

> 📸 **여기에 GIF** — `images/graph-search.gif`
>
> **촬영**: 그래프 검색 상자에 키워드를 입력하여 노드를 찾는 과정
> **순서**: ① 그래프 상단의 검색 상자 클릭 → ② 노트 이름 키워드 입력 → ③ 일치하는 노드가 빛나는 효과로 강조됨 → ④ 화면이 해당 노드로 자동 이동(센터링)
> **화면 영역**: 전체 그래프 화면 (상단 검색 상자 + 그래프 영역 모두 포함)
> **강조**: 검색 결과 노드의 빛나는 하이라이트 효과와 자동 센터링
> **길이**: 5~8초

## 설정 패널

그래프 우측의 설정 패널에서 표시 옵션과 물리 엔진을 조절할 수 있습니다.

### 표시 옵션

| 설정 | 설명 |
|------|------|
| **태그 표시** | 태그 노드(마름모)를 보이거나 숨깁니다 |
| **첨부파일 표시** | 첨부파일 노드를 보이거나 숨깁니다 |

### 물리 엔진 설정

| 설정 | 설명 |
|------|------|
| **전하(Charge)** | 노드 간 밀어내는 힘입니다. 값이 클수록 노드가 멀리 떨어집니다 |
| **연결 거리(Link Distance)** | 연결된 노드 사이의 기본 거리입니다 |
| **중심 강도(Center Strength)** | 노드를 화면 중앙으로 끌어당기는 힘입니다 |
| **초기화** | 모든 물리 설정을 기본값으로 되돌립니다 |

> 📸 **여기에 GIF** — `images/graph-settings.gif`
>
> **촬영**: 그래프 설정 패널에서 태그 표시/숨김 토글과 물리 엔진 슬라이더 조절 시연
> **순서**: ① 우측 설정 패널 열기 → ② 태그 표시 토글 OFF → 마름모 노드 사라짐 → ③ 태그 표시 토글 ON → 마름모 노드 다시 나타남 → ④ 전하(Charge) 슬라이더 조절 → 노드 간격 변화 → ⑤ 초기화 버튼 클릭
> **화면 영역**: 그래프 메인 영역 + 우측 설정 패널
> **강조**: 토글 전환 시 그래프가 실시간으로 변하는 모습, 슬라이더 조절 시 노드 재배치 애니메이션
> **길이**: 8~12초

## 정보 바 & 범례

그래프 하단에는 현재 그래프의 통계와 범례가 표시됩니다.

### 정보 바

| 항목 | 설명 |
|------|------|
| **노트 수** | 그래프에 표시된 총 노트 개수 |
| **태그 수** | 그래프에 표시된 총 태그 개수 |
| **첨부파일 수** | 그래프에 표시된 총 첨부파일 개수 |
| **연결 수** | 노드 간 총 연결선 개수 |

### 범례 바

그래프 하단에 각 노드 유형의 색상과 모양을 설명하는 범례가 표시됩니다.

> 📸 **여기에 스크린샷** — `images/graph-legend.png`
>
> **촬영**: 그래프 하단의 정보 바와 범례 바
> **내용**: 노트 수, 태그 수, 첨부파일 수, 연결 수가 숫자로 표시된 정보 바 + 노드 유형별 색상/모양 범례가 보이는 상태
> **화면 영역**: 그래프 화면 하단 바 영역만 (하단 약 15% 정도)

## 활용 팁

| 팁 | 설명 |
|----|------|
| 허브 노트 찾기 | 가장 큰 원(노드)이 가장 많이 연결된 핵심 노트입니다 |
| 고립된 노트 확인 | 바깥에 혼자 있는 노트는 다른 노트와 연결이 없습니다. 위키링크를 추가해보세요 |
| 클러스터 발견 | 모여 있는 노드 그룹은 관련 주제의 묶음입니다 |
| 태그 활용 | 태그 표시를 켜면 어떤 노트들이 같은 분류에 속하는지 쉽게 파악됩니다 |
