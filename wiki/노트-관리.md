# <img src="images/icons/file-text.png" width="24" height="24"> 노트 관리

노트를 만들고, 열고, 이름을 바꾸고, 옮기고, 삭제하는 방법을 알아봅니다.

---

## 노트 만들기

새 노트를 만드는 방법은 세 가지입니다.

| 방법 | 설명 |
|------|------|
| `Ctrl + N` | 단축키로 가장 빠르게 만들 수 있습니다 |
| 사이드바 **+ 버튼** | 사이드바 아래쪽의 + 버튼을 클릭합니다 |
| 폴더 우클릭 → 새 노트 | 특정 폴더 안에 노트를 만들 수 있습니다 |

> 📸 **여기에 GIF** — `images/note-create-shortcut.gif`
>
> **촬영**: Ctrl+N 단축키로 새 노트를 만드는 과정
> **순서**: ① Ctrl+N 누르기 → ② 새 노트 다이얼로그 나타남 → ③ 이름 입력 → ④ 템플릿 선택 → ⑤ 확인 → ⑥ 에디터에 새 노트 열림
> **화면 영역**: 앱 전체 화면 (다이얼로그에 포커스)
> **강조**: 단축키 사용과 다이얼로그가 나타나는 순간
> **길이**: 5~8초

> 📸 **여기에 GIF** — `images/note-create-contextmenu.gif`
>
> **촬영**: 폴더 우클릭 메뉴에서 새 노트를 만드는 과정
> **순서**: ① 사이드바에서 폴더 우클릭 → ② "새 노트" 선택 → ③ 이름 입력 → ④ 확인 → ⑤ 해당 폴더 안에 노트 생성됨
> **화면 영역**: 사이드바 영역 (컨텍스트 메뉴 포함)
> **강조**: 우클릭 메뉴의 "새 노트" 항목
> **길이**: 5~8초

## 템플릿 선택

노트를 만들 때 용도에 맞는 틀(템플릿)을 고를 수 있습니다. 템플릿을 쓰면 기본 구조가 미리 잡혀 있어서 편리합니다.

| 템플릿 | 어떤 건가요? | 이럴 때 쓰세요 |
|--------|------------|--------------|
| **노트** | 아무것도 없는 빈 노트 | 일반 메모, 아이디어 |
| **스케치** | 무한 캔버스 (자유 화면) | 다이어그램, 마인드맵 |
| **회의록** | 회의 정보/의제 구조 | 팀 회의, 미팅 |
| **세미나** | 발표자/주제/요약 구조 | 세미나, 강의 노트 |
| **이벤트** | 일시/장소/참석자 구조 | 행사, 일정 |
| **공문서** | 발신/수신/본문 구조 | 공식 문서 |
| **논문** | 초록/서론/방법/결과 구조 | 학술 논문 정리 |
| **문헌** | 저자/출판/인용 구조 | 참고문헌, 서적 |
| **데이터** | 키-값 데이터 구조 | 데이터 카드 |
| **이론** | 정의/설명/예시 구조 | 개념 정리, 학습 |
| **연락처** | 이름/전화/이메일 구조 | 인물 정보 |
| **설정** | 설정 항목 구조 | 환경 설정, 규칙 |

## 노트 열기

저장된 노트를 여는 방법입니다.

| 이렇게 하면 | 어디서 열리나요? |
|------------|----------------|
| 사이드바에서 클릭 | 메인 에디터에서 열림 |
| 사이드바에서 더블클릭 | 호버 윈도우로 열림 |
| 검색 결과에서 클릭 | 호버 윈도우로 열림 |
| `[[위키링크]]` 클릭 | 호버 윈도우로 열림 |
| 캘린더 메모 클릭 | 호버 윈도우로 열림 |

> 📸 **여기에 GIF** — `images/note-open-methods.gif`
>
> **촬영**: 노트를 여는 여러 방법을 순서대로 보여주기
> **순서**: ① 사이드바에서 노트 클릭 (에디터에 열림) → ② 다른 노트 더블클릭 (호버 윈도우로 열림) → ③ 위키링크 클릭 (호버 윈도우로 열림)
> **화면 영역**: 사이드바 + 에디터 + 호버 윈도우
> **강조**: 클릭/더블클릭에 따라 열리는 위치가 다른 것
> **길이**: 8~12초

## 이름 바꾸기

노트 이름을 바꾸면 다른 노트에 있는 **위키링크가 자동으로 바뀝니다**. 하나하나 고칠 필요가 없어요!

1. 사이드바에서 노트를 **우클릭**합니다
2. **이름 바꾸기**를 선택합니다
3. 새 이름을 입력하고 **확인**을 누릅니다
4. Vault 전체에서 `[[이전 이름]]`이 `[[새 이름]]`으로 자동 변경됩니다

> 📸 **여기에 GIF** — `images/note-rename.gif`
>
> **촬영**: 노트 이름을 바꾸고 다른 노트의 위키링크가 자동 업데이트되는 것을 확인하는 과정
> **순서**: ① 사이드바에서 노트 우클릭 → ② "이름 바꾸기" 선택 → ③ 새 이름 입력 → ④ 확인 → ⑤ 다른 노트를 열어서 위키링크가 바뀐 것 확인
> **화면 영역**: 사이드바 + 에디터 영역
> **강조**: 이름 변경 전후의 위키링크 비교
> **길이**: 5~8초

> **💡 팁**: NAS나 클라우드 드라이브로 동기화 중일 때 이름 바꾸기가 실패할 수 있습니다. Notology는 자동으로 3번까지 다시 시도하며, 그래도 안 되면 원래 이름으로 돌려놓습니다.

## 노트 이동

노트를 다른 폴더로 옮기는 방법은 두 가지입니다.

### 드래그 앤 드롭

사이드바에서 노트를 마우스로 잡고 끌어서 원하는 폴더에 놓습니다.

> 📸 **여기에 GIF** — `images/note-move-drag.gif`
>
> **촬영**: 노트를 드래그 앤 드롭으로 다른 폴더로 이동하는 모습
> **순서**: ① 노트를 마우스로 잡기 → ② 다른 폴더 위로 드래그 → ③ 폴더 하이라이트됨 → ④ 마우스 놓기 → ⑤ 노트가 이동됨
> **화면 영역**: 사이드바 영역만
> **강조**: 드래그 중 대상 폴더가 하이라이트되는 모습
> **길이**: 3~5초

### 우클릭 메뉴

1. 노트를 **우클릭**합니다
2. **이동**을 선택합니다
3. 이동할 폴더를 선택합니다

> 📸 **여기에 GIF** — `images/note-move-menu.gif`
>
> **촬영**: 우클릭 메뉴에서 "이동"을 선택해서 노트를 이동하는 과정
> **순서**: ① 노트 우클릭 → ② "이동" 선택 → ③ 폴더 선택 다이얼로그 → ④ 대상 폴더 선택 → ⑤ 확인 → ⑥ 노트 이동 완료
> **화면 영역**: 사이드바 + 폴더 선택 다이얼로그
> **강조**: "이동" 메뉴 항목과 폴더 선택 화면
> **길이**: 5~8초

## 노트 삭제

1. 사이드바에서 노트를 **우클릭**합니다
2. **삭제**를 선택합니다
3. 다른 노트에서 이 노트를 참조하는 위키링크가 있으면 경고 메시지가 나옵니다
4. **확인**을 누르면 삭제됩니다

> 📸 **여기에 GIF** — `images/note-delete.gif`
>
> **촬영**: 노트를 삭제하는 과정 (위키링크 경고 포함)
> **순서**: ① 노트 우클릭 → ② "삭제" 선택 → ③ 위키링크 경고 다이얼로그 나타남 → ④ 확인 클릭 → ⑤ 노트가 사이드바에서 사라짐
> **화면 영역**: 사이드바 + 경고 다이얼로그
> **강조**: 위키링크 경고 메시지 내용
> **길이**: 5~8초

> **주의**: 삭제된 노트는 휴지통에 들어가지 않고 바로 사라집니다. 중요한 노트는 삭제 전에 꼭 확인하세요!

## 폴더 관리

| 할 일 | 방법 |
|-------|------|
| 새 폴더 만들기 | 상위 폴더를 우클릭 → **새 폴더** |
| 폴더 이름 바꾸기 | 폴더를 우클릭 → **이름 바꾸기** |
| 폴더 삭제 | 폴더를 우클릭 → **삭제** (안에 있는 모든 파일도 함께 삭제!) |
| 폴더 이동 | 사이드바에서 드래그 앤 드롭 |

> 📸 **여기에 GIF** — `images/folder-create.gif`
>
> **촬영**: 새 폴더를 만들고 이름을 짓는 과정
> **순서**: ① 상위 폴더 우클릭 → ② "새 폴더" 선택 → ③ 폴더 이름 입력 → ④ 확인 → ⑤ 새 폴더가 트리에 나타남
> **화면 영역**: 사이드바 영역
> **강조**: 새로 만들어진 폴더가 트리에 나타나는 순간
> **길이**: 3~5초

## 파일 작업

| 할 일 | 방법 |
|-------|------|
| 경로 복사 | 노트 우클릭 → **경로 복사** (파일 위치가 클립보드에 복사됩니다) |
| 탐색기에서 열기 | 노트 우클릭 → **탐색기에서 열기** (Windows 탐색기에서 해당 위치를 보여줍니다) |

> 📸 **여기에 GIF** — `images/note-file-actions.gif`
>
> **촬영**: 노트 우클릭으로 경로 복사와 탐색기에서 열기를 사용하는 모습
> **순서**: ① 노트 우클릭 → ② "경로 복사" 클릭 → ③ 다시 우클릭 → ④ "탐색기에서 열기" 클릭 → ⑤ Windows 탐색기가 해당 폴더 위치로 열림
> **화면 영역**: 사이드바 + Windows 탐색기
> **강조**: 각 메뉴 항목 클릭과 결과
> **길이**: 5~8초

## 검색에서 일괄 작업

[검색](검색) 기능에서 여러 노트를 한꺼번에 관리할 수 있습니다.

- **일괄 삭제**: 여러 노트를 선택해서 한 번에 삭제
- **일괄 이동**: 여러 노트를 선택해서 한 번에 다른 폴더로 이동
- **일괄 태그**: 여러 노트에 태그를 한 번에 추가

> 📸 **여기에 GIF** — `images/note-bulk-actions.gif`
>
> **촬영**: 검색 결과에서 여러 노트를 선택하고 일괄 이동하는 과정
> **순서**: ① 검색 창 열기 → ② 키워드 입력 → ③ 체크박스로 여러 노트 선택 → ④ 일괄 이동 버튼 클릭 → ⑤ 대상 폴더 선택 → ⑥ 이동 완료
> **화면 영역**: 검색 화면 전체
> **강조**: 체크박스 선택과 일괄 작업 버튼
> **길이**: 8~12초

자세한 내용은 [검색](검색) 페이지에서 확인하세요.
