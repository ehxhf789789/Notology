# <img src="images/icons/search.png" width="24" height="24"> 검색

원하는 노트를 빠르게 찾고, 조건을 걸어 좁히고, 여러 노트를 한꺼번에 관리하는 방법을 알아봅니다.

---

## 검색 열기

| 방법 | 설명 |
|------|------|
| `Ctrl + Shift + F` | 단축키로 바로 열 수 있습니다 (가장 빠름) |
| 사이드바 검색 버튼 | 사이드바 아래쪽의 돋보기 아이콘을 클릭합니다 |

> 📸 **여기에 GIF** — `images/search-open.gif`
>
> **촬영**: Ctrl+Shift+F 단축키로 검색 창을 여는 과정
> **순서**: ① 에디터에서 작업 중 → ② Ctrl+Shift+F 누르기 → ③ 검색 창이 열림 → ④ 커서가 검색 입력란에 위치
> **화면 영역**: 앱 전체 화면 (검색 창 전환)
> **강조**: 검색 창이 열리면서 입력란에 포커스가 가는 순간
> **길이**: 3~5초

---

## 기본 검색

검색창에 단어를 입력하면 **입력하는 즉시 결과가 나타납니다**.

- 한 글자씩 입력할 때마다 결과가 바뀝니다
- 검색어가 있는 부분이 **노란색으로 강조**됩니다
- 노트 제목과 본문 모두에서 찾습니다

> 📸 **여기에 GIF** — `images/search-basic.gif`
>
> **촬영**: 검색창에 키워드를 입력하면서 실시간으로 결과가 나타나는 모습
> **순서**: ① 검색창에 한 글자씩 입력 → ② 입력할 때마다 결과 목록이 바뀜 → ③ 검색어가 하이라이트됨 → ④ 결과 항목 클릭 → ⑤ 호버 윈도우로 노트 열림
> **화면 영역**: 검색 화면 전체
> **강조**: 실시간으로 결과가 업데이트되는 모습과 하이라이트
> **길이**: 5~8초

---

## 검색 필드

원하는 범위를 지정해서 검색할 수 있습니다.

| 검색 필드 | 어디서 찾나요? | 예시 |
|----------|--------------|------|
| **제목** | 노트 제목에서만 | "회의록"이 제목에 있는 노트 |
| **본문** | 노트 내용에서만 | "프로젝트 일정"이 본문에 있는 노트 |
| **태그** | 태그에서만 | `#중요` 태그가 달린 노트 |
| **컨테이너** | 특정 컨테이너 안에서 | "업무" 컨테이너 안의 노트 |
| **첨부파일** | 첨부 파일 이름에서 | "보고서.pdf"가 첨부된 노트 |

> 📸 **여기에 GIF** — `images/search-fields.gif`
>
> **촬영**: 검색 필드를 바꿔가며 검색 범위를 조정하는 모습
> **순서**: ① 기본 검색 (전체) → ② "제목" 필드로 변경 → ③ 결과가 줄어듦 → ④ "태그" 필드로 변경 → ⑤ 태그 검색 결과 확인
> **화면 영역**: 검색 화면 (필드 선택 UI에 포커스)
> **강조**: 필드를 바꿀 때마다 결과가 달라지는 모습
> **길이**: 5~8초

## 고급 필터

검색 결과를 더 정확하게 좁힐 수 있는 필터입니다.

### 날짜 필터

특정 기간에 쓰거나 수정한 노트만 볼 수 있습니다.

> 📸 **여기에 GIF** — `images/search-date-filter.gif`
>
> **촬영**: 날짜 범위 필터를 설정해서 결과를 좁히는 모습
> **순서**: ① 검색 결과가 많음 → ② 날짜 필터 열기 → ③ 시작 날짜 선택 → ④ 끝 날짜 선택 → ⑤ 결과가 해당 기간의 노트만으로 줄어듦
> **화면 영역**: 검색 화면 (날짜 필터 UI에 포커스)
> **강조**: 날짜 선택과 결과가 줄어드는 모습
> **길이**: 5~8초

### 노트 유형 필터

특정 템플릿으로 만든 노트만 볼 수 있습니다 (예: 회의록만, 논문만).

> 📸 **여기에 GIF** — `images/search-type-filter.gif`
>
> **촬영**: 노트 유형 필터로 "회의록"만 선택해서 결과를 좁히는 모습
> **순서**: ① 검색 결과 목록 → ② 유형 필터 열기 → ③ "회의록" 선택 → ④ 결과가 회의록만으로 줄어듦
> **화면 영역**: 검색 화면 (유형 필터 UI에 포커스)
> **강조**: 필터 적용 전후 결과 비교
> **길이**: 3~5초

### 태그 필터

특정 태그가 달린 노트만 볼 수 있습니다.

> 📸 **여기에 GIF** — `images/search-tag-filter.gif`
>
> **촬영**: 태그 필터로 특정 태그가 있는 노트만 보여주는 과정
> **순서**: ① 태그 필터 열기 → ② 태그 선택 (예: #중요) → ③ 결과가 해당 태그 노트만으로 줄어듦
> **화면 영역**: 검색 화면 (태그 필터 UI에 포커스)
> **강조**: 태그 선택과 결과 변화
> **길이**: 3~5초

### 필터 조합

여러 필터를 동시에 쓸 수 있습니다.

- 예: "업무" 컨테이너 + "회의록" 유형 + 이번 달 작성
- 이렇게 하면 **이번 달 업무 회의록만** 검색됩니다

## 검색 결과에서 노트 열기

검색 결과에서 노트를 클릭하면 **호버 윈도우**로 열립니다.

- 지금 쓰고 있는 노트는 그대로 유지됩니다
- 검색 결과를 보면서 여러 노트를 빠르게 확인할 수 있습니다

---

## 일괄 작업

검색 결과에서 여러 노트를 선택해서 한 번에 작업할 수 있습니다. 노트가 많을 때 아주 유용합니다.

| 작업 | 하는 일 |
|------|---------|
| **일괄 삭제** | 선택한 노트를 한 번에 삭제합니다 |
| **일괄 이동** | 선택한 노트를 한 번에 다른 폴더로 옮깁니다 |
| **일괄 태그** | 선택한 노트에 한 번에 태그를 추가합니다 |

### 일괄 작업하는 방법

1. 검색으로 원하는 노트를 찾습니다
2. **체크박스**로 여러 노트를 선택합니다
3. 원하는 일괄 작업 버튼을 클릭합니다

> 📸 **여기에 GIF** — `images/search-bulk-actions.gif`
>
> **촬영**: 검색 결과에서 여러 노트를 체크박스로 선택하고 일괄 이동하는 과정
> **순서**: ① 검색 결과 목록 → ② 첫 번째 노트 체크박스 클릭 → ③ 두 번째, 세 번째 노트도 체크 → ④ "일괄 이동" 버튼 클릭 → ⑤ 대상 폴더 선택 → ⑥ 확인 → ⑦ 이동 완료
> **화면 영역**: 검색 화면 전체
> **강조**: 체크박스 선택과 일괄 작업 버튼
> **길이**: 8~12초

## 충돌 파일 찾기

NAS나 클라우드 드라이브로 노트를 동기화할 때, 여러 컴퓨터에서 동시에 수정하면 **충돌 파일**이 생길 수 있습니다.

- 충돌 파일은 파일 이름에 `(conflict)` 같은 표시가 붙습니다
- 검색에서 "conflict"를 검색하면 충돌 파일을 찾을 수 있습니다
- 원본과 비교해서 내용을 합친 다음, 충돌 파일을 삭제하면 됩니다

> 📸 **여기에 GIF** — `images/search-conflicts.gif`
>
> **촬영**: 검색에서 "conflict"를 검색하여 충돌 파일을 찾고 정리하는 과정
> **순서**: ① 검색창에 "conflict" 입력 → ② 충돌 파일 목록 나타남 → ③ 충돌 파일 클릭해서 내용 확인 → ④ 원본과 비교 → ⑤ 충돌 파일 삭제
> **화면 영역**: 검색 화면 + 호버 윈도우
> **강조**: 충돌 파일을 식별하는 방법
> **길이**: 5~8초

## 검색 팁

| 팁 | 설명 |
|----|------|
| 짧게 검색하세요 | 긴 문장보다 핵심 단어 1~2개가 더 잘 찾아줍니다 |
| 태그를 활용하세요 | 자주 찾는 주제에 태그를 달아두면 필터로 빠르게 찾을 수 있습니다 |
| 범위를 좁히세요 | 컨테이너나 유형 필터를 쓰면 더 정확한 결과를 얻습니다 |
| 날짜로 찾으세요 | "지난주에 쓴 노트"처럼 기간으로 좁히면 편합니다 |
| 정기적으로 정리하세요 | 일괄 작업으로 오래된 노트를 주기적으로 정리하면 좋습니다 |
