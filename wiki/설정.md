# <img src="images/icons/settings.png" width="24" height="24"> 설정

Notology의 외관, 에디터 동작, 템플릿, 단축키, 개발자 옵션 등을 설정합니다.

---

## 설정 열기

사이드바 하단의 **⚙ 설정 버튼**을 클릭합니다.

> 📸 **여기에 GIF** — `images/settings-open.gif`
>
> **촬영**: 사이드바 하단의 설정(⚙) 버튼을 클릭하여 설정 대화상자가 열리는 과정
> **순서**: ① 사이드바 하단의 ⚙ 버튼에 커서 이동 → ② 클릭 → ③ 설정 대화상자(모달)가 나타남
> **화면 영역**: 전체 화면 (사이드바 하단 클릭 + 설정 모달이 열리는 과정)
> **강조**: ⚙ 버튼 위치, 설정 모달이 팝업되는 순간
> **길이**: 3~5초

## 외관 탭

앱의 테마, 글꼴, 언어를 설정합니다.

### 테마

| 옵션 | 설명 |
|------|------|
| **다크 모드** | 어두운 배경에 밝은 글자 (눈의 피로 감소) |
| **라이트 모드** | 밝은 배경에 어두운 글자 (일반적인 문서 스타일) |
| **시스템 설정** | Windows 설정에 맞춰 자동으로 전환됩니다 |

> 📸 **여기에 GIF** — `images/settings-theme.gif`
>
> **촬영**: 설정 > 외관 탭에서 테마를 다크/라이트로 전환하는 과정
> **순서**: ① 외관 탭에서 테마 옵션 확인 → ② "다크 모드" 선택 → 화면이 어두운 테마로 전환 → ③ "라이트 모드" 선택 → 화면이 밝은 테마로 전환
> **화면 영역**: 전체 화면 (설정 모달 + 배경 앱 전체가 테마 전환되는 모습)
> **강조**: 테마 전환 시 앱 전체의 색상 변화 (배경, 사이드바, 에디터 모두 변경)
> **길이**: 5~8초

### 글꼴

본문에 사용할 글꼴을 선택할 수 있습니다.

| 글꼴 | 설명 |
|------|------|
| **시스템 기본** | Windows 기본 글꼴 |
| **나눔고딕** | 네이버 나눔고딕 |
| **Noto Sans KR** | 구글 Noto Sans 한국어 |
| **맑은 고딕** | Windows 내장 한국어 글꼴 |
| **커스텀** | 직접 글꼴 이름을 입력하여 사용합니다 |

**커스텀 글꼴 추가 방법**: 글꼴 설정에서 "커스텀"을 선택한 뒤, 컴퓨터에 설치된 글꼴의 이름을 정확히 입력합니다.

> 📸 **여기에 GIF** — `images/settings-font.gif`
>
> **촬영**: 설정 > 외관 탭에서 글꼴을 변경하여 에디터의 글꼴이 바뀌는 과정
> **순서**: ① 글꼴 드롭다운 클릭 → ② 목록에서 다른 글꼴 선택 (예: 나눔고딕 → Noto Sans KR) → ③ 에디터 본문의 글꼴이 실시간으로 변경됨
> **화면 영역**: 설정 모달 (글꼴 드롭다운) + 배경의 에디터 본문
> **강조**: 글꼴 변경 전후의 텍스트 모양 차이
> **길이**: 5~8초

### 언어

| 옵션 | 설명 |
|------|------|
| **한국어** | 전체 UI가 한국어로 표시됩니다 |
| **English** | 전체 UI가 영어로 표시됩니다 |

> 📸 **여기에 GIF** — `images/settings-language.gif`
>
> **촬영**: 설정 > 외관 탭에서 언어를 한국어/영어로 전환하는 과정
> **순서**: ① 언어 드롭다운 클릭 → ② "English" 선택 → ③ UI 전체가 영어로 변경됨 → ④ 다시 "한국어" 선택 → ⑤ UI가 한국어로 복귀
> **화면 영역**: 전체 화면 (설정 모달 + 사이드바/메뉴 등 UI 전체 변화)
> **강조**: 사이드바, 메뉴, 버튼 텍스트가 언어에 따라 바뀌는 모습
> **길이**: 5~8초

## 에디터 탭

에디터의 동작 방식을 설정합니다.

| 설정 | 설명 | 기본값 |
|------|------|--------|
| **툴바 기본 접힘** | 에디터 상단 툴바를 기본적으로 접어둡니다 | 끔 |
| **Ctrl+스크롤 줌** | `Ctrl + 마우스 휠`로 에디터 글자 크기를 조절합니다 | 켬 |
| **현재 줌 레벨** | 현재 에디터의 줌 비율을 표시하고 조절합니다 | 100% |
| **기본 창 크기** | 호버 윈도우의 기본 크기를 설정합니다 | Medium |
| **자동 저장 지연** | 입력 후 자동 저장까지의 대기 시간 (밀리초) | 1000ms |

### 기본 창 크기 옵션

| 크기 | 설명 |
|------|------|
| **Small** | 작은 호버 윈도우 (간단한 메모 확인용) |
| **Medium** | 중간 크기 (일반적인 노트 편집용) |
| **Large** | 큰 호버 윈도우 (긴 문서 편집용) |
| **Wide** | 넓은 호버 윈도우 (표나 코드 편집용) |

> 📸 **여기에 GIF** — `images/settings-editor.gif`
>
> **촬영**: 설정 > 에디터 탭에서 옵션을 변경하는 과정 (기본 창 크기 변경, 줌 레벨 조절 등)
> **순서**: ① 에디터 탭 선택 → ② 기본 창 크기를 Medium에서 Large로 변경 → ③ 줌 레벨 슬라이더 조절 → ④ 변경사항이 에디터에 반영되는 모습 확인
> **화면 영역**: 설정 모달의 에디터 탭 전체
> **강조**: 각 설정 항목의 위치, 변경 시 실시간 반영
> **길이**: 5~8초

## 템플릿 탭

템플릿의 활성/비활성과 커스텀 템플릿을 관리합니다.

| 기능 | 설명 |
|------|------|
| **활성/비활성 토글** | 각 템플릿을 노트 생성 시 표시할지 결정합니다 |
| **커스텀 템플릿 만들기** | 나만의 템플릿을 새로 만듭니다 |
| **커스텀 템플릿 편집** | 기존 커스텀 템플릿의 내용을 수정합니다 |
| **커스텀 템플릿 삭제** | 커스텀 템플릿을 삭제합니다 |

자세한 내용은 [템플릿](템플릿) 페이지를 참고하세요.

> 📸 **여기에 GIF** — `images/settings-templates.gif`
>
> **촬영**: 설정 > 템플릿 탭에서 템플릿 목록을 확인하고 토글/편집하는 과정
> **순서**: ① 템플릿 탭 선택 → ② 기본 템플릿 목록 확인 → ③ 특정 템플릿 토글 OFF → ④ 커스텀 템플릿 영역 확인
> **화면 영역**: 설정 모달의 템플릿 탭 전체
> **강조**: 템플릿 목록, 토글 스위치, 커스텀 템플릿 영역
> **길이**: 5~8초

## 단축키 탭

앱에서 사용하는 모든 키보드 단축키를 확인하고 변경할 수 있습니다.

| 기능 | 설명 |
|------|------|
| **단축키 목록** | 모든 단축키와 현재 바인딩을 확인합니다 |
| **단축키 변경** | 원하는 단축키를 클릭한 뒤 새로운 키 조합을 입력하여 변경합니다 |
| **초기화** | 변경한 단축키를 기본값으로 되돌립니다 |

자세한 내용은 [단축키](단축키) 페이지를 참고하세요.

> 📸 **여기에 GIF** — `images/settings-shortcuts.gif`
>
> **촬영**: 설정 > 단축키 탭에서 단축키 목록을 확인하고 키 바인딩을 변경하는 과정
> **순서**: ① 단축키 탭 선택 → ② 단축키 목록 스크롤하며 확인 → ③ 특정 단축키 클릭 → ④ 새로운 키 조합 입력 → ⑤ 변경 완료
> **화면 영역**: 설정 모달의 단축키 탭 전체
> **강조**: 단축키 목록의 현재 바인딩, 변경 입력 중인 키 조합 표시
> **길이**: 5~8초

## 개발자 탭

고급 사용자를 위한 개발자 옵션입니다.

| 설정 | 설명 |
|------|------|
| **개발자 모드** | 디버그 정보를 표시합니다 (일반 사용에는 불필요) |
| **DevTools (F12)** | 브라우저 개발자 도구를 열어 앱 내부를 확인합니다 |

> **주의**: 개발자 탭의 기능은 앱 개발이나 디버깅용입니다. 일반 사용에서는 변경하지 않는 것을 권장합니다.
