# <img src="images/icons/zap.png" width="24" height="24"> 에디터 고급

코드 블록, 섹션 접기, 첨부파일, 자동완성 등 고급 기능을 알아봅니다.

## 코드 블록

프로그래밍 코드나 스크립트를 쓸 때 사용합니다. 코드가 색상으로 구분되어 읽기 쉬워집니다.

### 코드 블록 만들기

줄 앞에 ` ``` `을 입력하고 바로 뒤에 언어 이름을 쓰면 됩니다.

````
```javascript
function hello() {
  console.log("Hello, World!");
}
```
````

### 지원하는 언어

20개 이상의 프로그래밍 언어를 지원합니다.

| 분류 | 언어 |
|------|------|
| 웹 | JavaScript, TypeScript, HTML, CSS |
| 시스템 | C, C++, Rust, Go |
| 스크립트 | Python, Ruby, Shell (Bash) |
| 데이터 | JSON, YAML, XML, SQL |
| 기타 | Java, C#, PHP, Markdown, LaTeX |

> 📸 **여기에 GIF** — `images/editor-code-block.gif`
>
> **촬영**: 코드 블록을 만들고 코드를 입력하는 과정 (구문 강조 포함)
> **순서**: ① 빈 줄에 ```javascript 입력 → ② 코드 블록 생성됨 → ③ 코드 입력 → ④ 구문 강조(색상)가 자동 적용됨 → ⑤ 언어를 python으로 변경
> **화면 영역**: 에디터 본문 영역만
> **강조**: 구문 강조 색상이 적용되는 모습과 언어 선택 드롭다운
> **길이**: 5~8초

### 코드 블록 접기/펼치기

코드 블록 왼쪽의 **화살표 버튼**을 클릭하면 코드를 접거나 펼 수 있습니다. 긴 코드를 잠깐 숨겨두면 문서를 읽기 편합니다.

> 📸 **여기에 GIF** — `images/editor-code-fold.gif`
>
> **촬영**: 코드 블록의 화살표를 클릭해서 접고 펼치는 모습
> **순서**: ① 긴 코드 블록이 보임 → ② 왼쪽 화살표 클릭 → ③ 코드 블록이 접힘 (한 줄로 줄어듦) → ④ 다시 화살표 클릭 → ⑤ 코드 블록이 펼쳐짐
> **화면 영역**: 에디터 본문 영역만
> **강조**: 화살표 버튼과 접히는 애니메이션
> **길이**: 3~5초

## 섹션 접기 (제목 접기)

제목 왼쪽의 화살표를 클릭하면 그 제목 아래의 모든 내용이 숨겨집니다.

### 어떻게 동작하나요?

- 제목 왼쪽의 **화살표**를 클릭하면 접힙니다
- 같은 단계 또는 더 높은 단계의 다음 제목까지의 내용이 숨겨집니다
- 예: `## 챕터 1`을 접으면 `### 소제목`은 숨겨지지만 `## 챕터 2`는 계속 보입니다

### 이럴 때 유용합니다

| 상황 | 이렇게 쓰세요 |
|------|-------------|
| 긴 문서 읽을 때 | 안 보는 부분은 접고, 필요한 부분만 펼쳐서 읽기 |
| 문서 구조 파악할 때 | 모든 제목을 접으면 목차처럼 한눈에 보기 |
| 집중해서 쓸 때 | 지금 쓰는 섹션만 펼치고 나머지는 접기 |

> 📸 **여기에 GIF** — `images/editor-section-fold.gif`
>
> **촬영**: 여러 섹션이 있는 긴 문서에서 제목을 접고 펼치면서 탐색하는 모습
> **순서**: ① 긴 문서에 H2 제목 3개 보임 → ② 첫 번째 H2 화살표 클릭 → ③ 해당 섹션 내용 접힘 → ④ 두 번째 H2도 접기 → ⑤ 제목들만 목차처럼 보임 → ⑥ 세 번째 H2 펼치기
> **화면 영역**: 에디터 본문 영역만
> **강조**: 접기/펼치기 전후의 문서 길이 변화
> **길이**: 5~8초

## 첨부파일

노트에 파일을 첨부할 수 있습니다. 첨부한 파일은 **첨부파일** 섹션에 자동으로 정리됩니다.

### 파일 첨부하는 방법

| 방법 | 설명 |
|------|------|
| 드래그 앤 드롭 | 파일을 에디터로 끌어다 놓습니다 |
| `//` 입력 | 에디터에서 `//`를 입력하면 파일 선택 목록이 나타납니다 |

> 📸 **여기에 GIF** — `images/editor-attach-drag.gif`
>
> **촬영**: 파일을 에디터로 드래그 앤 드롭하여 첨부하는 과정
> **순서**: ① Windows 탐색기에서 파일 선택 → ② 에디터로 드래그 → ③ 드롭 → ④ "첨부파일" 섹션에 자동으로 추가됨
> **화면 영역**: 에디터 영역 (Windows 탐색기 일부 포함)
> **강조**: 첨부파일 섹션에 항목이 추가되는 순간
> **길이**: 5~8초

> 📸 **여기에 GIF** — `images/editor-attach-trigger.gif`
>
> **촬영**: 에디터에서 // 입력으로 첨부파일 목록을 불러오는 과정
> **순서**: ① 에디터에서 "//" 입력 → ② 파일 선택 드롭다운 나타남 → ③ 목록에서 파일 선택 → ④ 첨부파일 섹션에 추가됨
> **화면 영역**: 에디터 본문 영역 (드롭다운 포함)
> **강조**: // 입력 시 나타나는 파일 선택 목록
> **길이**: 3~5초

### 첨부파일 섹션

- 파일을 처음 첨부하면 노트 아래쪽에 **첨부파일** 섹션이 자동 생성됩니다
- 이미 섹션이 있으면 기존 목록 아래에 추가됩니다
- 첨부파일은 글머리 기호 목록(- )으로 정리됩니다

## 인라인 제안 (자동완성)

특정 기호를 입력하면 자동완성 목록이 나타납니다.

| 이걸 입력하면 | 이런 목록이 나타납니다 |
|-------------|---------------------|
| `[[` | Vault 안의 노트 목록 (위키링크 만들기) |
| `@` | 노트 멘션 목록 |
| `//` | Vault 안의 파일 목록 (첨부파일 삽입) |

- 방향키(↑↓)로 고르고 `Enter`로 확정합니다
- 글자를 더 입력하면 목록이 좁혀집니다

> 📸 **여기에 GIF** — `images/editor-suggestions.gif`
>
> **촬영**: [[, @, // 각각을 입력해서 자동완성 목록이 나타나는 모습
> **순서**: ① "[["  입력 → ② 노트 목록 나타남 → ③ 노트 선택 → ④ 위키링크 완성 → ⑤ 새 줄에서 "@" 입력 → ⑥ 멘션 목록 나타남 → ⑦ 선택
> **화면 영역**: 에디터 본문 영역 (자동완성 드롭다운 포함)
> **강조**: 각 트리거 문자 입력 시 드롭다운이 나타나는 순간
> **길이**: 8~12초

## 에디터 확대/축소

글자 크기를 크게 하거나 작게 할 수 있습니다.

| 동작 | 방법 |
|------|------|
| 확대 (크게) | `Ctrl` + 마우스 휠 위로 |
| 축소 (작게) | `Ctrl` + 마우스 휠 아래로 |
| 범위 | 50% ~ 200% |

> 📸 **여기에 GIF** — `images/editor-zoom.gif`
>
> **촬영**: Ctrl+마우스 휠로 에디터를 확대/축소하는 모습
> **순서**: ① 기본 크기(100%) 상태 → ② Ctrl+휠 위로 (확대) → ③ 글자가 커짐 → ④ Ctrl+휠 아래로 (축소) → ⑤ 글자가 작아짐
> **화면 영역**: 에디터 본문 영역만
> **강조**: 글자 크기가 변하는 모습
> **길이**: 3~5초

## YAML 프론트매터

노트 맨 위에 `---`로 감싼 영역에 노트의 정보를 기록할 수 있습니다.

```yaml
---
type: 노트
tags: [프로젝트, 아이디어]
created: 2024-01-15
---
```

| 항목 | 뜻 |
|------|-----|
| `type` | 노트의 종류 (어떤 템플릿으로 만들었는지) |
| `tags` | 태그 목록 (검색할 때 활용) |
| `created` | 만든 날짜 |

프론트매터는 에디터에서 회색 영역으로 표시되며, 검색과 필터에 활용됩니다.

## 인라인 메모 (코멘트)

텍스트에 메모를 달아둘 수 있습니다. 달아둔 메모는 오른쪽 패널의 캘린더에서 날짜별로 확인할 수 있습니다.

### 메모 다는 방법

1. 메모를 달고 싶은 텍스트를 드래그해서 선택합니다
2. 마우스 우클릭 → **메모 추가**를 선택합니다
3. 메모 내용과 날짜를 입력합니다

> 📸 **여기에 GIF** — `images/editor-comment-add.gif`
>
> **촬영**: 텍스트를 선택하고 우클릭으로 메모를 추가하는 과정
> **순서**: ① 텍스트 드래그로 선택 → ② 우클릭 → ③ "메모 추가" 선택 → ④ 메모 내용 입력 → ⑤ 날짜 선택 → ⑥ 확인 → ⑦ 텍스트에 하이라이트 표시됨
> **화면 영역**: 에디터 본문 영역 (컨텍스트 메뉴 + 메모 다이얼로그)
> **강조**: "메모 추가" 메뉴 항목과 하이라이트가 적용된 텍스트
> **길이**: 5~8초

### 캘린더에서 메모 확인

- 메모가 달린 텍스트는 하이라이트로 표시됩니다
- 오른쪽 패널의 **캘린더**에서 해당 날짜의 메모를 한눈에 볼 수 있습니다
- 캘린더에서 메모를 클릭하면 그 노트의 해당 위치로 이동합니다

> 📸 **여기에 GIF** — `images/editor-comment-calendar.gif`
>
> **촬영**: 오른쪽 패널 캘린더에서 메모를 확인하고 클릭해서 해당 노트로 이동하는 과정
> **순서**: ① 오른쪽 패널의 캘린더 보기 → ② 메모가 있는 날짜 클릭 → ③ 메모 목록 표시됨 → ④ 메모 항목 클릭 → ⑤ 해당 노트의 메모 위치로 이동
> **화면 영역**: 오른쪽 패널 + 에디터 영역
> **강조**: 캘린더의 메모 마커와 클릭 시 이동하는 모습
> **길이**: 5~8초

## 자동 업데이트 알림

Notology의 새 버전이 나오면 앱 안에서 알림이 표시됩니다. 알림을 클릭하면 최신 버전을 다운로드할 수 있습니다.

> 📸 **여기에 GIF** — `images/auto-update.gif`
>
> **촬영**: 업데이트 알림이 나타나고 클릭하는 과정
> **순서**: ① 앱 사용 중 업데이트 알림 배너 나타남 → ② 알림 클릭 → ③ 다운로드/업데이트 진행
> **화면 영역**: 앱 전체 화면 (알림 배너에 포커스)
> **강조**: 업데이트 알림 배너
> **길이**: 3~5초
