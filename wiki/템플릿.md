# <img src="images/icons/clipboard.png" width="24" height="24"> 템플릿

미리 만들어둔 구조로 노트를 빠르게 만들 수 있습니다. 회의록, 연락처, 논문 정리 등 반복적으로 쓰는 형식을 템플릿으로 저장해두면 매번 처음부터 작성할 필요가 없어요.

---

## 개념

**템플릿**은 노트를 만들 때 사용하는 미리 만들어진 틀입니다.

- 새 노트를 만들 때 원하는 템플릿을 선택하면, 해당 구조가 자동으로 채워집니다
- YAML 프론트매터(제목 위의 정보 영역)와 본문이 포함됩니다
- 기본 제공 템플릿 12가지 + 직접 만드는 커스텀 템플릿을 사용할 수 있습니다

---

## 기본 제공 템플릿 (12가지)

Notology에는 다양한 용도의 템플릿이 기본으로 포함되어 있습니다.

### 일반

| 아이콘 | 템플릿 | 용도 | 포함 항목 |
|--------|--------|------|----------|
| 📝 | **노트** | 자유로운 메모 | 제목, 태그, 본문 |
| 🎨 | **스케치** | 캔버스 그리기 | 캔버스 형식 노트 |

### 업무

| 아이콘 | 템플릿 | 용도 | 포함 항목 |
|--------|--------|------|----------|
| 🤝 | **회의록** | 회의 내용 기록 | 날짜, 참석자, 안건, 결정사항, 할 일 |
| 🎓 | **세미나** | 세미나/강의 정리 | 발표자, 주제, 핵심내용, 질의응답 |
| 🎉 | **이벤트** | 행사/일정 기록 | 날짜, 장소, 참석자, 프로그램 |
| 📃 | **공문서** | 공식 문서 작성 | 문서번호, 수신, 발신, 제목, 본문 |

### 연구

| 아이콘 | 템플릿 | 용도 | 포함 항목 |
|--------|--------|------|----------|
| 📑 | **논문** | 논문 리뷰/정리 | 저자, 출처, 초록, 방법론, 결과, 의의 |
| 📚 | **문헌** | 참고문헌 기록 | 저자, 출판정보, 요약, 인용 |
| 📊 | **데이터** | 데이터 분석 기록 | 데이터 출처, 분석 방법, 결과, 시각화 |
| 🔬 | **이론** | 이론/개념 정리 | 정의, 배경, 핵심개념, 관련이론, 적용 |

### 기타

| 아이콘 | 템플릿 | 용도 | 포함 항목 |
|--------|--------|------|----------|
| 👤 | **연락처** | 사람 정보 관리 | 이름, 소속, 연락처, 메모 |
| ⚙️ | **설정** | 환경/설정 기록 | 항목, 값, 설명 |

> 📸 **여기에 GIF** — `images/template-types.gif`
>
> **촬영**: 노트 생성 대화상자에서 템플릿 목록을 스크롤하며 각 템플릿의 미리보기를 확인하는 과정
> **순서**: ① Ctrl+N으로 노트 생성 대화상자 열기 → ② 템플릿 목록을 위아래 스크롤하며 여러 템플릿 확인 → ③ 각 템플릿에 마우스를 올려 미리보기 표시
> **화면 영역**: 노트 생성 대화상자 전체 (템플릿 목록 + 미리보기 패널)
> **강조**: 각 템플릿의 아이콘과 이름, 선택 시 표시되는 미리보기 내용
> **길이**: 8~12초

## 템플릿으로 노트 만들기

1. `Ctrl + N`을 누르거나 사이드바 하단의 **+ 버튼**을 클릭합니다
2. 노트 이름을 입력합니다
3. **템플릿 목록**에서 원하는 템플릿을 선택합니다
4. **만들기**를 클릭하면 템플릿 구조가 적용된 노트가 생성됩니다

> 📸 **여기에 GIF** — `images/template-select.gif`
>
> **촬영**: Ctrl+N으로 노트 생성 대화상자를 열고 템플릿을 선택하는 과정
> **순서**: ① Ctrl+N 입력 → ② 노트 생성 대화상자 나타남 → ③ 템플릿 목록에서 원하는 템플릿 클릭 → ④ 선택된 템플릿이 강조됨
> **화면 영역**: 노트 생성 대화상자 (중앙 모달)
> **강조**: 템플릿 선택 시 하이라이트 변화
> **길이**: 3~5초

> 📸 **여기에 GIF** — `images/template-create-note.gif`
>
> **촬영**: 템플릿을 선택한 후 노트 이름을 입력하고 생성 완료까지의 전체 과정
> **순서**: ① 노트 이름 입력란에 이름 타이핑 → ② 템플릿 선택 → ③ "만들기" 버튼 클릭 → ④ 새 노트가 열리고 템플릿 구조가 채워진 상태 표시
> **화면 영역**: 전체 화면 (대화상자 → 에디터에 새 노트가 열리는 과정)
> **강조**: 생성된 노트에 템플릿의 YAML 프론트매터와 본문 구조가 자동으로 채워진 모습
> **길이**: 5~8초

## 커스텀 템플릿

기본 템플릿 외에도 나만의 템플릿을 직접 만들 수 있습니다.

### 만들기

1. **설정** (사이드바 하단 ⚙ 버튼)을 엽니다
2. **템플릿** 탭을 선택합니다
3. **새 템플릿 만들기**를 클릭합니다
4. 템플릿 이름, 아이콘, YAML 프론트매터, 본문을 작성합니다
5. 저장합니다

### 구조

커스텀 템플릿은 **YAML 프론트매터**와 **마크다운 본문**으로 구성됩니다.

```yaml
---
tags:
  - 프로젝트
상태: 진행중
담당자: ""
---
# 프로젝트명

## 목표

## 일정

## 메모
```

### 편집 / 삭제

- 설정 → 템플릿 탭에서 기존 커스텀 템플릿을 **편집**하거나 **삭제**할 수 있습니다

> 📸 **여기에 GIF** — `images/template-custom-create.gif`
>
> **촬영**: 설정 > 템플릿 탭에서 새 커스텀 템플릿을 만드는 전체 과정
> **순서**: ① 설정 열기 (⚙ 버튼 클릭) → ② 템플릿 탭 선택 → ③ "새 템플릿 만들기" 버튼 클릭 → ④ 이름/아이콘 입력 → ⑤ YAML 프론트매터와 본문 작성 → ⑥ 저장 버튼 클릭
> **화면 영역**: 설정 대화상자 전체 (템플릿 탭 + 편집 폼)
> **강조**: 새 템플릿 만들기 버튼, 편집 폼의 각 입력 필드, 저장 버튼
> **길이**: 8~12초

## 템플릿 활성/비활성

사용하지 않는 템플릿은 비활성화할 수 있습니다. 비활성화된 템플릿은 노트 생성 시 목록에 나타나지 않습니다.

- 설정 → 템플릿 탭에서 각 템플릿의 **토글 스위치**로 활성/비활성을 전환합니다

> 📸 **여기에 GIF** — `images/template-toggle.gif`
>
> **촬영**: 설정 > 템플릿 탭에서 템플릿 토글 스위치를 끄고 켜는 과정
> **순서**: ① 설정 > 템플릿 탭에서 특정 템플릿의 토글 스위치 클릭 (OFF) → ② 해당 템플릿이 비활성화됨 → ③ 다시 토글 클릭 (ON) → ④ 활성화 상태로 복귀
> **화면 영역**: 설정 대화상자의 템플릿 탭 (템플릿 목록 영역)
> **강조**: 토글 스위치의 ON/OFF 변화
> **길이**: 3~5초

## Storage 컨테이너와 템플릿

**Storage(저장소) 컨테이너**는 하나의 템플릿과 연결되어, 해당 컨테이너에서 만드는 모든 노트에 같은 템플릿이 자동 적용됩니다.

| 특징 | 설명 |
|------|------|
| **고정 템플릿** | 컨테이너 생성 시 선택한 템플릿이 모든 노트에 적용됩니다 |
| **자동 적용** | 노트를 만들 때 템플릿 선택 단계가 생략됩니다 |
| **일관된 형식** | 모든 노트가 같은 구조를 가지므로 검색과 관리가 편리합니다 |

> 예: "연락처" 템플릿으로 Storage 컨테이너를 만들면, 모든 새 노트가 연락처 형식으로 생성됩니다.

> 📸 **여기에 GIF** — `images/template-storage-container.gif`
>
> **촬영**: Storage 컨테이너를 만들고 템플릿을 연결한 뒤, 컨테이너에서 새 노트를 생성하여 템플릿이 자동 적용되는 과정
> **순서**: ① 사이드바에서 Storage 컨테이너 생성 → ② 템플릿 선택(예: 연락처) → ③ 컨테이너 안에서 새 노트 생성 → ④ 템플릿이 자동 적용된 노트 확인
> **화면 영역**: 전체 화면 (사이드바의 컨테이너 + 에디터에 열리는 새 노트)
> **강조**: 노트 생성 시 템플릿 선택 단계 없이 바로 구조가 적용되는 점
> **길이**: 8~12초

## 활용 팁

| 팁 | 설명 |
|----|------|
| 반복 작업에 활용 | 매주 작성하는 회의록, 주간보고 등에 템플릿을 사용하면 시간을 절약할 수 있습니다 |
| Storage로 데이터베이스 만들기 | 연락처, 논문, 프로젝트 등을 Storage 컨테이너로 관리하면 구조화된 데이터베이스가 됩니다 |
| 불필요한 템플릿 숨기기 | 사용하지 않는 기본 템플릿은 비활성화하여 목록을 깔끔하게 유지하세요 |
