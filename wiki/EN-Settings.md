---

## Appearance Tab

Set the app's theme, font, and language.

### Theme

| Option | Description |
|--------|-------------|
| **Dark mode** | Dark background with light text (reduces eye strain) |
| **Light mode** | Light background with dark text (standard document style) |
| **System setting** | Automatically follows your Windows theme setting |

> 📸 **GIF placeholder** — `images/settings-theme.gif`
>
> **Shot**: Switching themes between dark and light in Settings > Appearance tab
> **Steps**: ① Check theme options in the Appearance tab → ② Select "Dark mode" → the screen switches to the dark theme → ③ Select "Light mode" → the screen switches to the light theme
> **Screen area**: Full screen (settings modal + the entire app switching themes in the background)
> **Highlight**: The entire app changing colors when themes switch (background, sidebar, editor all change)
> **Duration**: 5~8s

### Font

Choose the font used for the editor body text.

| Font | Description |
|------|-------------|
| **System default** | Windows default font |
| **NanumGothic** | Naver NanumGothic |
| **Noto Sans KR** | Google Noto Sans Korean |
| **Malgun Gothic** | Built-in Windows Korean font |
| **Custom** | Enter a font name manually |

**How to add a custom font**: Select "Custom" in the font settings, then type the exact name of a font installed on your computer.

> 📸 **GIF placeholder** — `images/settings-font.gif`
>
> **Shot**: Changing the font in Settings > Appearance tab and seeing the editor font update
> **Steps**: ① Click the font dropdown → ② Select a different font from the list (e.g., NanumGothic → Noto Sans KR) → ③ The editor body font changes in real time
> **Screen area**: Settings modal (font dropdown) + editor body in the background
> **Highlight**: The text appearance difference before and after the font change
> **Duration**: 5~8s

### Language

| Option | Description |
|--------|-------------|
| **Korean** | The entire UI is displayed in Korean |
| **English** | The entire UI is displayed in English |

> 📸 **GIF placeholder** — `images/settings-language.gif`
>
> **Shot**: Switching the language between Korean and English in Settings > Appearance tab
> **Steps**: ① Click the language dropdown → ② Select "English" → ③ The entire UI changes to English → ④ Select "Korean" again → ⑤ The UI reverts to Korean
> **Screen area**: Full screen (settings modal + sidebar/menus and the entire UI changing)
> **Highlight**: Sidebar, menus, and button text changing with the language
> **Duration**: 5~8s

## Editor Tab

Configure how the editor behaves.

| Setting | Description | Default |
|---------|-------------|---------|
| **Toolbar collapsed by default** | Collapses the editor toolbar at the top by default | Off |
| **Ctrl+Scroll zoom** | Adjust editor text size with `Ctrl + mouse wheel` | On |
| **Current zoom level** | Shows and adjusts the current editor zoom ratio | 100% |
| **Default window size** | Sets the default size of hover windows | Medium |
| **Auto-save delay** | Wait time after typing before auto-saving (milliseconds) | 1000ms |

### Default Window Size Options

| Size | Description |
|------|-------------|
| **Small** | Small hover window (for quickly checking short memos) |
| **Medium** | Medium size (for general note editing) |
| **Large** | Large hover window (for editing long documents) |
| **Wide** | Wide hover window (for editing tables or code) |

> 📸 **GIF placeholder** — `images/settings-editor.gif`
>
> **Shot**: Changing options in Settings > Editor tab (default window size, zoom level, etc.)
> **Steps**: ① Select the Editor tab → ② Change default window size from Medium to Large → ③ Adjust the zoom level slider → ④ Observe changes reflected in the editor
> **Screen area**: Entire Editor tab in the settings modal
> **Highlight**: Location of each setting, real-time reflection of changes
> **Duration**: 5~8s

## Templates Tab

Manage template activation and custom templates.

| Feature | Description |
|---------|-------------|
| **Enable/disable toggle** | Choose whether each template appears when creating notes |
| **Create custom template** | Create a new template of your own |
| **Edit custom template** | Modify existing custom template content |
| **Delete custom template** | Remove a custom template |

For more details, see the [Templates](EN-Templates) page.

> **Screen area**: Entire Templates tab in the settings modal
> **Highlight**: Template list, toggle switches, custom templates area
> **Duration**: 5~8s

## Shortcuts Tab

View and customize all keyboard shortcuts used in the app.

| Feature | Description |
|---------|-------------|
| **Shortcut list** | View all shortcuts and their current key bindings |
| **Change shortcut** | Click a shortcut and press a new key combination to reassign it |
| **Reset** | Restore changed shortcuts to their default values |

For more details, see the [Keyboard Shortcuts](EN-Keyboard-Shortcuts) page.

> 📸 **GIF placeholder** — `images/settings-shortcuts.gif`
>
> **Shot**: Viewing the shortcut list and changing a key binding in Settings > Shortcuts tab
> **Steps**: ① Select the Shortcuts tab → ② Scroll through the shortcut list → ③ Click a specific shortcut → ④ Enter a new key combination → ⑤ Change confirmed
> **Screen area**: Entire Shortcuts tab in the settings modal
> **Highlight**: Current key bindings in the shortcut list, the key combination being entered during the change
> **Duration**: 5~8s

## Developer Tab

Advanced options for power users.

| Setting | Description |
|---------|-------------|
| **Developer mode** | Displays debug information (not needed for general use) |
| **DevTools (F12)** | Opens the browser developer tools to inspect app internals |

> **Note**: The Developer tab features are intended for app development and debugging. It is recommended not to change these settings during normal use.
