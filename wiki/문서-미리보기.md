# <img src="images/icons/file-scan.png" width="24" height="24"> 문서 미리보기

Notology 안에서 다양한 파일을 바로 열어볼 수 있습니다. PDF, 이미지, 오피스 문서, 코드 파일 등을 별도 프로그램 없이 미리보기할 수 있어요.

---

## 지원 파일 형식

| 분류 | 확장자 | 미리보기 방식 |
|------|--------|-------------|
| **PDF** | `.pdf` | 앱 내장 뷰어 (iframe) |
| **이미지** | `.png` `.jpg` `.gif` `.svg` `.webp` `.bmp` | 앱 내장 이미지 뷰어 |
| **최신 오피스** | `.docx` `.xlsx` `.pptx` `.hwpx` | LibreOffice로 PDF 변환 후 표시 |
| **레거시 오피스** | `.doc` `.ppt` `.xls` `.hwp` | 기본 앱에서 바로 열기 |
| **코드 파일** | `.js` `.py` `.ts` `.css` 등 | 구문 하이라이팅 뷰어 |

> 📸 **여기에 GIF** — `images/docpreview-file-types.gif`
>
> **촬영**: 여러 종류의 파일(PDF, 이미지, DOCX)을 차례로 클릭하여 각각의 미리보기 방식을 보여주는 과정
> **순서**: ① PDF 파일 클릭 → PDF 뷰어 표시 → ② 이미지 파일 클릭 → 이미지 뷰어 표시 → ③ DOCX 파일 클릭 → 변환 후 PDF 뷰어 표시
> **화면 영역**: 전체 화면 (사이드바에서 파일 선택 + 호버 윈도우의 미리보기 화면)
> **강조**: 파일 유형에 따라 뷰어 화면이 다르게 나타나는 점
> **길이**: 8~12초

---

## PDF 미리보기

PDF 파일은 Notology 안에서 바로 열립니다. 스크롤, 확대/축소, 페이지 이동 등 기본적인 PDF 뷰어 기능을 지원합니다.

- 위키링크, 첨부파일, 사이드바에서 PDF를 클릭하면 호버 윈도우에서 열립니다
- 별도의 PDF 뷰어 프로그램이 필요 없습니다

> 📸 **여기에 GIF** — `images/docpreview-pdf.gif`
>
> **촬영**: 사이드바에서 PDF 파일을 클릭하여 호버 윈도우에서 PDF가 열리고, 스크롤하는 과정
> **순서**: ① 사이드바에서 PDF 파일 클릭 → ② 호버 윈도우에 PDF가 표시됨 → ③ 마우스 스크롤로 페이지 이동
> **화면 영역**: 전체 화면 (사이드바 클릭 + 호버 윈도우의 PDF 뷰어)
> **강조**: PDF가 앱 안에서 바로 렌더링되는 모습
> **길이**: 5~8초

## 이미지 미리보기

이미지 파일은 내장 뷰어에서 바로 표시됩니다.

- **지원 형식**: PNG, JPG/JPEG, GIF, SVG, WebP, BMP
- 호버 윈도우에서 이미지를 바로 확인할 수 있습니다

> 📸 **여기에 GIF** — `images/docpreview-image.gif`
>
> **촬영**: 이미지 파일을 클릭하여 호버 윈도우에서 이미지가 표시되는 과정
> **순서**: ① 사이드바에서 이미지 파일 클릭 → ② 호버 윈도우에 이미지가 표시됨
> **화면 영역**: 전체 화면 (사이드바 클릭 + 호버 윈도우의 이미지 뷰어)
> **강조**: 이미지가 깔끔하게 렌더링되는 모습
> **길이**: 3~5초

## 오피스 문서 미리보기

최신 오피스 문서(`.docx`, `.xlsx`, `.pptx`, `.hwpx`)는 **LibreOffice**를 통해 PDF로 변환한 뒤 표시됩니다.

### 변환 과정

| 단계 | 설명 |
|------|------|
| 1 | 문서를 클릭하면 **변환 중** 스피너가 표시됩니다 |
| 2 | LibreOffice가 백그라운드에서 PDF로 변환합니다 |
| 3 | 변환이 완료되면 PDF가 화면에 표시됩니다 |

### 캐싱

- 한번 변환된 문서는 **캐시에 저장**되어 다음에 열 때 즉시 표시됩니다
- 원본 파일이 수정되면 (수정 시각 변경) 자동으로 다시 변환합니다
- 캐시 위치: `%LOCALAPPDATA%\Notology\preview_cache\`

> 📸 **여기에 GIF** — `images/docpreview-office.gif`
>
> **촬영**: DOCX 파일을 클릭하여 변환 스피너가 표시된 후 PDF로 변환되어 표시되는 전 과정
> **순서**: ① DOCX 파일 클릭 → ② "변환 중" 스피너 표시 → ③ 스피너가 사라지고 변환된 PDF가 화면에 나타남 → ④ 스크롤로 내용 확인
> **화면 영역**: 호버 윈도우 전체 (스피너 → PDF 전환 과정)
> **강조**: 스피너에서 PDF로 전환되는 순간
> **길이**: 5~8초

### 레거시 형식

`.doc`, `.ppt`, `.xls`, `.hwp` 같은 오래된 형식은 변환 없이 **기본 프로그램에서 바로 열립니다**.

## LibreOffice 요구 사항

오피스 문서 미리보기를 사용하려면 **LibreOffice**가 컴퓨터에 설치되어 있어야 합니다.

| 상황 | 동작 |
|------|------|
| LibreOffice **설치됨** | 자동으로 감지되어 문서 변환이 작동합니다 |
| LibreOffice **미설치** | 안내 메시지와 함께 **"앱에서 열기"** 버튼이 표시됩니다 |

- Notology는 LibreOffice 설치 경로를 자동으로 감지합니다 (Program Files 폴더 검색)
- LibreOffice가 없어도 **"앱에서 열기"** 버튼으로 기본 프로그램에서 파일을 열 수 있습니다

> 📸 **여기에 GIF** — `images/docpreview-no-libreoffice.gif`
>
> **촬영**: LibreOffice가 설치되어 있지 않을 때 오피스 문서를 열면 나타나는 안내 화면과 "앱에서 열기" 버튼 클릭
> **순서**: ① DOCX 파일 클릭 → ② "LibreOffice 미설치" 안내 메시지 표시 → ③ "앱에서 열기" 버튼 클릭 → ④ 기본 프로그램(예: MS Word)에서 파일이 열림
> **화면 영역**: 호버 윈도우 전체 (안내 메시지 + 버튼)
> **강조**: 안내 메시지 내용과 "앱에서 열기" 버튼 위치
> **길이**: 5~8초

> **💡 팁**: LibreOffice는 무료 오픈소스 프로그램입니다. [libreoffice.org](https://www.libreoffice.org/)에서 다운로드할 수 있습니다.

## 코드 파일 미리보기

프로그래밍 코드 파일은 **구문 하이라이팅(Syntax Highlighting)** 뷰어로 표시됩니다. 코드의 키워드, 문자열, 주석 등이 색상으로 구분되어 읽기 쉽습니다.

> 📸 **여기에 GIF** — `images/docpreview-code.gif`
>
> **촬영**: 코드 파일(.js 또는 .py)을 클릭하여 구문 하이라이팅된 코드 뷰어가 표시되는 과정
> **순서**: ① 사이드바에서 코드 파일 클릭 → ② 호버 윈도우에 구문 하이라이팅된 코드 표시 → ③ 스크롤로 코드 내용 확인
> **화면 영역**: 전체 화면 (사이드바 클릭 + 호버 윈도우의 코드 뷰어)
> **강조**: 키워드, 문자열, 주석이 다른 색상으로 표시되는 구문 하이라이팅
> **길이**: 3~5초

## 미리보기 열기 방법

문서 미리보기는 여러 곳에서 시작할 수 있습니다.

| 방법 | 설명 |
|------|------|
| **첨부파일 클릭** | 노트 안의 첨부파일 링크를 클릭합니다 |
| **사이드바** | 사이드바에서 파일을 클릭합니다 |
| **위키링크** | `[[파일명]]` 위키링크를 클릭합니다 |
| **검색 결과** | 검색에서 파일을 클릭합니다 |
| **캔버스** | 캔버스의 파일 노드를 더블클릭합니다 |
