## What Is the Canvas?

The **Canvas** is a visual workspace on an infinitely large surface where you can place text, shapes, files, and more wherever you want. Think of it as a whiteboard where you stick notes and draw connecting lines.

- Create mind maps, flowcharts, and diagrams
- Drag note files onto the canvas to visualize their relationships
- Use shapes and arrows to represent workflows

## Creating a Canvas

1. Press `Ctrl + N` to create a new note
2. In the template selection, choose **Sketch**
3. An infinite canvas opens!

> 📸 **GIF placeholder** — `images/canvas-create.gif`
>
> **Shot**: Creating a new note with Ctrl+N and selecting the "Sketch" template to open a canvas
> **Steps**: ① Press Ctrl+N → ② New note dialog → ③ Enter a name → ④ Select "Sketch" as the template → ⑤ Click OK → ⑥ An empty canvas opens
> **Screen area**: Full app window (dialog transitioning to canvas)
> **Highlight**: Selecting the "Sketch" template and the canvas appearing
> **Duration**: 5~8s

## Text Nodes

**Double-click** on an empty area of the canvas to create a text box (node).

- Type freely inside it
- Drag the node to move it anywhere
- Drag a corner to resize it

> 📸 **GIF placeholder** — `images/canvas-create-node.gif`
>
> **Shot**: Double-clicking the canvas to create a text node and typing in it
> **Steps**: ① Double-click on empty canvas space → ② Text node is created → ③ Type text → ④ Click outside the node to finish editing → ⑤ Drag the node to move it
> **Screen area**: Center of the canvas
> **Highlight**: The node appearing on double-click and text being entered
> **Duration**: 5~8s

## Shape Nodes

Six shape types are available. They're especially useful for flowcharts and diagrams.

| Shape | Appearance | When to use |
|-------|-----------|-------------|
| **Process** | Rectangle | General tasks, processing steps |
| **Terminal** | Rounded rectangle | Start and end of a process |
| **Decision** | Diamond | Conditional branches (yes/no) |
| **I/O** | Parallelogram | Data input, output |
| **Subroutine** | Double-bordered rectangle | Sub-processes |
| **Database** | Cylinder | Data stores |

> 📸 **GIF placeholder** — `images/canvas-shapes.gif`
>
> **Shot**: Adding several shapes to the canvas and typing text inside them
> **Steps**: ① Click the shape add menu/button → ② Select "Process" shape → ③ Place it on the canvas → ④ Type text inside the shape → ⑤ Add a "Decision" shape → ⑥ Add a "Terminal" shape
> **Screen area**: Canvas area (including shape selection menu)
> **Highlight**: The different appearance of each shape and text editing inside them
> **Duration**: 8~12s

## File Nodes

**Drag a note or file from the sidebar onto the canvas** to create a file node.

- A preview of the note's content appears as a card
- **Double-click** a file node to open that note in a hover window
- Arrange multiple notes on the canvas to visually map out their relationships

> 📸 **GIF placeholder** — `images/canvas-file-node.gif`
>
> **Shot**: Dragging a note from the sidebar onto the canvas to create a file node
> **Steps**: ① Click and hold a note in the sidebar → ② Drag it onto the canvas → ③ Release the mouse → ④ File node is created (preview card) → ⑤ Double-click the file node → ⑥ Opens in a hover window
> **Screen area**: Sidebar + canvas area
> **Highlight**: The drag-and-drop creating a file node and the preview card
> **Duration**: 5~8s

## Connection Lines (Arrows)

Connect nodes with arrows.

### Creating a Connection

1. Hover over a node to reveal **connection points** (small circles)
2. Drag from a connection point toward another node
3. Release on the other node to create an arrow

### Connection Line Features

- Arrows indicate the direction of flow
- Lines curve naturally between nodes
- Moving a node automatically repositions its connection lines

> 📸 **GIF placeholder** — `images/canvas-create-edge.gif`
>
> **Shot**: Connecting two nodes with an arrow (connection line)
> **Steps**: ① Hover over the first node → ② Connection points appear → ③ Start dragging from a connection point → ④ Drag toward the second node → ⑤ Release the mouse → ⑥ Arrow is created → ⑦ Move a node — the arrow follows
> **Screen area**: Canvas area (both nodes visible)
> **Highlight**: The connection points and the arrow preview during the drag
> **Duration**: 5~8s

## Multi-Select

Hold `Shift` and drag to select multiple nodes within the selection area.

- Move all selected nodes together
- Press `Delete` to delete all selected nodes at once

> 📸 **GIF placeholder** — `images/canvas-multiselect.gif`
>
> **Shot**: Shift+drag to select multiple nodes and move them together
> **Steps**: ① Several nodes on the canvas → ② Hold Shift and drag → ③ Selection box appears → ④ Selected nodes become highlighted → ⑤ Drag the selected nodes together
> **Screen area**: Canvas area
> **Highlight**: The selection box and highlighted nodes
> **Duration**: 3~5s

## Flowchart Example

Here's what a simple flowchart looks like on the canvas.

```
┌─────────────┐
│  Start (Terminal) │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ Data Input (I/O)  │
└──────┬──────┘
       │
       ▼
  ◆ Condition met? ◆ ── No ──→ ┌──────────┐
  (Decision)                    │ Error     │
       │                        │ Handling  │
      Yes                       │ (Process) │
       │                        └──────────┘
       ▼
┌─────────────┐
│ Process         │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  End (Terminal)   │
└─────────────┘
```

> 📸 **GIF placeholder** — `images/canvas-flowchart-demo.gif`
>
> **Shot**: Building the flowchart above on the canvas (quick demo)
> **Steps**: ① Add a Terminal shape ("Start") → ② Add an I/O shape ("Data Input") → ③ Connect with an arrow → ④ Add a Decision shape ("Condition met?") → ⑤ Connect with an arrow → ⑥ Add Process shapes → ⑦ Complete all connections → ⑧ View the finished flowchart
> **Screen area**: Full canvas screen
> **Highlight**: The flow from adding shapes to connecting to completing the chart
> **Duration**: 8~12s
