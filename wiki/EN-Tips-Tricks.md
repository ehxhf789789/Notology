A collection of practical know-how to help you get the most out of Notology.

## Productivity Tips

### 1. Add 1-2 Wikilinks to Every Note

Whenever you write a new note, add 1 or 2 `[[wikilinks]]` to related notes. Over time, this naturally builds a knowledge network.

- Check your connection map at a glance in the [Graph View](EN-Graph-View)
- When looking for related information later, just follow the links to get there fast

> 📸 **GIF placeholder** — `images/tips-wikilink-habit.gif`
>
> **Shot**: Adding a `[[wikilink]]` to a note and then checking the connection in the graph view
> **Steps**: ① Type `[[` in the editor → ② Select a note from the autocomplete list → ③ Wikilink is inserted → ④ Switch to graph view → ⑤ See the two notes now connected by a line
> **Screen area**: Full screen (wikilink entry in the editor → switching to graph view)
> **Highlight**: The wikilink autocomplete dropdown, and the new connection line in the graph
> **Duration**: 8~12s

### 2. Fold Headings to Tame Long Documents

For long documents, use the **heading fold** feature to keep only the section you're working on expanded.

- Click the **▶ button** to the left of a heading to collapse that section
- Expand only what you need to stay focused
- Code blocks can be folded too

> 📸 **GIF placeholder** — `images/tips-fold-sections.gif`
>
> **Shot**: Folding and unfolding multiple heading sections in a long document
> **Steps**: ① Click the ▶ button next to a heading in a long document → section collapses → ② Fold another section → ③ Click ▶ to expand only the section you need → ④ Fold/unfold a code block
> **Screen area**: Entire editor body area
> **Highlight**: The ▶/▼ fold/unfold buttons next to headings, the visual indication of collapsed sections
> **Duration**: 5~8s

---

### 3. Use Hover Windows Like a Dual Monitor

Open multiple [hover windows](EN-Hover-Windows) to split your screen view.

- Place a reference note on the left and your working note on the right
- Great for multitasking — write a summary while reading meeting notes, for example
- Hover windows can be freely moved and resized

> 📸 **GIF placeholder** — `images/tips-dual-view.gif`
>
> **Shot**: Placing two hover windows side by side, referencing one while writing in the other
> **Steps**: ① Open the first note as a hover window → ② Move it to the left side of the screen → ③ Open a second note as a hover window → ④ Place it on the right side → ⑤ Work back and forth between the two windows
> **Screen area**: Full screen (two hover windows arranged side by side)
> **Highlight**: The side-by-side layout of the two windows, switching between them
> **Duration**: 8~12s

## Organization Tips

### 5. Use Tag Namespaces for Systematic Classification

Add prefixes to your [tags](EN-Tags) to create a classification system.

| Prefix | Purpose | Examples |
|--------|---------|----------|
| `domain:` | Field | `domain:development`, `domain:marketing` |
| `who:` | Person | `who:john`, `who:sarah` |
| `org:` | Organization | `org:planning`, `org:external-vendorA` |
| `ctx:` | Status/context | `ctx:urgent`, `ctx:done`, `ctx:on-hold` |

Tags with the same prefix naturally form groups, making management much easier.

---

### 6. Create a Container for Each Project

Create a Standard container for each active project to gather all related notes in one place.

- Organize the folder structure however you like within each project
- When a project wraps up, just collapse the container
- Expand it anytime you need to revisit

### 7. Do a Daily Review with the Calendar

At the end of the day, click today's date in the [Calendar](EN-Calendar) to review the memos you wrote.

- See at a glance what you worked on today
- Check incomplete items and plan for tomorrow
- Just 5 minutes a day can greatly improve your workflow

> 📸 **GIF placeholder** — `images/tips-daily-review.gif`
>
> **Shot**: Clicking today's date in the calendar and reviewing memos and incomplete to-dos
> **Steps**: ① Open the calendar (Ctrl+Shift+C) → ② Click today's date → ③ Review the list of today's memos → ④ Switch to the To-do tab → ⑤ Check incomplete items
> **Screen area**: Entire right panel (calendar + memo/to-do list)
> **Highlight**: Today's memo/to-do counts, incomplete items
> **Duration**: 5~8s

## Search Tips

### 8. Combine Filters for Precise Results

Use multiple filters together in [Search](EN-Search) to find exactly the note you need.

- **Keyword** + **tag filter**: Search for a keyword only among notes with a specific tag
- **Keyword** + **date filter**: Search within a specific time period
- **Keyword** + **type filter**: Search only a specific type (note/canvas)

---

### 9. Use `[[` as a Quick Note Finder

Type `[[` in the editor and an autocomplete list of all notes appears.

- Start typing a note name to filter the list
- Even if you don't plan to create a link, it's a quick way to find any note
- Press Esc to dismiss the autocomplete

## Canvas Tips

### 10. Map Project Structures on the Canvas

Use the [Canvas](EN-Canvas) to visually lay out your project's structure.

- Draw workflow processes as flowcharts
- Organize ideas as mind maps
- Visualize system architecture as diagrams

> **Highlight**: Node creation, connection dragging, and the overall structure when complete

---

### 11. Create Note Maps with File Nodes

Add **file nodes** to the canvas to place actual notes on it.

- Drag a note from the sidebar onto the canvas to create a file node
- Double-click to open that note
- Arrange related notes spatially to intuitively understand their relationships

## Performance Tips

### 12. Use Sidebar Favorites

Add frequently used notes or folders to your favorites. Access them instantly without digging through the folder tree every time.

---

### 13. Adjust Editor Zoom for Comfort

Use `Ctrl + mouse wheel` to adjust the editor's text size.

- Zoom in when reading long documents for comfortable reading
- Zoom out to see the overall structure at a glance
- Check and reset your zoom level in Settings

---

### 14. Keyboard-First Workflow

Minimize mouse usage by relying on keyboard shortcuts — it can significantly boost your speed.

| Task | Shortcut |
|------|----------|
| New note | `Ctrl + N` |
| Search | `Ctrl + Shift + F` |
| Toggle sidebar | `Ctrl + ←` |
| Wikilink | Type `[[` |
| Bold | `Ctrl + B` |

See the [Keyboard Shortcuts](EN-Keyboard-Shortcuts) page for the full list.

## Backup Tips

### 15. Back Up Your Vault Folder Regularly

All your notes in Notology are **plain markdown files**, so simply copying the vault folder is a complete backup.

| Backup Method | Frequency | Description |
|---------------|-----------|-------------|
| **USB / external drive** | Weekly | Copy the entire vault folder |
| **Cloud** | Automatic | Place your vault inside a OneDrive, Google Drive, or similar folder |
| **Git** | As needed | Developers can use Git for version control, which also tracks change history |

> **Important**: Your note files are not locked into any specific app. Even if you stop using Notology, you can always open all your notes in any other markdown editor.
