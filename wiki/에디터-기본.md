# <img src="images/icons/type.png" width="24" height="24"> 에디터 기본

글꼴 꾸미기, 제목, 목록, 표, 이미지 등 에디터의 기본 기능을 알아봅니다.

---

## 도구 모음 (툴바)

에디터 위쪽에 있는 버튼 줄입니다. 버튼을 클릭하면 바로 서식이 적용됩니다. 단축키를 쓰면 더 빠릅니다.

> 📸 **여기에 GIF** — `images/editor-toolbar.gif`
>
> **촬영**: 도구 모음의 각 버튼 영역을 마우스로 가리키면서 전체적으로 훑어보는 모습
> **순서**: ① 도구 모음 왼쪽부터 오른쪽으로 마우스 이동 → ② 텍스트 서식 버튼들 → ③ 제목 드롭다운 → ④ 목록 버튼들 → ⑤ 삽입 버튼들 (표, 이미지 등)
> **화면 영역**: 에디터 상단 도구 모음 영역만
> **강조**: 마우스가 각 버튼 위를 지날 때 나타나는 툴팁
> **길이**: 5~8초

## 텍스트 서식

글씨를 꾸미는 기능입니다. 텍스트를 먼저 선택한 후 버튼을 누르거나 단축키를 쓰면 됩니다.

| 서식 | 단축키 | 마크다운 입력 | 결과 |
|------|--------|-------------|------|
| **굵게** | `Ctrl + B` | `**텍스트**` | **텍스트** |
| *기울임* | `Ctrl + I` | `*텍스트*` | *텍스트* |
| <u>밑줄</u> | `Ctrl + U` | — | 밑줄 텍스트 |
| ~~취소선~~ | `Ctrl + Shift + X` | `~~텍스트~~` | ~~텍스트~~ |
| `인라인 코드` | `Ctrl + E` | `` `텍스트` `` | `텍스트` |
| 형광펜 | 도구 모음에서 선택 | — | 강조 표시된 텍스트 |
| 위첨자 | 도구 모음에서 선택 | — | 텍스트^위^ |
| 아래첨자 | 도구 모음에서 선택 | — | 텍스트~아래~ |

> 📸 **여기에 GIF** — `images/editor-text-formatting.gif`
>
> **촬영**: 텍스트를 선택한 후 여러 서식을 적용하는 모습
> **순서**: ① 텍스트 입력 → ② 텍스트 드래그로 선택 → ③ Ctrl+B로 굵게 → ④ 다른 텍스트 선택 → ⑤ Ctrl+I로 기울임 → ⑥ 형광펜 버튼 클릭
> **화면 영역**: 에디터 본문 영역 (도구 모음 일부 포함)
> **강조**: 서식이 적용되는 순간의 텍스트 변화
> **길이**: 5~8초

## 제목 (H1 ~ H6)

제목은 6단계까지 있습니다. `#`의 개수가 많을수록 작은 제목이 됩니다.

| 입력 | 결과 | 이럴 때 쓰세요 |
|------|------|--------------|
| `# 제목` | 제목 1 (가장 큼) | 문서 제목 |
| `## 제목` | 제목 2 | 큰 분류 |
| `### 제목` | 제목 3 | 중간 분류 |
| `#### 제목` | 제목 4 | 작은 분류 |
| `##### 제목` | 제목 5 | 세부 항목 |
| `###### 제목` | 제목 6 (가장 작음) | 최하위 항목 |

> 📸 **여기에 GIF** — `images/editor-headings.gif`
>
> **촬영**: # 기호를 입력해서 H1~H3 제목을 만드는 과정
> **순서**: ① "# 큰 제목" 입력 → ② 엔터 → ③ "## 중간 제목" 입력 → ④ 엔터 → ⑤ "### 작은 제목" 입력 → ⑥ 각 제목 크기 비교
> **화면 영역**: 에디터 본문 영역만
> **강조**: #을 입력하면 바로 제목 서식이 적용되는 모습
> **길이**: 5~8초

### 제목 접기/펼치기

제목 왼쪽의 **화살표 버튼**을 클릭하면 그 제목 아래 내용을 접거나 펼 수 있습니다.

- 접으면 같은 단계의 다음 제목까지의 내용이 숨겨집니다
- 긴 문서에서 보고 싶은 부분만 골라서 볼 수 있어요

> 📸 **여기에 GIF** — `images/editor-heading-fold.gif`
>
> **촬영**: 제목 왼쪽 화살표를 클릭해서 섹션을 접고 펼치는 모습
> **순서**: ① 긴 문서에서 제목이 여러 개 보임 → ② 첫 번째 제목의 화살표 클릭 → ③ 내용이 접힘 → ④ 다시 화살표 클릭 → ⑤ 내용이 펼쳐짐
> **화면 영역**: 에디터 본문 영역만
> **강조**: 화살표 버튼 클릭과 내용이 접히는/펼쳐지는 애니메이션
> **길이**: 3~5초

## 목록

### 글머리 기호 목록

줄 앞에 `-`를 쓰고 한 칸 띄우면 글머리 기호 목록이 됩니다.

```
- 첫 번째 항목
- 두 번째 항목
  - 하위 항목 (Tab 키로 들여쓰기)
```

### 번호 목록

줄 앞에 `1.`을 쓰고 한 칸 띄우면 번호 목록이 됩니다.

```
1. 첫 번째 단계
2. 두 번째 단계
3. 세 번째 단계
```

### 체크리스트

줄 앞에 `- [ ]`를 입력하면 체크리스트가 됩니다. 체크박스를 클릭해서 완료 표시를 할 수 있습니다.

```
- [ ] 해야 할 일
- [x] 완료한 일
```

### 들여쓰기

| 단축키 | 하는 일 |
|--------|---------|
| `Tab` | 목록을 한 단계 안으로 들이기 |
| `Shift + Tab` | 목록을 한 단계 밖으로 빼기 |

> 📸 **여기에 GIF** — `images/editor-lists.gif`
>
> **촬영**: 글머리 기호 목록, 번호 목록, 체크리스트를 차례로 만드는 모습
> **순서**: ① "- " 입력으로 글머리 목록 만들기 → ② Tab으로 하위 항목 → ③ "1. " 입력으로 번호 목록 → ④ "- [ ]" 입력으로 체크리스트 → ⑤ 체크박스 클릭
> **화면 영역**: 에디터 본문 영역만
> **강조**: 마크다운 입력이 실시간으로 목록으로 변환되는 모습
> **길이**: 8~12초

## 인용문

줄 앞에 `>`를 쓰고 한 칸 띄우면 인용문이 됩니다.

```
> 이것은 인용문입니다.
> 여러 줄로 쓸 수 있습니다.
```

> 📸 **여기에 GIF** — `images/editor-blockquote.gif`
>
> **촬영**: > 기호를 입력해서 인용문을 만드는 과정
> **순서**: ① "> " 입력 → ② 인용문 블록으로 변환됨 → ③ 텍스트 입력 → ④ 엔터로 다음 줄 계속 입력
> **화면 영역**: 에디터 본문 영역만
> **강조**: > 입력 시 인용문 스타일이 적용되는 순간
> **길이**: 3~5초

## 표 (테이블)

### 표 만들기

도구 모음에서 **표 버튼**을 클릭하고 원하는 행/열 수를 고릅니다.

### 표 편집하기

| 할 일 | 방법 |
|-------|------|
| 행 추가 | 표 안에서 우클릭 → 행 추가 (위/아래) |
| 행 삭제 | 표 안에서 우클릭 → 행 삭제 |
| 열 추가 | 표 안에서 우클릭 → 열 추가 (왼쪽/오른쪽) |
| 열 삭제 | 표 안에서 우클릭 → 열 삭제 |
| 셀 배경색 | 셀을 선택하고 우클릭 → 배경색 고르기 |
| 셀 병합 | 여러 셀을 선택하고 우클릭 → 셀 병합 |

> 📸 **여기에 GIF** — `images/editor-table.gif`
>
> **촬영**: 표를 삽입하고 행/열을 추가하며 배경색을 바꾸는 과정
> **순서**: ① 도구 모음에서 표 버튼 클릭 → ② 3x3 표 선택 → ③ 표 생성됨 → ④ 셀에 텍스트 입력 → ⑤ 우클릭으로 행 추가 → ⑥ 셀 배경색 변경
> **화면 영역**: 에디터 도구 모음 + 본문 영역
> **강조**: 표 삽입 그리드 선택과 우클릭 메뉴
> **길이**: 8~12초

## 이미지

노트에 이미지를 넣는 방법입니다.

| 방법 | 설명 |
|------|------|
| 드래그 앤 드롭 | 이미지 파일을 에디터로 끌어다 놓습니다 |
| 붙여넣기 | 스크린샷을 찍은 뒤 `Ctrl + V`로 붙여넣습니다 |
| 도구 모음 | 이미지 버튼을 클릭해서 파일을 선택합니다 |

> 📸 **여기에 GIF** — `images/editor-image-insert.gif`
>
> **촬영**: 이미지를 에디터로 드래그 앤 드롭하여 삽입하는 모습
> **순서**: ① Windows 탐색기에서 이미지 파일 선택 → ② 에디터로 드래그 → ③ 이미지가 노트에 삽입됨 → ④ 삽입된 이미지 크기 확인
> **화면 영역**: 에디터 영역 (Windows 탐색기 일부 포함)
> **강조**: 이미지가 에디터에 삽입되는 순간
> **길이**: 3~5초

## 구분선

`---`를 입력하면 가로 구분선이 들어갑니다.

- 구분선 위에 마우스를 올리면 **삭제 버튼**이 나타납니다
- 삭제 버튼을 클릭하면 구분선을 지울 수 있습니다

> 📸 **여기에 GIF** — `images/editor-hr.gif`
>
> **촬영**: ---을 입력해서 구분선을 만들고, 마우스를 올려 삭제 버튼을 보여주는 모습
> **순서**: ① "---" 입력 → ② 구분선으로 변환됨 → ③ 구분선에 마우스 올리기 → ④ 삭제 버튼 나타남 → ⑤ 삭제 버튼 클릭 → ⑥ 구분선 사라짐
> **화면 영역**: 에디터 본문 영역만
> **강조**: 삭제 버튼이 나타나는 모습
> **길이**: 3~5초

## 텍스트 정렬

글을 왼쪽, 가운데, 오른쪽, 양쪽으로 정렬할 수 있습니다.

| 정렬 | 설명 |
|------|------|
| 왼쪽 정렬 | 기본값 — 글이 왼쪽에 붙습니다 |
| 가운데 정렬 | 글이 한가운데에 옵니다 |
| 오른쪽 정렬 | 글이 오른쪽에 붙습니다 |
| 양쪽 정렬 | 글이 양쪽 끝에 맞춰 정렬됩니다 |

> 📸 **여기에 GIF** — `images/editor-alignment.gif`
>
> **촬영**: 텍스트의 정렬을 왼쪽 → 가운데 → 오른쪽으로 바꾸는 모습
> **순서**: ① 텍스트 입력 (왼쪽 정렬 상태) → ② 가운데 정렬 버튼 클릭 → ③ 텍스트가 가운데로 이동 → ④ 오른쪽 정렬 버튼 클릭 → ⑤ 텍스트가 오른쪽으로 이동
> **화면 영역**: 에디터 도구 모음 + 본문 영역
> **강조**: 정렬 버튼 클릭에 따른 텍스트 위치 변화
> **길이**: 3~5초

## 콜아웃

중요한 내용을 강조하는 색상 상자입니다. 도구 모음에서 **콜아웃 버튼**을 클릭해서 넣습니다.

| 종류 | 색상 | 이럴 때 쓰세요 |
|------|------|--------------|
| **Info** | 파랑 | 참고 정보, 설명 |
| **Warning** | 노랑 | 주의사항, 경고 |
| **Error** | 빨강 | 위험, 금지 사항 |
| **Success** | 초록 | 성공, 완료 |
| **Note** | 회색 | 일반 메모 |
| **Tip** | 보라 | 팁, 요령 |

> 📸 **여기에 GIF** — `images/editor-callout.gif`
>
> **촬영**: 콜아웃을 삽입하고 유형을 바꿔보는 과정
> **순서**: ① 도구 모음에서 콜아웃 버튼 클릭 → ② 콜아웃 유형 선택 (예: Info) → ③ 파란 콜아웃 상자 생성 → ④ 안에 텍스트 입력 → ⑤ 유형을 Warning으로 변경 → ⑥ 색상이 노랑으로 바뀜
> **화면 영역**: 에디터 도구 모음 + 본문 영역
> **강조**: 각 콜아웃 유형의 색상 차이
> **길이**: 5~8초

## 링크 카드

URL을 입력하면 자동으로 예쁜 미리보기 카드가 만들어집니다. 웹사이트의 제목, 설명, 이미지가 카드 형태로 보입니다.

> 📸 **여기에 GIF** — `images/editor-link-card.gif`
>
> **촬영**: URL을 붙여넣으면 링크 카드가 자동 생성되는 과정
> **순서**: ① URL 텍스트 붙여넣기 (Ctrl+V) → ② 잠시 로딩 → ③ 미리보기 카드로 변환됨 (제목, 설명, 이미지 표시)
> **화면 영역**: 에디터 본문 영역만
> **강조**: URL이 카드로 변환되는 순간
> **길이**: 3~5초

## 자동 저장

노트를 수정하면 **1초 뒤에 자동으로 저장**됩니다.

- 저장 버튼을 따로 누를 필요가 없습니다
- 설정에서 자동 저장 간격을 바꿀 수 있습니다
- 저장 중에는 상태 표시가 나타납니다

## 우클릭 메뉴 (컨텍스트 메뉴)

에디터 안에서 마우스 오른쪽 버튼을 누르면 상황에 맞는 메뉴가 나옵니다.

- **텍스트를 선택한 상태**: 서식 변경, 복사, 붙여넣기, 메모 추가
- **표 안에서**: 행/열 추가/삭제, 셀 배경색, 셀 병합
- **이미지에서**: 크기 변경, 정렬
- **링크에서**: 링크 열기, 수정, 삭제

> 📸 **여기에 GIF** — `images/editor-context-menu.gif`
>
> **촬영**: 에디터에서 텍스트 선택 후 우클릭 메뉴를 사용하는 모습
> **순서**: ① 텍스트 선택 → ② 우클릭 → ③ 컨텍스트 메뉴 나타남 → ④ "굵게" 선택 → ⑤ 서식 적용됨 → ⑥ 표 셀 안에서 우클릭 → ⑦ 표 전용 메뉴 나타남
> **화면 영역**: 에디터 본문 영역 (컨텍스트 메뉴 포함)
> **강조**: 상황에 따라 다른 메뉴가 나타나는 것
> **길이**: 5~8초
