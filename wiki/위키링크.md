# <img src="images/icons/link.png" width="24" height="24"> 위키링크

노트와 노트를 연결하는 위키링크에 대해 알아봅니다. 노트를 서로 연결하면 나중에 관련 내용을 쉽게 찾을 수 있습니다.

---

## 위키링크란?

**위키링크**는 `[[노트 이름]]` 형식으로 노트끼리 연결하는 기능입니다.

- 위키백과에서 파란 글씨를 클릭하면 다른 문서로 이동하는 것과 같은 원리입니다
- 노트 A에서 `[[노트 B]]`라고 쓰면, 클릭 한 번으로 노트 B를 열 수 있습니다
- 연결된 노트들의 관계를 [그래프 뷰](그래프-뷰)에서 그림으로 볼 수 있습니다

> 📸 **여기에 GIF** — `images/wikilink-concept.gif`
>
> **촬영**: 노트 안에 [[위키링크]]가 있고, 클릭하면 다른 노트가 열리는 기본 개념 시연
> **순서**: ① 에디터에 [[노트이름]] 형태의 위키링크가 보임 → ② 위키링크가 파란 글씨로 표시됨 → ③ 위키링크 클릭 → ④ 호버 윈도우에서 해당 노트가 열림
> **화면 영역**: 에디터 영역 + 호버 윈도우
> **강조**: 위키링크의 파란 글씨와 클릭 시 호버 윈도우가 뜨는 모습
> **길이**: 3~5초

---

## 위키링크 만들기

### 방법 1: `[[` 입력

가장 많이 쓰는 방법입니다.

1. 에디터에서 `[[`를 입력합니다
2. 자동완성 목록에 내 노트들이 나타납니다
3. 연결할 노트를 고르거나 이름을 직접 입력합니다
4. `]]`로 닫습니다 (자동완성으로 고르면 자동으로 닫힘)

### 방법 2: `@` 멘션

1. 에디터에서 `@`를 입력합니다
2. 노트 목록이 나타납니다
3. 원하는 노트를 선택합니다

> 📸 **여기에 GIF** — `images/wikilink-create.gif`
>
> **촬영**: [[ 입력으로 위키링크를 만드는 전체 과정
> **순서**: ① 에디터에서 "[["  입력 → ② 자동완성 드롭다운 나타남 → ③ 글자 더 입력해서 필터링 → ④ 방향키로 노트 선택 → ⑤ Enter 누름 → ⑥ 위키링크 완성 ([[노트이름]])
> **화면 영역**: 에디터 본문 영역 (자동완성 드롭다운 포함)
> **강조**: 자동완성 목록이 나타나는 순간과 선택하는 모습
> **길이**: 5~8초

> 📸 **여기에 GIF** — `images/wikilink-mention.gif`
>
> **촬영**: @ 멘션으로 위키링크를 만드는 과정
> **순서**: ① "@" 입력 → ② 노트 목록 나타남 → ③ 노트 선택 → ④ 멘션 링크 완성
> **화면 영역**: 에디터 본문 영역 (드롭다운 포함)
> **강조**: @ 입력 시 나타나는 목록
> **길이**: 3~5초

> **💡 팁**: 글자를 더 입력하면 목록이 좁아져서 원하는 노트를 빨리 찾을 수 있습니다.

---

## 위키링크 클릭하기

위키링크를 클릭하면 **호버 윈도우**로 해당 노트가 열립니다.

- 지금 쓰고 있는 노트는 그대로 유지됩니다
- 연결된 노트를 참고하면서 글을 계속 쓸 수 있습니다

> 📸 **여기에 GIF** — `images/wikilink-click.gif`
>
> **촬영**: 위키링크를 클릭해서 호버 윈도우로 노트를 여는 과정
> **순서**: ① 에디터에서 위키링크가 보임 → ② 위키링크 클릭 → ③ 호버 윈도우가 열림 → ④ 호버 윈도우에서 내용 확인 → ⑤ 메인 에디터로 돌아가서 계속 작성
> **화면 영역**: 에디터 영역 + 호버 윈도우
> **강조**: 클릭 순간과 호버 윈도우가 뜨는 모습
> **길이**: 3~5초

---

## 존재하지 않는 노트 링크

아직 안 만든 노트 이름으로도 위키링크를 미리 만들어둘 수 있습니다.

- 아직 없는 노트의 위키링크는 **흐린 색**으로 표시됩니다
- 그 링크를 클릭하면 새 노트를 만들 수 있습니다
- "나중에 쓸 노트"를 미리 연결해두면 편리합니다

| 상태 | 어떻게 보이나요? |
|------|----------------|
| 이미 있는 노트 | 일반 파란 글씨 |
| 아직 없는 노트 | 흐린 색 글씨 (클릭하면 새로 만들 수 있음) |

## 이름 바꾸면 자동 업데이트

노트 이름을 바꾸면 Vault 전체에서 그 노트를 가리키는 **모든 위키링크가 자동으로 바뀝니다**.

- 예: "프로젝트 계획"을 "2024년 프로젝트 계획"으로 바꾸면
- Vault 안의 모든 `[[프로젝트 계획]]`이 `[[2024년 프로젝트 계획]]`으로 변경됩니다
- 일일이 고칠 필요가 없어요!

> 📸 **여기에 GIF** — `images/wikilink-auto-update.gif`
>
> **촬영**: 노트 이름을 바꾸고 다른 노트의 위키링크가 자동으로 바뀌는 것을 확인하는 과정
> **순서**: ① 사이드바에서 노트 이름 바꾸기 → ② 새 이름 입력 → ③ 확인 → ④ 다른 노트 열기 → ⑤ 위키링크가 새 이름으로 바뀌어 있는 것 확인
> **화면 영역**: 사이드바 + 에디터 영역
> **강조**: 이름 변경 전의 위키링크와 변경 후의 위키링크 비교
> **길이**: 5~8초

---

## 양방향 링크 (백링크)

위키링크는 **양방향**입니다.

- 노트 A에서 `[[노트 B]]`를 만들면
- 노트 B의 **백링크** 목록에 노트 A가 자동으로 나타납니다
- 오른쪽 패널에서 "이 노트를 어디서 참조하고 있는지" 한눈에 볼 수 있습니다

쉽게 말해, 내가 다른 노트를 연결하면 상대 노트에서도 나를 알 수 있다는 뜻입니다.

---

## 그래프 뷰와 연동

위키링크로 연결된 노트들의 관계를 [그래프 뷰](그래프-뷰)에서 그림으로 볼 수 있습니다.

- 각 노트가 점(노드)으로 표시됩니다
- 위키링크로 연결된 노트 사이에 선이 그어집니다
- 많이 참조되는 노트는 더 크게 표시됩니다

> 📸 **여기에 GIF** — `images/wikilink-graph.gif`
>
> **촬영**: 그래프 뷰에서 위키링크로 연결된 노트들의 관계를 확인하는 모습
> **순서**: ① 그래프 뷰 열기 → ② 노트들이 점으로 표시됨 → ③ 연결선 확인 → ④ 특정 노트 위에 마우스 올리기 → ⑤ 연결된 노트들이 강조됨
> **화면 영역**: 그래프 뷰 전체 화면
> **강조**: 노트 위에 마우스 올릴 때 연결선이 강조되는 모습
> **길이**: 5~8초

## 활용 예시

### 프로젝트 관리

```
[[프로젝트 개요]] 문서에서 각 단계를 링크합니다:
- [[1단계: 기획]]
- [[2단계: 개발]]
- [[3단계: 테스트]]

각 단계 노트에서 관련 [[회의록 0115]], [[회의록 0122]]를 참조합니다.
```

### 지식 연결

```
[[머신러닝]] 노트에서 관련 개념을 연결합니다:
- 기초: [[선형대수]], [[통계학]]
- 알고리즘: [[신경망]], [[의사결정트리]]
- 응용: [[자연어처리]], [[컴퓨터비전]]
```

### 일일 기록

```
[[2024-01-15 일지]]에서 오늘 진행한 내용을 기록하고
관련 노트를 연결합니다:
- [[프로젝트A]] 진행상황 업데이트
- [[홍길동]] 님과 미팅 — [[회의록 0115]] 참고
```
