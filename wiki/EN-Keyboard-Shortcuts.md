# <img src="images/icons/keyboard.png" width="24" height="24"> Keyboard Shortcuts

Keyboard shortcuts let you work faster without reaching for the mouse. Learning the shortcuts for frequently used features can significantly speed up your workflow.

---

## Global Shortcuts

These shortcuts work anywhere in the app.

| Shortcut | Action |
|----------|--------|
| `Ctrl + N` | Create a new note |
| `Ctrl + Shift + F` | Open search |
| `Ctrl + Shift + C` | Open calendar |
| `Ctrl + ←` | Toggle sidebar open/closed |
| `Ctrl + →` | Toggle right panel open/closed |

> 📸 **GIF placeholder** — `images/shortcuts-global.gif`
>
> **Shot**: Demonstrating global shortcuts one after another (new note, search, calendar, sidebar toggle)
> **Steps**: ① Ctrl+N → new note dialog opens (press Esc to close) → ② Ctrl+Shift+F → search panel opens (press Esc to close) → ③ Ctrl+Shift+C → calendar opens → ④ Ctrl+← → sidebar collapses/expands
> **Screen area**: Full screen (UI elements opening and closing with each shortcut)
> **Highlight**: The UI change after each shortcut is pressed (a keyboard overlay showing the keys would be ideal)
> **Duration**: 8~12s

## Text Formatting Shortcuts

Use these after selecting text in the editor.

| Shortcut | Action | Result |
|----------|--------|--------|
| `Ctrl + B` | **Bold** | **Bold text like this** |
| `Ctrl + I` | *Italic* | *Italicized text like this* |
| `Ctrl + U` | <u>Underline</u> | Underlined text |
| `Ctrl + Shift + X` | ~~Strikethrough~~ | ~~Crossed out text like this~~ |
| `Ctrl + E` | `Inline code` | Text displayed as code |

> 📸 **GIF placeholder** — `images/shortcuts-formatting.gif`
>
> **Shot**: Selecting text in the editor and applying formatting shortcuts (bold, italic, underline, etc.)
> **Steps**: ① Type some text and select it by dragging → ② Ctrl+B → bold applied → ③ Select other text → Ctrl+I → italic applied → ④ Ctrl+U → underline applied → ⑤ Ctrl+E → inline code applied
> **Screen area**: Editor body area only (text selection + formatting changes visible)
> **Highlight**: The text selection range and the visual change before and after formatting
> **Duration**: 8~12s

## Block Shortcuts

Shortcuts for manipulating paragraphs and lists.

| Shortcut | Action |
|----------|--------|
| `Tab` | Indent (move one level in) |
| `Shift + Tab` | Outdent (move one level out) |
| `Enter` | New line / new list item |
| `Shift + Enter` | Line break within the same block |

## Editor Triggers

Typing certain characters automatically activates features.

| Trigger | Feature | Description |
|---------|---------|-------------|
| `[[` | Wikilink | Link to another note. An autocomplete list appears |
| `@` | Mention | Mention a note or person |
| `//` | Attachment | Attach a file. A file list appears |
| `#` + space | Heading | `# ` for Heading 1, `## ` for Heading 2, `### ` for Heading 3 |
| `-` + space | Bullet list | Starts a bulleted list |
| `1.` + space | Numbered list | Starts a numbered list |
| `- [ ]` + space | Checklist | Starts a list with checkboxes |
| `>` + space | Block quote | Starts a quote block |
| ` ``` ` | Code block | Starts a code block |
| `---` | Horizontal rule | Inserts a horizontal divider line |

> 📸 **GIF placeholder** — `images/shortcuts-triggers.gif`
>
> **Shot**: Typing trigger characters (`[[`, `@`, `//`, etc.) in the editor to show autocomplete lists
> **Steps**: ① Type `[[` → wikilink autocomplete list appears → press Esc to close → ② Type `@` → mention autocomplete appears → press Esc to close → ③ Type `//` → attachment list appears → press Esc to close → ④ Type `# ` → text converts to a heading
> **Screen area**: Editor body area (cursor position + autocomplete dropdown)
> **Highlight**: The autocomplete dropdown menus that appear after typing trigger characters
> **Duration**: 8~12s

## Canvas Shortcuts

Shortcuts for use in canvas mode.

| Shortcut | Action |
|----------|--------|
| `Delete` | Delete the selected node/edge |
| `Shift + drag` | Select multiple nodes by area |
| `Ctrl + mouse wheel` | Zoom canvas in/out |
| Double-click (empty space) | Create a new text node |
| Double-click (node) | Enter node edit mode |

## Customizing Shortcuts

You can change shortcuts to any key combination you prefer.

1. Open **Settings** (click the ⚙ button at the bottom of the sidebar)
2. Select the **Shortcuts** tab
3. Click the shortcut you want to change
4. Press the new key combination
5. Save

> 📸 **GIF placeholder** — `images/shortcuts-customize.gif`
>
> **Shot**: Changing an existing shortcut to a new key combination in Settings > Shortcuts tab
> **Steps**: ① Open Settings (click ⚙) → ② Select the Shortcuts tab → ③ Click the shortcut entry to change → ④ Key input mode activates (waiting for input) → ⑤ Press the new key combination → ⑥ Change confirmed
> **Screen area**: Entire Shortcuts tab in the settings modal
> **Highlight**: The visual indicator for key input waiting state, and the key binding text changing before and after
> **Duration**: 5~8s
