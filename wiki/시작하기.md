# <img src="images/icons/rocket.png" width="24" height="24"> 시작하기

Notology를 처음 쓰시나요? 이 페이지를 따라하면 5분 안에 첫 번째 노트를 만들 수 있습니다.

---

## 설치하기

Notology는 Windows 전용 데스크톱 앱입니다. 아래 순서대로 따라하세요.

| 단계 | 할 일 |
|------|-------|
| 1 | [GitHub Releases](https://github.com/your-repo/releases) 페이지에서 최신 `.msi` 파일을 다운로드합니다 |
| 2 | 다운로드한 `.msi` 파일을 더블클릭해서 실행합니다 |
| 3 | 설치 화면이 나타나면 **다음** 버튼을 계속 눌러 설치를 끝냅니다 |
| 4 | 바탕화면 또는 시작 메뉴에서 **Notology** 아이콘을 클릭해서 실행합니다 |

> 📸 **여기에 GIF** — `images/install-download.gif`
>
> **촬영**: GitHub Releases 페이지에서 .msi 파일을 다운로드하는 과정
> **순서**: ① 브라우저에서 Releases 페이지 열기 → ② 최신 버전의 .msi 파일 클릭 → ③ 다운로드 완료 확인
> **화면 영역**: 브라우저 전체 화면
> **강조**: .msi 파일 링크를 클릭하는 순간
> **길이**: 5~8초

> 📸 **여기에 GIF** — `images/install-wizard.gif`
>
> **촬영**: 설치 마법사 진행 과정
> **순서**: ① .msi 파일 더블클릭 → ② 설치 마법사 시작 화면 → ③ "다음" 클릭 반복 → ④ 설치 완료 → ⑤ Notology 실행
> **화면 영역**: 설치 마법사 창 중심 (바탕화면 일부 포함)
> **강조**: "다음" 버튼과 "설치 완료" 화면
> **길이**: 8~12초

## Vault(보관함) 만들기

**Vault**는 노트가 저장되는 폴더입니다. 쉽게 말해서 "내 노트 모음을 넣어두는 상자"입니다.

- Vault 안에 들어가는 모든 노트는 `.md` (마크다운) 파일로 저장됩니다
- Vault 안에서 폴더를 자유롭게 만들어서 정리할 수 있습니다
- 용도별로 여러 Vault를 만들 수 있습니다 (예: 업무용 Vault, 개인용 Vault)

### Vault 만드는 방법

1. Notology를 처음 실행하면 "Vault를 선택하세요" 화면이 나타납니다
2. **새 Vault 만들기** 버튼을 클릭합니다
3. 노트를 저장할 폴더 위치를 선택합니다 (예: 내 문서 폴더)
4. Vault 이름을 입력하고 **확인**을 누르면 끝!

> 📸 **여기에 GIF** — `images/vault-create.gif`
>
> **촬영**: 앱 첫 실행 후 Vault를 새로 만드는 전체 과정
> **순서**: ① Notology 첫 실행 화면 → ② "새 Vault 만들기" 클릭 → ③ 폴더 위치 선택 → ④ 이름 입력 → ⑤ 확인 → ⑥ Vault 열림
> **화면 영역**: Notology 앱 전체 화면
> **강조**: "새 Vault 만들기" 버튼 클릭과 폴더 선택 단계
> **길이**: 8~12초

> **💡 팁**: NAS 동기화 폴더나 클라우드 드라이브(OneDrive, Google Drive 등) 폴더를 Vault로 지정하면 여러 컴퓨터에서 같은 노트를 쓸 수 있습니다.

## 첫 번째 노트 만들기

Vault를 만들었으면 바로 노트를 써볼 수 있습니다!

1. `Ctrl + N`을 누르세요 (또는 사이드바 아래쪽의 **+ 버튼** 클릭)
2. 노트 이름을 입력합니다 (예: "나의 첫 번째 노트")
3. 템플릿을 고릅니다 (처음에는 기본 "노트"를 선택하세요)
4. 에디터가 열리면 자유롭게 내용을 쓰면 됩니다

> 📸 **여기에 GIF** — `images/create-first-note.gif`
>
> **촬영**: Ctrl+N으로 새 노트를 만들고 이름을 짓는 과정
> **순서**: ① Ctrl+N 누르기 → ② 새 노트 다이얼로그 나타남 → ③ 이름 입력 → ④ 템플릿 "노트" 선택 → ⑤ 확인 클릭
> **화면 영역**: Notology 앱 전체 화면 (다이얼로그에 포커스)
> **강조**: 이름 입력란과 템플릿 선택 부분
> **길이**: 5~8초

> 📸 **여기에 GIF** — `images/first-note-writing.gif`
>
> **촬영**: 새로 만든 노트에 텍스트를 쓰는 모습
> **순서**: ① 에디터에서 커서 깜빡임 → ② 텍스트 타이핑 → ③ 제목 만들기 (`# 제목` 입력) → ④ 본문 작성
> **화면 영역**: 에디터 영역만
> **강조**: 마크다운 문법이 실시간으로 서식으로 바뀌는 모습
> **길이**: 5~8초

노트는 **자동으로 저장**되므로 따로 저장 버튼을 누르지 않아도 됩니다. 안심하고 쓰세요!

## 컨테이너란?

Notology에서 **컨테이너**는 노트를 담는 큰 그릇입니다. 두 종류가 있습니다.

| 컨테이너 종류 | 어떤 건가요? | 이럴 때 써보세요 |
|--------------|-------------|----------------|
| **Standard (표준)** | 폴더를 자유롭게 만들어서 노트를 정리합니다. Windows 탐색기처럼 폴더 안에 폴더를 넣을 수 있어요. | 프로젝트 관리, 일반 노트, 자유로운 구조 |
| **Storage (저장소)** | 하나의 템플릿으로 같은 형식의 노트만 모읍니다. 폴더 없이 납작하게 쭉 나열됩니다. | 연락처 모음, 회의록 모음, 데이터 카드 |

> 📸 **여기에 GIF** — `images/create-container.gif`
>
> **촬영**: Standard 컨테이너와 Storage 컨테이너를 각각 만들어보는 과정
> **순서**: ① 사이드바에서 컨테이너 추가 버튼 클릭 → ② "Standard" 선택 → ③ 이름 입력 → ④ 생성 완료 → ⑤ 다시 추가 버튼 → ⑥ "Storage" 선택 → ⑦ 이름 + 템플릿 선택 → ⑧ 생성 완료
> **화면 영역**: 사이드바 영역 중심 (다이얼로그 포함)
> **강조**: Standard와 Storage 선택 화면의 차이
> **길이**: 8~12초
