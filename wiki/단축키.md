# <img src="images/icons/keyboard.png" width="24" height="24"> 키보드 단축키

키보드 단축키를 사용하면 마우스 없이도 빠르게 작업할 수 있습니다. 자주 쓰는 기능을 단축키로 익혀두면 작업 속도가 크게 올라갑니다.

---

## 전역 단축키

앱 어디에서나 사용할 수 있는 단축키입니다.

| 단축키 | 기능 |
|--------|------|
| `Ctrl + N` | 새 노트 만들기 |
| `Ctrl + Shift + F` | 검색 열기 |
| `Ctrl + Shift + C` | 캘린더 열기 |
| `Ctrl + ←` | 사이드바 접기/펴기 |
| `Ctrl + →` | 오른쪽 패널 접기/펴기 |

> 📸 **여기에 GIF** — `images/shortcuts-global.gif`
>
> **촬영**: 전역 단축키를 차례로 시연하는 과정 (새 노트, 검색, 캘린더, 사이드바 토글)
> **순서**: ① Ctrl+N → 새 노트 대화상자 열림 (Esc로 닫기) → ② Ctrl+Shift+F → 검색 패널 열림 (Esc로 닫기) → ③ Ctrl+Shift+C → 캘린더 열림 → ④ Ctrl+← → 사이드바 접기/펴기
> **화면 영역**: 전체 화면 (각 단축키에 따라 UI 요소가 열리고 닫히는 과정)
> **강조**: 각 단축키 입력 후 나타나는 UI 변화 (키보드 오버레이로 누르는 키를 표시하면 좋음)
> **길이**: 8~12초

## 텍스트 서식 단축키

에디터에서 텍스트를 선택한 후 사용합니다.

| 단축키 | 기능 | 결과 |
|--------|------|------|
| `Ctrl + B` | **굵게** | **이렇게 굵은 글씨** |
| `Ctrl + I` | *기울임* | *이렇게 기울어진 글씨* |
| `Ctrl + U` | <u>밑줄</u> | 밑줄이 그어진 글씨 |
| `Ctrl + Shift + X` | ~~취소선~~ | ~~이렇게 줄이 그어진 글씨~~ |
| `Ctrl + E` | `인라인 코드` | 코드처럼 표시된 글씨 |

> 📸 **여기에 GIF** — `images/shortcuts-formatting.gif`
>
> **촬영**: 에디터에서 텍스트를 선택한 뒤 서식 단축키(굵게, 기울임, 밑줄 등)를 적용하는 과정
> **순서**: ① 텍스트 입력 후 드래그로 선택 → ② Ctrl+B → 굵게 적용 → ③ 다른 텍스트 선택 → Ctrl+I → 기울임 적용 → ④ Ctrl+U → 밑줄 적용 → ⑤ Ctrl+E → 인라인 코드 적용
> **화면 영역**: 에디터 본문 영역만 (텍스트 선택 + 서식 변화가 보이도록)
> **강조**: 텍스트 선택 범위, 서식 적용 전후의 시각적 변화
> **길이**: 8~12초

## 블록 단축키

문단이나 목록 단위로 조작하는 단축키입니다.

| 단축키 | 기능 |
|--------|------|
| `Tab` | 들여쓰기 (한 단계 안으로) |
| `Shift + Tab` | 내어쓰기 (한 단계 밖으로) |
| `Enter` | 새 줄 / 새 목록 항목 |
| `Shift + Enter` | 같은 블록 안에서 줄바꿈 |

## 에디터 트리거

특정 문자를 입력하면 자동으로 기능이 활성화됩니다.

| 트리거 | 기능 | 설명 |
|--------|------|------|
| `[[` | 위키링크 | 다른 노트를 연결합니다. 자동완성 목록이 나타납니다 |
| `@` | 멘션 | 노트나 사람을 멘션합니다 |
| `//` | 첨부파일 | 파일을 첨부합니다. 파일 목록이 나타납니다 |
| `#` + 공백 | 제목 | `# `은 제목1, `## `은 제목2, `### `은 제목3 |
| `-` + 공백 | 불릿 목록 | 글머리 기호 목록을 시작합니다 |
| `1.` + 공백 | 번호 목록 | 번호 매기기 목록을 시작합니다 |
| `- [ ]` + 공백 | 체크리스트 | 체크박스가 있는 목록을 시작합니다 |
| `>` + 공백 | 인용문 | 인용 블록을 시작합니다 |
| ` ``` ` | 코드 블록 | 코드 블록을 시작합니다 |
| `---` | 구분선 | 수평 구분선을 삽입합니다 |

> 📸 **여기에 GIF** — `images/shortcuts-triggers.gif`
>
> **촬영**: 에디터에서 트리거 문자(`[[`, `@`, `//` 등)를 입력하여 자동완성 목록이 나타나는 과정
> **순서**: ① `[[` 입력 → 위키링크 자동완성 목록 표시 → Esc로 닫기 → ② `@` 입력 → 멘션 자동완성 표시 → Esc로 닫기 → ③ `//` 입력 → 첨부파일 목록 표시 → Esc로 닫기 → ④ `# ` 입력 → 제목으로 변환
> **화면 영역**: 에디터 본문 영역 (커서 위치 + 자동완성 드롭다운)
> **강조**: 트리거 문자 입력 후 나타나는 자동완성 드롭다운 메뉴
> **길이**: 8~12초

## 캔버스 단축키

캔버스 모드에서 사용하는 단축키입니다.

| 단축키 | 기능 |
|--------|------|
| `Delete` | 선택한 노드/엣지 삭제 |
| `Shift + 드래그` | 여러 노드 영역 선택 |

| 더블클릭 (빈 공간) | 새 텍스트 노드 생성 |
| 더블클릭 (노드) | 노드 편집 모드 |

## 단축키 커스터마이징

단축키를 원하는 키 조합으로 변경할 수 있습니다.

1. **설정**을 엽니다 (사이드바 하단 ⚙ 버튼)
2. **단축키** 탭을 선택합니다
3. 변경할 단축키를 클릭합니다
4. 새로운 키 조합을 입력합니다
5. 저장합니다

> 📸 **여기에 GIF** — `images/shortcuts-customize.gif`
>
> **촬영**: 설정 > 단축키 탭에서 기존 단축키를 새로운 키 조합으로 변경하는 과정
> **순서**: ① 설정 열기 (⚙ 클릭) → ② 단축키 탭 선택 → ③ 변경할 단축키 항목 클릭 → ④ 키 입력 모드 활성화 (입력 대기 상태) → ⑤ 새로운 키 조합 입력 → ⑥ 변경 완료 확인
> **화면 영역**: 설정 모달의 단축키 탭 전체
> **강조**: 키 입력 대기 상태의 시각적 표시, 변경 전후의 키 바인딩 텍스트 변화
> **길이**: 5~8초
