# <img src="images/icons/panel-left.png" width="24" height="24"> 사이드바 & 탐색기

사이드바에서 내 노트와 폴더를 찾아다니고 관리하는 방법을 알아봅니다.

---

## 사이드바 전체 모습

> 📸 **여기에 스크린샷** — `images/sidebar-overview.png`
>
> **촬영**: 사이드바 전체 모습 캡처 — Vault 선택기, 파일 탐색기, 하단 버튼이 모두 보이는 상태
> **내용**: 사이드바 상단에 Vault 이름, 중간에 폴더/노트 트리, 하단에 +/검색/설정 버튼이 보이는 상태
> **화면 영역**: 사이드바 영역만 캡처

## Vault 선택기

사이드바 맨 위에 있는 부분입니다. 지금 사용 중인 Vault 이름이 보입니다.

- 클릭하면 내가 등록한 Vault 목록이 나옵니다
- 다른 Vault를 선택하면 그 Vault의 파일로 바뀝니다
- 새 Vault를 추가하거나, 안 쓰는 Vault를 목록에서 뺄 수 있습니다

> 📸 **여기에 GIF** — `images/sidebar-vault-switch.gif`
>
> **촬영**: Vault 선택기를 클릭해서 다른 Vault로 전환하는 모습
> **순서**: ① 사이드바 상단의 Vault 이름 클릭 → ② 드롭다운 목록 나타남 → ③ 다른 Vault 선택 → ④ 파일 탐색기가 새 Vault 내용으로 바뀜
> **화면 영역**: 사이드바 영역 (드롭다운 포함)
> **강조**: Vault 이름 클릭과 전환 후 파일 목록이 바뀌는 순간
> **길이**: 3~5초

## 파일 탐색기

Windows 탐색기처럼 폴더와 노트를 트리 구조로 보여주는 곳입니다.

### 기본 동작

| 이렇게 하면 | 이런 일이 일어납니다 |
|------------|-------------------|
| 폴더를 클릭 | 폴더가 열리거나 닫힙니다 (펼치기/접기) |
| 노트를 클릭 | 에디터에서 그 노트가 열립니다 |
| 노트를 더블클릭 | 호버 윈도우(떠다니는 창)로 노트가 열립니다 |

> 📸 **여기에 GIF** — `images/sidebar-tree-navigate.gif`
>
> **촬영**: 폴더를 펼치고 접으면서 노트를 탐색하는 기본 동작
> **순서**: ① 폴더 화살표 클릭 → ② 폴더 펼쳐짐 → ③ 노트 클릭 → ④ 에디터에 내용 표시 → ⑤ 다른 폴더 접기
> **화면 영역**: 사이드바 + 에디터 영역
> **강조**: 폴더가 펼쳐지는 애니메이션과 노트 클릭 시 에디터 변화
> **길이**: 5~8초

### 노트 우클릭 메뉴

노트 위에서 마우스 오른쪽 버튼을 누르면 여러 가지 작업을 할 수 있습니다.

| 메뉴 항목 | 하는 일 |
|----------|---------|
| 열기 | 에디터에서 노트를 엽니다 |
| 호버로 열기 | 호버 윈도우(떠다니는 창)로 엽니다 |
| 이름 바꾸기 | 노트 이름을 바꿉니다 (다른 노트의 위키링크도 자동으로 바뀜) |
| 이동 | 다른 폴더로 노트를 옮깁니다 |
| 삭제 | 노트를 삭제합니다 (참조하는 위키링크가 있으면 알려줌) |
| 경로 복사 | 파일 경로를 복사합니다 |
| 탐색기에서 열기 | Windows 탐색기에서 해당 위치를 엽니다 |

> 📸 **여기에 GIF** — `images/sidebar-note-contextmenu.gif`
>
> **촬영**: 사이드바에서 노트를 우클릭해서 메뉴를 사용하는 모습
> **순서**: ① 노트 위에서 마우스 우클릭 → ② 컨텍스트 메뉴 나타남 → ③ "이름 바꾸기" 선택 → ④ 새 이름 입력 → ⑤ 확인
> **화면 영역**: 사이드바 영역 (컨텍스트 메뉴 포함)
> **강조**: 우클릭 메뉴의 각 항목이 잘 보이도록
> **길이**: 5~8초

### 폴더 우클릭 메뉴

| 메뉴 항목 | 하는 일 |
|----------|---------|
| 새 노트 | 이 폴더 안에 새 노트를 만듭니다 |
| 새 폴더 | 이 폴더 안에 새 하위 폴더를 만듭니다 |
| 이름 바꾸기 | 폴더 이름을 바꿉니다 |
| 삭제 | 폴더와 안에 있는 모든 파일을 삭제합니다 |

> 📸 **여기에 GIF** — `images/sidebar-folder-contextmenu.gif`
>
> **촬영**: 폴더를 우클릭해서 메뉴를 사용하는 모습
> **순서**: ① 폴더 위에서 마우스 우클릭 → ② 컨텍스트 메뉴 나타남 → ③ "새 노트" 선택 → ④ 노트 이름 입력 → ⑤ 노트 생성 완료
> **화면 영역**: 사이드바 영역 (컨텍스트 메뉴 포함)
> **강조**: 폴더 우클릭 메뉴의 항목들
> **길이**: 5~8초

## 드래그 앤 드롭

### 내부 이동 (사이드바 안에서)

노트나 폴더를 마우스로 끌어서 다른 폴더에 놓으면 그 폴더로 이동합니다.

- 노트를 폴더 위로 끌어다 놓으면 해당 폴더 안으로 이동
- 폴더를 다른 폴더로 끌어다 놓으면 하위 폴더로 이동

> 📸 **여기에 GIF** — `images/sidebar-drag-note.gif`
>
> **촬영**: 사이드바에서 노트를 드래그해서 다른 폴더로 이동하는 모습
> **순서**: ① 노트를 마우스로 잡기 (클릭+홀드) → ② 다른 폴더 위로 드래그 → ③ 폴더가 하이라이트됨 → ④ 마우스 놓기 → ⑤ 노트가 그 폴더 안으로 이동
> **화면 영역**: 사이드바 영역만
> **강조**: 드래그 중에 대상 폴더가 하이라이트되는 모습
> **길이**: 3~5초

### 외부 파일 가져오기

Windows 탐색기에서 파일을 Notology 사이드바로 끌어다 놓으면 Vault에 복사됩니다.

- 이미지, PDF, Office 문서 등 다양한 파일을 가져올 수 있습니다
- 가져온 파일은 놓은 위치의 폴더에 복사됩니다

> 📸 **여기에 GIF** — `images/sidebar-drag-external.gif`
>
> **촬영**: Windows 탐색기에서 파일을 사이드바로 드래그하여 가져오는 모습
> **순서**: ① Windows 탐색기에서 파일 선택 → ② Notology 사이드바로 드래그 → ③ 드롭 영역 하이라이트 → ④ 마우스 놓기 → ⑤ 파일이 Vault에 추가됨
> **화면 영역**: Windows 탐색기 + Notology 사이드바 (두 앱이 나란히 보이도록)
> **강조**: 파일이 사이드바에 추가되는 순간
> **길이**: 5~8초

## 컨테이너 유형

Notology에는 두 종류의 컨테이너가 있습니다.

### Standard (표준)

- 폴더를 자유롭게 만들 수 있습니다 (폴더 안에 폴더도 가능)
- 일반적인 노트 정리에 적합합니다

> 📸 **여기에 스크린샷** — `images/container-standard.png`
>
> **촬영**: Standard 컨테이너의 모습 — 폴더가 여러 단계로 중첩된 트리 구조
> **내용**: 폴더 안에 하위 폴더와 노트가 있는 트리 구조가 보이는 상태
> **화면 영역**: 사이드바 영역만

### Storage (저장소)

- 하나의 템플릿으로 같은 형식의 노트만 저장합니다
- 폴더 없이 납작한(flat) 구조로 관리합니다
- 연락처 모음, 회의록 모음 같은 용도에 좋습니다

> 📸 **여기에 스크린샷** — `images/container-storage.png`
>
> **촬영**: Storage 컨테이너의 모습 — 폴더 없이 노트가 나열된 구조
> **내용**: 같은 템플릿으로 만들어진 노트들이 폴더 없이 쭉 나열된 상태
> **화면 영역**: 사이드바 영역만

### 컨테이너 만들기

1. 사이드바에서 **컨테이너 추가 버튼**을 클릭합니다
2. **Standard** 또는 **Storage** 중 하나를 고릅니다
3. 컨테이너 이름을 입력합니다
4. Storage를 골랐다면 사용할 템플릿도 선택합니다

> 📸 **여기에 GIF** — `images/sidebar-container-create.gif`
>
> **촬영**: 사이드바에서 새 컨테이너를 만드는 과정
> **순서**: ① 컨테이너 추가 버튼 클릭 → ② 유형 선택 (Standard/Storage) → ③ 이름 입력 → ④ (Storage인 경우) 템플릿 선택 → ⑤ 확인 → ⑥ 사이드바에 새 컨테이너 나타남
> **화면 영역**: 사이드바 영역 + 다이얼로그
> **강조**: 유형 선택 화면과 생성 완료 후 사이드바 변화
> **길이**: 5~8초

## 사이드바 열기/닫기

`Ctrl + ←` 단축키로 사이드바를 열거나 닫을 수 있습니다. 사이드바를 닫으면 에디터가 넓어져서 글쓰기에 집중할 수 있습니다.

> 📸 **여기에 GIF** — `images/sidebar-toggle.gif`
>
> **촬영**: Ctrl+← 으로 사이드바를 토글하는 모습
> **순서**: ① 사이드바가 열린 상태 → ② Ctrl+← 누르기 → ③ 사이드바 닫힘 → ④ 다시 Ctrl+← → ⑤ 사이드바 열림
> **화면 영역**: 앱 전체 화면 (사이드바 + 에디터)
> **강조**: 사이드바 열림/닫힘에 따라 에디터 넓이가 변하는 모습
> **길이**: 3~5초

## 하단 버튼

사이드바 맨 아래에 세 가지 버튼이 있습니다.

| 버튼 | 단축키 | 하는 일 |
|------|--------|---------|
| **+ (새 노트)** | `Ctrl + N` | 새 노트를 만듭니다 |
| **검색** | `Ctrl + Shift + F` | 전체 검색 창을 엽니다 |
| **설정** | — | 앱 설정 화면을 엽니다 |

> 📸 **여기에 GIF** — `images/sidebar-bottom-buttons.gif`
>
> **촬영**: 사이드바 하단의 +, 검색, 설정 버튼을 차례로 클릭하는 모습
> **순서**: ① + 버튼 클릭 → ② 새 노트 다이얼로그 나타남 → ③ 취소 → ④ 검색 버튼 클릭 → ⑤ 검색 창 열림 → ⑥ 닫기 → ⑦ 설정 버튼 클릭 → ⑧ 설정 화면 열림
> **화면 영역**: 사이드바 하단 + 각 기능 화면
> **강조**: 각 버튼의 위치와 클릭 시 나타나는 화면
> **길이**: 8~12초
