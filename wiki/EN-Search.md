# <img src="images/icons/search.png" width="24" height="24"> Search

Learn how to quickly find notes, narrow results with filters, and manage multiple notes at once.

---

## Opening Search

| Method | Description |
|--------|------------|
| `Ctrl + Shift + F` | Keyboard shortcut — the fastest way |
| Sidebar search button | Click the magnifying glass icon at the bottom of the sidebar |

> 📸 **GIF placeholder** — `images/search-open.gif`
>
> **Shot**: Opening the search panel with Ctrl+Shift+F
> **Steps**: ① Working in the editor → ② Press Ctrl+Shift+F → ③ Search panel opens → ④ Cursor is placed in the search input field
> **Screen area**: Full app window (transition to search panel)
> **Highlight**: The search panel opening and the input field receiving focus
> **Duration**: 3~5s

## Basic Search

Type a word into the search bar and **results appear instantly as you type**.

- Results update with each keystroke
- Matching text is **highlighted in yellow**
- Both note titles and body content are searched

> 📸 **GIF placeholder** — `images/search-basic.gif`
>
> **Shot**: Typing a keyword in the search bar with results appearing in real time
> **Steps**: ① Type one character at a time → ② Results update with each keystroke → ③ Search terms are highlighted → ④ Click a result → ⑤ Note opens in a hover window
> **Screen area**: Full search screen
> **Highlight**: Results updating in real time and the yellow highlight
> **Duration**: 5~8s

## Search Fields

You can narrow your search to a specific scope.

| Search Field | Where it looks | Example |
|-------------|---------------|---------|
| **Title** | Note titles only | Notes with "Meeting" in the title |
| **Body** | Note content only | Notes containing "project schedule" in the body |
| **Tags** | Tags only | Notes tagged with `#important` |
| **Container** | Within a specific container | Notes inside the "Work" container |
| **Attachments** | Attachment file names | Notes with "report.pdf" attached |

> 📸 **GIF placeholder** — `images/search-fields.gif`
>
> **Shot**: Switching between search fields to adjust the search scope
> **Steps**: ① Default search (all fields) → ② Switch to "Title" field → ③ Results narrow down → ④ Switch to "Tags" field → ⑤ See tag-filtered results
> **Screen area**: Search screen (focus on field selection UI)
> **Highlight**: Results changing as you switch fields
> **Duration**: 5~8s

Filters let you narrow results even further.

View only notes created or modified within a specific time period.

> **Highlight**: Date selection and results shrinking

### Tag Filter

View only notes that have a specific tag.

> 📸 **GIF placeholder** — `images/search-tag-filter.gif`
>
> **Shot**: Using the tag filter to show only notes with a specific tag

### Combining Filters

You can use multiple filters at the same time.

- Example: "Work" container + "Meeting" type + created this month
- This gives you **only this month's work meeting notes**

## Opening Notes from Search Results

Click a note in the search results to open it in a **hover window**.

- The note you're currently editing stays open
- Quickly browse through multiple notes from the search results

---

## Bulk Actions

Select multiple notes from the search results to perform actions on them all at once. Extremely useful when managing a large number of notes.

| Action | What it does |
|--------|-------------|
| **Bulk Delete** | Delete all selected notes at once |
| **Bulk Move** | Move all selected notes to another folder at once |
| **Bulk Tag** | Add a tag to all selected notes at once |

### How to Use Bulk Actions

1. Use search to find the notes you want
2. Select multiple notes using the **checkboxes**
3. Click the bulk action button you need

> 📸 **GIF placeholder** — `images/search-bulk-actions.gif`
>
> **Shot**: Selecting multiple notes with checkboxes in search results and performing a bulk move
> **Steps**: ① Search results list → ② Click the first note's checkbox → ③ Check the second and third notes too → ④ Click the "Bulk Move" button → ⑤ Select destination folder → ⑥ Confirm → ⑦ Move complete
> **Screen area**: Full search screen
> **Highlight**: Checkbox selections and the bulk action button
> **Duration**: 8~12s

## Finding Conflict Files

When syncing notes via a NAS or cloud drive, editing the same note on multiple computers at the same time can create **conflict files**.

- Conflict files have markings like `(conflict)` in their file names
- Search for "conflict" to find them
- Compare the conflict file with the original, merge the content, then delete the conflict file

> 📸 **GIF placeholder** — `images/search-conflicts.gif`
>
> **Shot**: Searching for "conflict" to find and clean up sync conflict files
> **Steps**: ① Type "conflict" in the search bar → ② Conflict file list appears → ③ Click a conflict file to check its content → ④ Compare with the original → ⑤ Delete the conflict file
> **Screen area**: Search screen + hover window
> **Highlight**: How to identify conflict files
> **Duration**: 5~8s

## Search Tips

| Tip | Details |
|-----|---------|
| Keep searches short | One or two keywords work better than long phrases |
| Use tags | Tag frequently searched topics, then filter by tag for quick access |
| Narrow the scope | Container or type filters give you more accurate results |
| Search by date | Narrow by time period (e.g., "notes from last week") |
| Clean up regularly | Use bulk actions to periodically organize old notes |
