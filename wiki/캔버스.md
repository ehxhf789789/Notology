# <img src="images/icons/pen-tool.png" width="24" height="24"> 캔버스

무한한 화면 위에서 자유롭게 생각을 정리하고 다이어그램을 그리는 공간입니다.

---

## 캔버스란?

**캔버스**는 끝없이 넓은 화면 위에 텍스트, 도형, 파일 등을 자유롭게 배치하는 시각적 작업 공간입니다. 화이트보드에 포스트잇을 붙이고 선을 긋는 것과 비슷합니다.

- 마인드맵, 플로차트, 다이어그램을 만들 수 있습니다
- 노트 파일을 캔버스에 올려놓고 관계를 눈으로 볼 수 있습니다
- 도형과 화살표로 흐름을 표현할 수 있습니다

> 📸 **여기에 GIF** — `images/canvas-overview.gif`
>
> **촬영**: 캔버스의 전체 모습 — 텍스트 노드, 도형, 파일 노드, 연결선이 있는 상태에서 화면을 드래그해서 둘러보기
> **순서**: ① 캔버스 전체 화면 보기 → ② 여러 노드와 연결선이 보임 → ③ 빈 공간 드래그로 화면 이동 → ④ 확대/축소로 전체 보기
> **화면 영역**: 캔버스 전체 화면
> **강조**: 다양한 종류의 노드와 연결선이 조화롭게 배치된 모습
> **길이**: 5~8초

---

## 캔버스 만들기

1. `Ctrl + N`을 눌러 새 노트를 만듭니다
2. 템플릿 선택에서 **스케치**를 선택합니다
3. 무한 캔버스가 열립니다!

> 📸 **여기에 GIF** — `images/canvas-create.gif`
>
> **촬영**: Ctrl+N으로 새 노트를 만들고 "스케치" 템플릿을 선택해서 캔버스를 여는 과정
> **순서**: ① Ctrl+N → ② 새 노트 다이얼로그 → ③ 이름 입력 → ④ 템플릿에서 "스케치" 선택 → ⑤ 확인 → ⑥ 빈 캔버스가 열림
> **화면 영역**: 앱 전체 화면 (다이얼로그 → 캔버스 전환)
> **강조**: "스케치" 템플릿 선택과 캔버스가 열리는 순간
> **길이**: 5~8초

---

## 텍스트 노드

캔버스의 빈 곳을 **더블클릭**하면 텍스트 상자(노드)가 만들어집니다.

- 자유롭게 글을 쓸 수 있습니다
- 드래그해서 원하는 위치로 옮길 수 있습니다
- 모서리를 드래그해서 크기를 바꿀 수 있습니다

> 📸 **여기에 GIF** — `images/canvas-create-node.gif`
>
> **촬영**: 캔버스에서 더블클릭으로 텍스트 노드를 만들고 글을 쓰는 과정
> **순서**: ① 캔버스 빈 공간 더블클릭 → ② 텍스트 노드 생성됨 → ③ 텍스트 입력 → ④ 노드 밖 클릭으로 편집 종료 → ⑤ 노드 드래그로 이동
> **화면 영역**: 캔버스 중앙 영역
> **강조**: 더블클릭으로 노드가 생기는 순간과 텍스트 입력
> **길이**: 5~8초

---

## 도형 노드

6가지 도형을 사용할 수 있습니다. 플로차트나 다이어그램을 만들 때 유용합니다.

| 도형 | 모양 | 이럴 때 쓰세요 |
|------|------|--------------|
| **Process (처리)** | 직사각형 | 일반 작업, 처리 단계 |
| **Terminal (시작/끝)** | 둥근 사각형 | 프로세스의 시작과 끝 |
| **Decision (판단)** | 마름모 | 조건 분기 (예/아니오) |
| **I/O (입출력)** | 평행사변형 | 데이터 입력, 출력 |
| **Subroutine (서브루틴)** | 이중 사각형 | 하위 프로세스 |
| **Database (데이터베이스)** | 원통 | 데이터 저장소 |

> 📸 **여기에 GIF** — `images/canvas-shapes.gif`
>
> **촬영**: 캔버스에서 여러 도형을 추가하고 텍스트를 넣는 과정
> **순서**: ① 도형 추가 메뉴/버튼 클릭 → ② "Process" 도형 선택 → ③ 캔버스에 배치 → ④ 도형 안에 텍스트 입력 → ⑤ "Decision" 도형 추가 → ⑥ "Terminal" 도형 추가
> **화면 영역**: 캔버스 영역 (도형 선택 메뉴 포함)
> **강조**: 각 도형의 다른 모양과 텍스트 편집 모습
> **길이**: 8~12초

## 파일 노드

사이드바에서 노트나 파일을 **캔버스로 드래그**하면 파일 노드가 만들어집니다.

- 노트 내용의 미리보기가 카드처럼 표시됩니다
- 파일 노드를 **더블클릭**하면 해당 노트가 호버 윈도우로 열립니다
- 여러 노트를 캔버스에 배치해서 관계를 눈으로 정리할 수 있습니다

> 📸 **여기에 GIF** — `images/canvas-file-node.gif`
>
> **촬영**: 사이드바에서 노트를 캔버스로 드래그해서 파일 노드를 만드는 과정
> **순서**: ① 사이드바에서 노트를 마우스로 잡기 → ② 캔버스 위로 드래그 → ③ 마우스 놓기 → ④ 파일 노드 생성 (미리보기 카드) → ⑤ 파일 노드 더블클릭 → ⑥ 호버 윈도우로 열림
> **화면 영역**: 사이드바 + 캔버스 영역
> **강조**: 드래그 앤 드롭으로 파일 노드가 생기는 순간과 미리보기 카드
> **길이**: 5~8초

## 노드 편집

| 할 일 | 방법 |
|-------|------|
| 이동 | 노드를 드래그합니다 |
| 크기 바꾸기 | 노드 모서리를 드래그합니다 |
| 색상 바꾸기 | 노드를 선택하고 색상 팔레트에서 고릅니다 |
| 삭제 | 노드를 선택하고 `Delete` 키를 누릅니다 |
| 텍스트 수정 | 노드를 더블클릭해서 글을 고칩니다 |

> 📸 **여기에 GIF** — `images/canvas-edit-node.gif`
>
> **촬영**: 노드를 이동, 크기 변경, 색상 변경하는 과정
> **순서**: ① 노드 클릭해서 선택 → ② 드래그로 이동 → ③ 모서리 드래그로 크기 변경 → ④ 색상 팔레트에서 색 변경 → ⑤ 결과 확인
> **화면 영역**: 캔버스 영역 (색상 팔레트 포함)
> **강조**: 각 편집 작업의 결과 변화
> **길이**: 5~8초

## 연결선 (화살표)

노드와 노드를 화살표로 연결할 수 있습니다.

### 연결선 만들기

1. 노드 위에 마우스를 올리면 **연결 포인트** (작은 원)가 나타납니다
2. 연결 포인트를 드래그해서 다른 노드로 끌어갑니다
3. 다른 노드 위에서 놓으면 화살표가 만들어집니다

### 연결선 특징

- 화살표 방향으로 흐름을 나타냅니다
- 곡선으로 자연스럽게 연결됩니다
- 노드를 이동하면 연결선도 따라갑니다

> 📸 **여기에 GIF** — `images/canvas-create-edge.gif`
>
> **촬영**: 두 노드를 연결선(화살표)으로 잇는 과정
> **순서**: ① 첫 번째 노드 위에 마우스 올리기 → ② 연결 포인트 나타남 → ③ 연결 포인트 드래그 시작 → ④ 두 번째 노드 위로 드래그 → ⑤ 마우스 놓기 → ⑥ 화살표 생성됨 → ⑦ 노드 이동 시 화살표도 따라감
> **화면 영역**: 캔버스 영역 (두 노드가 모두 보이도록)
> **강조**: 연결 포인트와 드래그 중 화살표 미리보기
> **길이**: 5~8초

## 화면 조작 (뷰포트)

| 동작 | 방법 |
|------|------|
| 화면 이동 (팬) | 빈 공간을 드래그합니다 |
| 확대/축소 | `Ctrl` + 마우스 휠 |
| 확대 범위 | 0.1배 ~ 3배 |
| 전체 보기 | 모든 노드가 화면에 들어오도록 자동 조절 |

> 📸 **여기에 GIF** — `images/canvas-viewport.gif`
>
> **촬영**: 캔버스에서 화면을 드래그로 이동하고 확대/축소하는 모습
> **순서**: ① 빈 공간 드래그로 팬 이동 → ② Ctrl+마우스 휠 위로 (확대) → ③ 노드가 크게 보임 → ④ Ctrl+마우스 휠 아래로 (축소) → ⑤ 전체 보기
> **화면 영역**: 캔버스 전체 화면
> **강조**: 확대/축소 시 노드 크기 변화
> **길이**: 5~8초

## 다중 선택

`Shift`를 누른 채로 드래그하면 범위 안의 여러 노드를 한 번에 선택할 수 있습니다.

- 선택한 노드들을 함께 이동할 수 있습니다
- `Delete`로 선택한 노드들을 한꺼번에 삭제할 수 있습니다

> 📸 **여기에 GIF** — `images/canvas-multiselect.gif`
>
> **촬영**: Shift+드래그로 여러 노드를 선택하고 함께 이동하는 모습
> **순서**: ① 여러 노드가 캔버스에 있음 → ② Shift 누른 채 드래그 → ③ 선택 박스 나타남 → ④ 선택된 노드들이 하이라이트됨 → ⑤ 선택된 노드들을 함께 드래그 이동
> **화면 영역**: 캔버스 영역
> **강조**: 선택 박스와 노드들의 하이라이트
> **길이**: 3~5초

## 플로차트 예시

캔버스로 간단한 플로차트를 만들 수 있습니다.

```
┌─────────────┐
│  시작 (Terminal) │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 데이터 입력 (I/O) │
└──────┬──────┘
       │
       ▼
  ◆ 조건 충족? ◆  ──── 아니오 ───→ ┌──────────┐
  (Decision)                        │ 오류 처리  │
       │                            │ (Process) │
      예                            └──────────┘
       │
       ▼
┌─────────────┐
│ 처리 (Process)  │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  종료 (Terminal) │
└─────────────┘
```

> 📸 **여기에 GIF** — `images/canvas-flowchart-demo.gif`
>
> **촬영**: 위 플로차트를 캔버스에서 실제로 만드는 과정 (빠른 시연)
> **순서**: ① Terminal 도형 추가 ("시작") → ② I/O 도형 추가 ("데이터 입력") → ③ 연결선으로 잇기 → ④ Decision 도형 추가 ("조건 충족?") → ⑤ 연결선 잇기 → ⑥ Process 도형들 추가 → ⑦ 모든 연결선 완성 → ⑧ 완성된 플로차트 전체 보기
> **화면 영역**: 캔버스 전체 화면
> **강조**: 도형 추가 → 연결 → 완성까지의 흐름
> **길이**: 8~12초
