# <img src="images/icons/lightbulb.png" width="24" height="24"> 팁과 트릭

Notology를 더 효과적으로 활용하기 위한 실전 노하우를 모았습니다.

## 생산성 팁

### 1. 노트마다 위키링크 1~2개씩 추가하기

새 노트를 작성할 때 관련된 노트에 `[[위키링크]]`를 1~2개씩 걸어두세요. 시간이 지나면 자연스럽게 지식 네트워크가 만들어집니다.

- [그래프 뷰](그래프-뷰)에서 연결 관계를 한눈에 확인할 수 있습니다
- 나중에 관련 정보를 찾을 때 링크를 따라가면 빠르게 도달합니다

> 📸 **여기에 GIF** — `images/tips-wikilink-habit.gif`
>
> **촬영**: 노트에 `[[위키링크]]`를 추가하고, 그래프 뷰에서 연결 관계가 생기는 것을 확인하는 과정
> **순서**: ① 에디터에서 `[[` 입력 → ② 자동완성 목록에서 노트 선택 → ③ 위키링크 삽입 완료 → ④ 그래프 뷰로 전환 → ⑤ 방금 연결한 두 노트가 선으로 이어진 모습 확인
> **화면 영역**: 전체 화면 (에디터에서 위키링크 입력 → 그래프 뷰로 전환하는 과정)
> **강조**: 위키링크 자동완성 드롭다운, 그래프에서 새로 생긴 연결선
> **길이**: 8~12초

---

### 2. 제목 접기로 긴 문서 정리하기

긴 문서는 **제목(Heading) 접기** 기능으로 현재 작업 중인 섹션만 펼쳐두세요.

- 제목 왼쪽의 **▶ 버튼**을 클릭하면 해당 섹션이 접힙니다
- 필요한 부분만 펼쳐서 집중할 수 있습니다
- 코드 블록도 접을 수 있습니다

> 📸 **여기에 GIF** — `images/tips-fold-sections.gif`
>
> **촬영**: 긴 문서에서 여러 제목 섹션을 접고 펼치며 정리하는 과정
> **순서**: ① 긴 문서에서 제목 왼쪽의 ▶ 버튼 클릭 → 섹션 접힘 → ② 다른 섹션도 접기 → ③ 필요한 섹션만 ▶ 클릭하여 펼치기 → ④ 코드 블록 접기/펼치기
> **화면 영역**: 에디터 본문 영역 전체
> **강조**: 제목 왼쪽의 ▶/▼ 접기/펼치기 버튼, 접힌 섹션의 시각적 표시
> **길이**: 5~8초

---

### 3. 호버 윈도우를 듀얼 모니터처럼 활용하기

[호버 윈도우](호버-윈도우)를 여러 개 열어서 화면을 분할 사용하세요.

- 왼쪽에 참고 노트, 오른쪽에 작성 중인 노트를 배치합니다
- 회의록을 보면서 정리 노트를 작성하는 등의 멀티 작업이 가능합니다
- 호버 윈도우는 자유롭게 이동하고 크기를 조절할 수 있습니다

> 📸 **여기에 GIF** — `images/tips-dual-view.gif`
>
> **촬영**: 호버 윈도우 2개를 나란히 배치하여 한쪽에서 참고하면서 다른 쪽에서 작성하는 과정
> **순서**: ① 첫 번째 노트를 호버 윈도우로 열기 → ② 화면 왼쪽으로 이동/배치 → ③ 두 번째 노트를 호버 윈도우로 열기 → ④ 화면 오른쪽으로 배치 → ⑤ 두 윈도우를 오가며 작업하는 모습
> **화면 영역**: 전체 화면 (두 개의 호버 윈도우가 나란히 배치된 모습)
> **강조**: 두 윈도우가 좌우로 나란히 배치된 레이아웃, 윈도우 간 전환
> **길이**: 8~12초

### 4. Storage 컨테이너를 데이터베이스처럼 사용하기

[템플릿](템플릿)과 **Storage 컨테이너**를 조합하면 구조화된 데이터베이스를 만들 수 있습니다.

| 예시 | 템플릿 | 활용 |
|------|--------|------|
| 연락처 모음 | 연락처 템플릿 | 모든 사람 정보를 같은 형식으로 관리 |
| 논문 라이브러리 | 논문 템플릿 | 읽은 논문을 체계적으로 정리 |
| 회의록 아카이브 | 회의록 템플릿 | 모든 회의 기록을 검색 가능하게 보관 |

> 📸 **여기에 GIF** — `images/tips-storage-container.gif`
>
> **촬영**: Storage 컨테이너를 만들고, 안에서 템플릿이 자동 적용된 노트를 여러 개 생성하여 데이터베이스처럼 활용하는 과정
> **순서**: ① 사이드바에서 Storage 컨테이너 확인 → ② 컨테이너 안에서 새 노트 생성 (+ 버튼) → ③ 템플릿이 자동 적용된 노트 확인 → ④ 여러 노트가 같은 구조로 정리된 목록 확인
> **화면 영역**: 전체 화면 (사이드바의 Storage 컨테이너 + 에디터)
> **강조**: 모든 노트가 같은 템플릿 구조를 가지는 일관성
> **길이**: 5~8초

## 정리 팁

### 5. 태그 네임스페이스로 체계적 분류하기

[태그](태그)에 접두사를 붙여 분류 체계를 만드세요.

| 접두사 | 용도 | 예시 |
|--------|------|------|
| `domain:` | 분야 | `domain:개발`, `domain:마케팅` |
| `who:` | 사람 | `who:김팀장`, `who:이대리` |
| `org:` | 조직 | `org:기획팀`, `org:외부업체A` |
| `ctx:` | 상태/맥락 | `ctx:긴급`, `ctx:완료`, `ctx:보류` |

같은 접두사의 태그끼리 자연스럽게 그룹이 만들어져 관리가 편리합니다.

---

### 6. 프로젝트마다 컨테이너 만들기

진행 중인 프로젝트마다 Standard 컨테이너를 하나씩 만들어 관련 노트를 모아두세요.

- 프로젝트별로 폴더 구조를 자유롭게 구성할 수 있습니다
- 프로젝트가 끝나면 컨테이너를 접어두면 됩니다
- 필요할 때 언제든 다시 펼쳐서 확인할 수 있습니다

---

### 7. 캘린더로 일일 회고하기

하루가 끝날 때 [캘린더](캘린더)에서 오늘 날짜를 클릭하여 작성한 메모들을 돌아보세요.

- 오늘 어떤 작업을 했는지 한눈에 파악할 수 있습니다
- 미완료 항목을 확인하고 내일 일정을 계획합니다
- 매일 5분만 투자하면 업무 흐름이 크게 개선됩니다

> 📸 **여기에 GIF** — `images/tips-daily-review.gif`
>
> **촬영**: 캘린더에서 오늘 날짜를 클릭하여 작성한 메모들을 돌아보고, 미완료 할 일을 확인하는 과정
> **순서**: ① 캘린더 열기 (Ctrl+Shift+C) → ② 오늘 날짜 클릭 → ③ 오늘 작성한 메모 목록 확인 → ④ 할 일 탭 전환 → ⑤ 미완료 항목 확인
> **화면 영역**: 오른쪽 패널 전체 (캘린더 + 메모/할 일 목록)
> **강조**: 오늘 날짜의 메모/할 일 개수, 미완료 항목
> **길이**: 5~8초

## 검색 팁

### 8. 필터 조합으로 정확하게 찾기

[검색](검색)에서 여러 필터를 동시에 사용하면 원하는 노트를 정확하게 찾을 수 있습니다.

- **키워드** + **태그 필터**: 특정 태그가 있는 노트 중에서 키워드 검색
- **키워드** + **날짜 필터**: 특정 기간에 작성한 노트 중에서 검색
- **키워드** + **유형 필터**: 특정 유형(노트/캔버스)만 검색

---

### 9. `[[` 를 빠른 노트 검색기로 활용하기

에디터에서 `[[`를 입력하면 모든 노트 목록이 자동완성으로 나타납니다.

- 노트 이름 일부를 입력하면 필터링됩니다
- 링크를 만들 생각이 없어도, 노트를 빠르게 찾는 용도로 활용할 수 있습니다
- Esc를 누르면 자동완성을 취소할 수 있습니다

## 캔버스 팁

### 10. 프로젝트 구조를 캔버스로 그리기

[캔버스](캔버스)에서 프로젝트의 전체 구조를 시각적으로 정리하세요.

- 플로우차트로 업무 프로세스를 그립니다
- 마인드맵으로 아이디어를 정리합니다
- 다이어그램으로 시스템 구조를 시각화합니다

> 📸 **여기에 GIF** — `images/tips-project-canvas.gif`
>
> **촬영**: 캔버스에서 프로젝트 구조를 텍스트 노드와 연결선으로 만드는 과정
> **순서**: ① 캔버스 열기 → ② 빈 공간 더블클릭하여 텍스트 노드 생성 → ③ 여러 노드 생성 → ④ 노드 간 연결선 드래그 → ⑤ 완성된 프로젝트 구조도 확인
> **화면 영역**: 캔버스 에디터 전체 화면
> **강조**: 노드 생성, 연결선 드래그, 완성된 구조도의 전체 모습
> **길이**: 8~12초

---

### 11. 파일 노드로 노트 맵 만들기

캔버스에 **파일 노드**를 추가하면 실제 노트를 캔버스 위에 배치할 수 있습니다.

- 사이드바에서 노트를 캔버스로 드래그하면 파일 노드가 생성됩니다
- 더블클릭하면 해당 노트가 열립니다
- 관련 노트들을 공간적으로 배치하여 관계를 직관적으로 이해할 수 있습니다

## 성능 팁

### 12. 사이드바 즐겨찾기 활용하기

자주 사용하는 노트나 폴더는 즐겨찾기에 추가하세요. 매번 폴더 트리를 탐색하지 않아도 빠르게 접근할 수 있습니다.

---

### 13. 에디터 줌으로 편안하게 작업하기

`Ctrl + 마우스 휠`로 에디터의 글자 크기를 조절하세요.

- 긴 문서를 읽을 때는 줌을 키워서 편하게 읽습니다
- 전체 구조를 볼 때는 줌을 줄여서 한눈에 봅니다
- 줌 레벨은 설정에서 확인하고 초기화할 수 있습니다

---

### 14. 키보드 중심 워크플로

마우스 사용을 최소화하고 키보드 단축키를 활용하면 작업 속도가 크게 향상됩니다.

| 작업 | 단축키 |
|------|--------|
| 새 노트 | `Ctrl + N` |
| 검색 | `Ctrl + Shift + F` |
| 사이드바 토글 | `Ctrl + ←` |
| 위키링크 | `[[` 입력 |
| 굵게 | `Ctrl + B` |

모든 단축키는 [단축키](단축키) 페이지에서 확인하세요.

## 백업 팁

### 15. 정기적으로 볼트 폴더 백업하기

Notology의 노트는 모두 **일반 마크다운 파일**이므로, 볼트 폴더를 복사하는 것만으로 완벽한 백업이 됩니다.

| 백업 방법 | 주기 | 설명 |
|-----------|------|------|
| **USB/외장하드** | 주 1회 | 볼트 폴더를 통째로 복사합니다 |
| **클라우드** | 자동 | OneDrive, Google Drive 폴더에 볼트를 위치시킵니다 |
| **Git** | 수시 | 개발자라면 Git으로 버전 관리하면 변경 이력도 추적됩니다 |

> **중요**: 노트 파일은 특정 앱에 종속되지 않습니다. 만약 Notology를 사용하지 않게 되더라도, 모든 노트를 다른 마크다운 편집기에서 그대로 열어볼 수 있습니다.
