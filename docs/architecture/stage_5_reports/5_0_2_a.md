## 2. The 14 primitives landed

Files live in `src/design-system/components/`, one `.tsx` each + a single
shared `primitives.css`. Importing any primitive pulls the stylesheet in
once via the barrel `index.ts` side-effect import.

| File | Component | Variants / sizes | Notes |
|---|---|---|---|
| `Button.tsx` | `<Button>` | variant: `primary` / `secondary` / `ghost` / `danger`; size: `sm` / `md` / `lg` | left/right icons, loading spinner, `fullWidth`, forwardRef |
| `IconButton.tsx` | `<IconButton>` | variant: `ghost` / `subtle` / `primary`; size: `sm` / `md` / `lg` | required `aria-label`, `pressed` (toggle), forwardRef |
| `Input.tsx` | `<Input>` | size: `sm` / `md` / `lg` | left/right icons, `invalid`, native `size` exposed as `htmlSize` to avoid collision |
| `Textarea.tsx` | `<Textarea>` | — | `invalid`, `noResize` |
| `Checkbox.tsx` | `<Checkbox>` | — | label + description; `indeterminate` |
| `Radio.tsx` | `<Radio>` | — | label + description |
| `Toggle.tsx` | `<Toggle>` (switch) | size: `sm` / `md` | label + description; sets `role="switch"` by default |
| `Spinner.tsx` | `<Spinner>` | size: `sm` / `md` / `lg` | a11y `aria-label`; reduced-motion slows to 4s |
| `Skeleton.tsx` | `<Skeleton>` | variant: `rect` / `text` / `circle`; radius: `sm` / `md` / `lg` / `full` | shimmer animation; freezes under `prefers-reduced-motion` |
| `ProgressBar.tsx` | `<ProgressBar>` | variant: `default` / `success` / `warning` / `danger` | indeterminate when `value=null`; required `aria-label` |
| `Badge.tsx` | `<Badge>` | variant: `neutral` / `accent` / `success` / `warning` / `danger` / `info`; size: `sm` / `md` | `outline`, `dot` (status), `icon` |
| `Card.tsx` | `<Card>` | density: `compact` / `cozy` / `spacious` | `interactive` (hover/focus/press), `selected`, `as` (div/article/section/li) |
| `EmptyState.tsx` | `<EmptyState>` | — | `icon`, `title`, `description`, `action` slot (typically `<Button>`) |
| `KeyboardHint.tsx` | `<KeyboardHint>` | size: `sm` / `md` | renders `<kbd>` per key with chord separator; arrow/escape/enter glyph mapping |

**Total**: 14 .tsx files + 1 primitives.css + 1 index.ts = 16 files in `src/design-system/components/`.

API conventions:

- **forwardRef** on Button / IconButton / Input / Textarea / Checkbox / Radio / Toggle / Card — these benefit from ref access for focus management.
- **Native attribute pass-through** via `{...rest}` so every primitive accepts standard HTML props (`onClick`, `aria-*`, `data-*`).
- **a11y by construction**: every interactive primitive has built-in `:focus-visible` ring (`--bdr-focus`); `IconButton` requires `aria-label`; `Toggle` defaults to `role="switch"`; `Spinner`/`ProgressBar` get `role="progressbar"` + `aria-valuetext`.
- **Class naming**: `ds-*` prefix on every primitive class — easy grep, no risk of collision with existing 70+ CSS files.

## 3. CSS scoping discipline

`src/design-system/components/primitives.css` (~600 lines) is the **only**
new stylesheet. It references **Tier 2 + Tier 3 tokens only** — verified by
`npm run audit:tokens`:

```
Tier-1 primitive leakage: PASS — 0 references outside the source files
```

To make this work, two new semantic tokens were added to `tokens.css` in
this same commit (Tier 2 aliases for Tier 1 primitives — see §4):

- `--space-px` (1px), `--space-2xs` (2px) — for hairlines / tight padding
- `--fw-regular/medium/semibold/bold` — semantic font-weight aliases
- `--font-sans`, `--font-display` — semantic font-family aliases (previously only `--font` alias existed)

`primitives.css` adds **0 hex literals** and **0 raw margin/padding px** to
the audit baseline (held at 815 / 901 across 75 CSS files).

## 4. tokens.css additions (in this commit)

Small, additive — no breaking changes:

```css
/* Tier 1 */
--primitive-space-px: 1px;
--primitive-space-half: 2px;

/* Tier 2 — semantic font weight */
--fw-regular:  var(--primitive-fw-400);
--fw-medium:   var(--primitive-fw-500);
--fw-semibold: var(--primitive-fw-600);
--fw-bold:     var(--primitive-fw-700);

/* Tier 2 — semantic font family */
--font-sans:    var(--primitive-font-sans);
--font-display: var(--primitive-font-display);
/* --font-mono already exists in legacy alias block */

/* Tier 2 — hairline spacing */
--space-px:  var(--primitive-space-px);
--space-2xs: var(--primitive-space-half);
```

These are forward-looking — Tier 2 names that didn't exist in 5.0.1 because
no consumer needed them yet. 5.0.2a's primitives surfaced the gap.
