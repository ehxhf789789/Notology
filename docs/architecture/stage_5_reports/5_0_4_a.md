## 4. CommandPalette — new feature module

`src/features/command-palette/CommandPalette.tsx` (~260 lines):

- Uses 5.0.2b `<Dialog size="lg" hideCloseButton>` for chrome (focus trap + overlay + Esc-to-close from Floating-UI)
- Search input + filtered list:
  - **Empty query**: all 9 commands + top 10 notes
  - **Non-empty**: fuzzy match on note name + path (top 30) + matching commands
- Fuzzy scoring: exact substring (high) → all-chars-in-order (medium) → no-match (0)
- Keyboard: ↑/↓ navigate, Home/End jump to ends, Enter select, Esc close
- Mouse hover sets active row (for accessibility consistency)
- Active row uses `--bg-sel` (semantic accent surface token)
- Footer hint row with `<KeyboardHint>` chips: navigate / open / close

**Commands available now (9)**:

| ID | Action |
|---|---|
| `search` | `uiActions.setShowSearch(true)` |
| `settings` | dispatch `open-settings` |
| `toggleSidebar` | `uiActions.setShowSidebar(!showSidebar)` |
| `toggleRightPanel` | `uiActions.setShowHoverPanel(!showHoverPanel)` |
| `tabCalendar` | open right panel + `setRightPanelTab('calendar')` |
| `tabTags` | open + `setRightPanelTab('tags')` |
| `tabComments` | open + `setRightPanelTab('comments')` |
| `tabOutline` | open + `setRightPanelTab('outline')` |
| `tabMetadata` | open + `setRightPanelTab('metadata')` |

`newNote` / `newFolder` excluded for now — they require container-context which the palette doesn't have (`newNote` needs a selected container; `newFolder` opens a Sidebar modal). They remain accessible via their own shortcuts (`Ctrl+N`, `Ctrl+Shift+N`) and via Sidebar UI.

CSS: `src/styles/features/command-palette.css` (~110 lines), Tier 2 / Tier 3 tokens only.

## 5. KeyboardHint OS detection (primitive update)

`src/design-system/components/KeyboardHint.tsx`:

- `isMacPlatform()` at module load: checks `navigator.userAgentData.platform`, `navigator.platform`, and `navigator.userAgent` for Mac/iPhone/iPad markers
- New `platform?: 'mac' | 'win'` prop for explicit override (testing / SSR)
- Two display maps:
  - **MAC_DISPLAY**: `Ctrl → ⌃, Cmd/Meta/Mod → ⌘, Alt/Option → ⌥, Shift → ⇧, Delete → Del`
  - **WIN_DISPLAY**: `Ctrl → Ctrl, Cmd/Meta → Win, Mod → Ctrl, Alt/Option → Alt, Shift → Shift, Delete → Del`
- Common keys (arrows, Enter, Esc, Backspace, Tab, Space) shared between both
- macOS convention: glyphs without separator (`⌘⇧K`). Win/Linux: `Ctrl+Shift+K` with `+` separator
- Default separator now context-aware (mac = `''`, win = `'+'`); caller can still override with `separator` prop
- New CSS hooks `.ds-kbd--mac` and `.ds-kbd--win` (currently unused — opt-in for future cosmetic differences)

Backward-compat: existing `<KeyboardHint keys={['Ctrl', 'K']}>` calls render identically on Win/Linux. On macOS, they auto-render as `⌃K` instead of `Ctrl+K`.

## 7. Smoke-test checklist

1. Press `Ctrl+K` → command palette opens with input focused, lists 9 commands + 10 notes (or all notes if vault is small)
2. Type a partial note name → results filter live, top match active
3. ↑/↓ → row highlight moves; Enter → opens that note in hover window (note row) OR runs the command (command row)
4. Esc → palette closes, focus returns to previous element
5. Press `Ctrl+Shift+F` → search panel opens (NOT command palette)
6. Press `Ctrl+,` → settings modal opens from anywhere
7. Press `Ctrl+Shift+N` → new-folder dialog opens (sidebar auto-expands if collapsed)
8. Press `Alt+1` → right panel opens + Calendar tab active
9. Press `Alt+3` → right panel + Comments tab
10. Press `Ctrl+D` → does nothing (binding moved)
11. Press `Ctrl+Shift+Delete` → does nothing yet (handler in 5.0.4c)
12. Settings → Keyboard Shortcuts tab → 17 active bindings listed; old `save / toggleMemo / toggleMetadata / calendar` gone
13. On macOS (if testing): KeyboardHint chips show `⌘ ⇧ K` rather than `Ctrl+Shift+K`
