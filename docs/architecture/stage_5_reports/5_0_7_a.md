## D. Deferred items

1. **`<SearchResultCard>` Card-primitive wrap** — Card primitive (5.0.2a) ships with rounded box + shadow + density padding that visually conflicts with `.search-content-item`'s row design (colored left strip + bg gradient). Three paths forward:
   - Add a `density="flat"` or `as="row"` variant to Card to neutralize its chrome
   - Migrate the per-type row coloring into a CSS layer so Card's chrome can sit on top cleanly
   - Skip the wrap permanently and let `.search-content-item` stay as a token-driven row
   - Decision: revisit when **5.0.7e** runs (ContextMenu + final card primitive sweep)
2. **ContextMenu primitive swap** — the 2 custom context menus (`customContextMenu`, `noteContextMenu`) in Search.tsx use raw absolute-positioned divs. Plan delta §C-5 says swap to 5.0.2b `<ContextMenu>` primitive, but that touches `modalActions.showContextMenu` which has 30+ call sites across the codebase. Carved out as **5.0.7e**.

## E. Risk register

- **Render flicker** on empty-query palette open: the recent-notes memo recomputes whenever `fileTree` changes. fileTreeStore typically holds a stable ref between unrelated updates, so this should rarely fire. If it does, the visible recent list is the same — no UX regression.
- **Tantivy index not ready** at palette open: `fullTextSearch` Tauri command throws; we catch + clear `contentResults`. UI shows only filename / command matches. No error toast — palette is best-effort.
- **Content match overflow**: capped at `MAX_CONTENT_RESULTS=20`. If the user has thousands of body matches for "a", they see top 20 ranked by Tantivy score. The "Search '{query}' in panel" punt is always present as an escape valve.
- **Stale Korean comment in NOTE_TYPES**: replaced with English `'All'` + JSDoc — the label is never rendered (call sites override), but a future reader who imports NOTE_TYPES directly will get a sensible default.

## F. What ships in this sub-stage

- 4-tab Search (`노트 / 본문 / 첨부 / 그래프`) — Details surface dropped, no replacement modal/expand (follow-up in 5.0.7-final).
