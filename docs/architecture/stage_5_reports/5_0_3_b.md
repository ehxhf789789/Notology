## 2. Changes landed

### 2.1 `tokens.css` — TitleBar height + new sidebar-icon-width Tier-3 token

```diff
-  --titlebar-height: 36px;
+  --titlebar-height: 32px;  /* plan §4.1: minimal 32px */
+  --sidebar-icon-width: 52px;  /* plan §4.1: collapsed-icon-only sidebar */
```

`--h-titlebar` alias automatically picks up the new value. Hover-window
chrome, vault selector, and any other surface that uses `var(--titlebar-height)`
also shrinks by 4px without further change.

### 2.2 `uiStore.ts` — new `sidebarCollapsed` state

- `SIDEBAR_ICON_WIDTH = 52` exported const (matches the Tier-3 token)
- `sidebarCollapsed: boolean` state, loaded from `localStorage` key `notology-sidebar-collapsed` (`'1'` / `'0'`)
- `setSidebarCollapsed(collapsed)` action persists on change; no-op when value unchanged (avoids redundant store mutations)
- `useSidebarCollapsed()` selector exported via zustand barrel

This is **additive** — `showSidebar` boolean is untouched, so the 3 effective states are:

| `showSidebar` | `sidebarCollapsed` | Effective state |
|---|---|---|
| `true` | `false` | Expanded (default) |
| `true` | `true` | Icon-only (~52px) |
| `false` | (any) | Hidden (thin strip with expand button — pre-existing behavior) |

Backward compatible: any code calling `setShowSidebar(false)` continues to work; only new code uses `sidebarCollapsed`.

### 2.3 `Sidebar.tsx` — branches on `sidebarCollapsed`

Render forks at one place. Collapsed mode renders:

- **Header**: only the existing back-arrow toggle button (action row hidden)
- **Body** (`<nav class="sidebar-icon-rail">`): vertical column of 3 `<IconButton>` (New folder / Search / Right-panel toggle), each wrapped in `<Tooltip placement="right">` for label discovery
- **Footer**: vertical stack with sync status `<Slot>`, collapse toggle (`<ChevronsRight>` when collapsed), settings `<IconButton>`. Vault button hidden in collapsed mode (no room for the label; vault switcher reachable via the settings dialog or by re-expanding).

Expanded mode preserves all pre-5.0.3b behavior; the only new element is the collapse toggle button next to settings in the footer (`<ChevronsLeft>` to collapse).

The icon-rail "New folder" button auto-expands the sidebar first (`setSidebarCollapsed(false)` then opens the new-container modal). Otherwise the modal would render under an icon-only header with no room for the input.

### 2.4 `App.tsx` — sidebar wrapper width logic

```diff
- <div className={`sidebar-wrapper ... `}
-      style={{ width: ... ? sidebarWidth : undefined }}>
+ <div className={`sidebar-wrapper ...${sidebarCollapsed ? ' sidebar-wrapper--icon-only' : ''}`}
+      style={{ width: ... ? (sidebarCollapsed ? SIDEBAR_ICON_WIDTH : sidebarWidth) : undefined }}>
   {showSidebar || sidebarAnimState === 'closing' ? (
     <>
       <Sidebar />
-      <div className="divider" onMouseDown={startResize} />
+      {!sidebarCollapsed && <div className="divider" onMouseDown={startResize} />}
     </>
```

Resize divider is hidden in icon-only mode (52px is fixed by design, not user-resizable). Existing slide-open/close animations remain untouched and operate on the appropriate width.

### 2.5 `sidebar-icon-only.css` — new isolated CSS file

~50 lines. Tier-2 tokens only. Defines:

- `.sidebar-wrapper--icon-only .divider { display: none }` — resize handle hidden
- `.sidebar--icon-only` width inheritance
- `.sidebar--icon-only .sidebar-header` — centered, tighter padding
- `.sidebar-icon-rail` — vertical flex column with gap
- `.sidebar--icon-only .sidebar-footer` — column layout for icon-only footer

Isolated from `sidebar.css` to avoid touching other-track WT changes.

### 2.6 i18n

2 new keys (ko + en):
- `sidebarCollapse: '사이드바 축소 (아이콘만)' / 'Collapse sidebar (icons only)'`
- `sidebarExpand: '사이드바 펼치기' / 'Expand sidebar'`

## 3. UX flow

1. User opens app → sidebar in last-used state (expanded or icon-only, persisted across reload)
2. User clicks `<ChevronsLeft>` in expanded mode's footer → sidebar collapses to 52px showing 3 icons + footer icons
3. User clicks `<ChevronsRight>` (now in collapsed footer) → sidebar expands back to last `sidebarWidth`
4. Right-panel toggle works identically in both modes
5. Search toggle, new-folder button, and right-panel toggle all reachable from icon rail in collapsed mode

Pre-existing `showSidebar` hide-entirely behavior unchanged — `Ctrl+←` still toggles between fully hidden + last-shown mode.
