## B. What landed in this sub-stage

1. **NEW `docs/architecture/MICROCOPY_GUIDE.md`** — 8 sections (tone / terminology / patterns / decision tree / exceptions / review checklist / known prefix status / source of truth). Replaces ad-hoc per-session microcopy decisions with a single canonical reference.

2. **7 new i18n keys** (ko + en × 7 = 14 occurrences) for primitive a11y + math extension:
   - `dsClose`, `dsSelectPlaceholder`, `dsToastRegion`
   - `mathInputBlock`, `mathInputInline`, `mathError`, `mathAutoFix`

3. **Dialog primitive `closeAriaLabel` prop** — primitives stay decoupled from i18n (no `useLanguage`/`t` import inside design-system); consumers thread their localized label. Sensible default of `'Close'`.

4. **Decision: Tone reconciliation pass on `vault*` / `trash*` / `calendar*` / `conflictList*`** explicitly deferred to **5.0.11-followup** (~1 session) — mechanical rewrite of ~80 keys against §4 of the guide.
