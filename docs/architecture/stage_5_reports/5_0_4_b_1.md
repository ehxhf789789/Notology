## 2. Why text triggers were removed

HanBin AskUserQuestion sign-off (2026-05-15) — all answered "Recommended":

| Trigger | Was | Now |
|---|---|---|
| `$` (single) | inline math 300ms debounce activation | **`/수식 (인라인)`** palette command |
| `$$` (consecutive) | block math activation | **`/수식 (블록)`** palette command |
| `[[name]]` | wiki-link InputRule → atom | **`/위키 링크`** palette command + existing `[[` Suggestion popup (retained — popup is not an InputRule, it's a typeahead that always allows Esc-out) |
| `![[file]]` | media/attachment embed InputRule | **`/첨부파일`** palette command + drag-drop (existing) |

Concrete reason: `$5,000` / `$100 / item` / Korean IME composition all activated math inadvertently. `[[` / `![[` were idiomatic markdown but inconsistent with the single-entry-point philosophy. Slash palette = one canonical way to insert structured content.

## 4. How math command execution works

Math is a special case — slash commands typically run a TipTap chain, but math needs to insert an atom node **and** open its edit popup. Implementation in `commands.ts`:

```ts
mathInline: {
  run: (editor, range) => {
    editor.chain().focus().deleteRange(range).run();  // remove "/query"
    insertMathNode(editor, 'mathInline');               // insert empty atom
  }
}

function insertMathNode(editor, nodeType) {
  const node = editor.schema.nodes[nodeType].create({ formula: '' });
  const tr = editor.state.tr.replaceSelectionWith(node);
  const insertedPos = tr.selection.from - 1;
  editor.view.dispatch(tr);
  // Open edit popup via MathExtension's _mathStartEdit hook
  setTimeout(() => {
    const domNode = editor.view.nodeDOM(insertedPos);
    const startEdit = (domNode as any)._mathStartEdit;
    if (startEdit) startEdit();
    else domNode.dispatchEvent(new MouseEvent('dblclick', { bubbles: true }));
  }, 50);
}
```

This reuses MathExtension's existing edit popup (the same one that double-click triggers) — no separate math-edit UI duplication.
