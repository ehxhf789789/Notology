## C. 동기화 상태 패널 (4 케이스)

> 좌하단 `● 동기화됨` (또는 다른 상태) 클릭

| # | 조작 | 기대 결과 | 결과 |
|---|------|-----------|------|
| C1 | sync indicator 클릭 | popover 에 **위에서부터**: 상태 라인 (● + 라벨 + 시각) → 메타데이터 (↑↓) → [지금 동기화] 큰 버튼 → 하단 [일시정지 \| 휴지통] | `[ ]` |
| C2 | [지금 동기화] 클릭 | 즉시 sync 실행 → 메타데이터 업데이트, "동기화됨 · 방금" | `[ ]` |
| C3 | [일시정지] 클릭 | 상태가 "일시 정지됨" 으로 변경, 버튼 라벨이 [재개] 로 | `[ ]` |
| C4 | popover 외부 클릭 또는 Esc | 닫힘 | `[ ]` |

## D. NAS 삭제 감지 + 휴지통 (5 케이스)

> 사전: 다른 device 또는 NAS DSM 웹에서 vault 측 파일을 임의 삭제할 수 있는 환경

| # | 조작 | 기대 결과 | 결과 |
|---|------|-----------|------|
| D1 | DSM 웹에서 `vault/.notology/refs/` 의 `.json` 1~4개 + 같은 노트의 `.md` 둘 다 삭제 → 앱에서 [지금 동기화] | 우하단 toast: "노트 N개가 NAS에서 삭제되어 휴지통으로 이동" + 노트 목록에서 사라짐 | `[ ]` |
| D2 | DSM 웹에서 ref `.json` **만** 삭제 (`.md` 는 그대로) → 앱에서 [지금 동기화] | trash 안 됨. ref 자동 복구 (다시 NAS 에 ref 생김) | `[ ]` |
| D3 | 좌하단 sync 패널 → [휴지통] 클릭 | 삭제된 노트만 보임 (`.notology/*` 시스템 파일은 기본 숨김). 헤더에 "N개 항목 · 30일 보관" | `[ ]` |
| D4 | 휴지통의 한 항목 [복원] 클릭 | 원위치로 복원 + success toast + 노트 목록에 다시 나타남 + NAS 에 자동 재push | `[ ]` |
| D5 | 휴지통의 한 항목 [영구 삭제] 클릭 | 확인 다이얼로그 → 확인 → 완전 제거 (휴지통에서도 사라짐) | `[ ]` |

## 점검 시 유의사항

- D 카테고리는 NAS DSM 웹 접근 필요. 1-device 환경에서 다른 device 의 동작 시뮬레이션
- A2 의 "보관소 변경" 진입점: 좌하단 vault 이름 (예: "한글test") 클릭 후 메뉴/버튼
- ✗ 인 항목 옆에 무엇이 어떻게 다른지 한 줄 메모 권장

미세한 시각적 어색함 (간격, 색상, 글꼴 크기) 은 별도 기록 — 본 검증은 **기능 동작** 위주
